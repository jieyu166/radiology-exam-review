## Follow-up: Explicit question answer states

The migration now records review status separately from answer semantics. The 51-note review queue uses `reviewStatus: needs_review`; unresolved answers use `answerStatus: unresolved`, `answerMode: none`, and an empty `acceptedAnswers` list. Multi-answer questions use an explicit answer mode and accepted answer set so the compiler and review UI do not infer clinical correctness from a scalar answer field.
