# arterial-dissection-mri

**動脈剝離的壁內血腫（intramural hematoma）訊號隨血紅素分解演變——急性期反而是『低/等訊號』而非高訊號（最常見陷阱）；亞急性期（methemoglobin）才轉為典型偏心/環周新月形高訊號。** 判讀分水嶺：**急性（deoxyhemoglobin）低-等訊號 → 亞急性（methemoglobin）高訊號新月徵（T1 FS 最可靠）；判讀須用『脂肪抑制 T1（T1 FS）』（血管旁脂肪亦亮）；殘餘管腔隨血栓化縮窄、流空減少/消失；經典＝偏心狹窄管腔 + 新月形壁內血腫 + 薄環狀（vasa vasorum）強化。**

## Summary
- **機轉/經典外觀**：內膜/vasa vasorum 撕裂 → 血入 media → **壁內血腫 + 假腔**；**經典＝偏心狹窄管腔 + 新月形壁內血腫 + 薄環狀強化**（adventitia vasa vasorum）。[^1][^2]
- **訊號隨時期演變**：壁內血腫 MR 呈**多樣訊號**（依血紅素階段），非單一固定。[^1][^2]
- **典型（亞急性期）**：**T1 FS/T2/DWI 呈高訊號新月徵（crescent sign）**——偏心（eccentric）或偶環周（circumferential）、新月/線狀/帶狀，對應 **methemoglobin** 期。[^1][^2]
- **急性期陷阱**：急性血腫（**deoxyhemoglobin** 為主）通常呈**低-等訊號**，非高訊號；須數天後轉 methemoglobin 才呈典型高訊號。[^1][^2]
- **殘餘管腔演變**：隨時間血栓化，殘餘管腔**逐漸縮窄**，**流空（flow void）減少或消失**。[^1]

## 放射科醫師影像判讀重點
- **序列**：懷疑頸動脈剝離 → **軸位脂肪抑制 T1（T1 FS）+ 頸部 MRA + DWI**；脂肪抑制必要（血管旁脂肪亦亮易混淆）。[^2]
- **crescent sign**：亞急性 T1 FS 高訊號新月＝壁內血腫最可靠徵象；DWI 亦可高訊號新月/環。[^2]
- **位置（STATdx）**：**ICAD 最常起於頸動脈球遠端 2-3 cm（不同於粥狀硬化好發球部）**；CCAD 常起自主動脈弓延伸至分叉；**顱外 ICAD >> 顱內或 CCAD、20% 雙側或併椎動脈**。[^3]
- **病理徵象（STATdx）**：**intimal flap 或 double lumen 為 pathognomonic 但僅 <10% 可見**；**aneurysmal dilatation 見於 30%（遠端 subcranial ICA）**；急性期呈 **flame-shaped（火焰狀）tapered 阻塞**；smooth tapering stenosis 為年輕無粥斑者典型。[^3]
- **超音波（STATdx）**：double lumen + 內膜膜片飄動 turbulent flow、**false lumen 低尖峰流速 + 舒張期逆流**、**ICAD 假腔幾乎皆血栓化**（CCAD 假腔可 blind-end 或通暢）；高位 ICAD 超音波不及 → 僅見阻力上升/流速下降；**"slosh" 現象（剝離近端收縮期前後往返血流）高度典型但非 pathognomonic**；flap 於 color Doppler 易被 blooming 遮蔽、grayscale 較清。[^3]
- **急性判讀**：急性期血腫可不亮，勿因「無高訊號」排除剝離；配合 MRA 管腔狹窄/double lumen/flap。[^1][^2]
- **CTA**：新月形高衰減壁增厚（intramural thrombus low-attenuation crescent）、管腔狹窄、dissecting pseudoaneurysm、double lumen。[^2][^3]
- **追蹤/預後**：殘餘管腔縮窄、流空消失反映血栓化；**US 追蹤抗凝療效——ICAD 抗凝後再通達 70%**；**90% 狹窄消退、70% 阻塞再通、33% 動脈瘤縮小**。[^1][^3]

## 臨床重點（5 句）
1. **臨床三聯**：**同側頭/頸/顏面痛 + 部分 Horner 症候群（miosis + ptosis，眼交感麻痺）+ TIA/中風三聯**（約 33%）；亦見 bruit(40%)、搏動性耳鳴、下顱神經麻痺（尤 CN X）。[^3]
2. **誘因**：**頸過度伸展/旋轉（瑜伽、劇烈運動、咳嗽、嘔吐、頸部按摩/整脊）**、外傷、醫源性、或血管壁弱化（FMD、遺傳結締組織病）；ICAD 可自發。[^3]
3. **流行病學**：**年齡 30-55 歲（平均 40）、年發生率 2.5-3/10 萬**；ICA 為最常剝離之頸段動脈、顱外 > 顱內。[^3]
4. **預後**：**ICAD 死亡 <5%**、90% 狹窄消退、70% 阻塞再通；**復發風險 2%（首月）之後每年 1%**（多在他血管）；外傷型神經併發症較自發型嚴重。[^3]
5. **治療**：**抗栓（IV heparin + 口服 warfarin，除非出血性中風禁忌）+ 降壓**；無症狀且穩定者抗血小板 6 個月；**血管內支架罕用、手術（interposition graft）為難治備選**。[^3]

> [!note] 考點：關於dissecting/dissection artery，何者錯誤?
> **「急性血腫通常呈高訊號」錯誤**——急性期（deoxyhemoglobin）通常呈**低-等訊號**，需演變至 methemoglobin 期才呈高訊號。壁內血腫訊號隨時間多樣變化、典型呈偏心/環周新月形高訊號、殘餘管腔隨時間縮窄反映流空減少，皆正確。[^1][^2]
