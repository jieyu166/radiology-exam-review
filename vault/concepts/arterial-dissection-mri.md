# arterial-dissection-mri

**動脈剝離的壁內血腫（intramural hematoma）訊號隨血紅素分解演變——急性期反而是『低/等訊號』而非高訊號（最常見陷阱）；亞急性期（methemoglobin）才轉為典型偏心/環周新月形高訊號。** 判讀分水嶺：**急性（deoxyhemoglobin）低-等訊號 → 亞急性（methemoglobin）高訊號新月徵（T1 FS 最可靠）；判讀須用『脂肪抑制 T1（T1 FS）』（血管旁脂肪亦亮）；殘餘管腔隨血栓化縮窄、流空減少/消失；經典＝偏心狹窄管腔 + 新月形壁內血腫 + 薄環狀（vasa vasorum）強化。**

## Summary
- **機轉/經典外觀**：內膜/vasa vasorum 撕裂 → 血入 media → **壁內血腫 + 假腔**；**經典＝偏心狹窄管腔 + 新月形壁內血腫 + 薄環狀強化**（adventitia vasa vasorum）。[^1][^2]
- **訊號隨時期演變**：壁內血腫 MR 呈**多樣訊號**（依血紅素階段），非單一固定。[^1][^2]
- **典型（亞急性期）**：**T1 FS/T2/DWI 呈高訊號新月徵（crescent sign）**——偏心（eccentric）或偶環周（circumferential）、新月/線狀/帶狀，對應 **methemoglobin** 期。[^1][^2]
- **急性期陷阱**：急性血腫（**deoxyhemoglobin** 為主）通常呈**低-等訊號**，非高訊號；須數天後轉 methemoglobin 才呈典型高訊號。[^1][^2]
- **殘餘管腔演變**：隨時間血栓化，殘餘管腔**逐漸縮窄**，**流空（flow void）減少或消失**。[^1]

## 放射科醫師影像判讀重點
- **序列**：懷疑頸動脈剝離 → **軸位脂肪抑制 T1（T1 FS）+ 頸部 MRA + DWI**；脂肪抑制必要（血管旁脂肪亦亮易混淆）。[^2]
- **crescent sign**：亞急性 T1 FS 高訊號新月＝壁內血腫最可靠徵象；DWI 亦可高訊號新月/環。[^2]
- **急性判讀**：急性期血腫可不亮，勿因「無高訊號」排除剝離；配合 MRA 管腔狹窄/double lumen/flap。[^1][^2]
- **CTA**：新月形高衰減壁增厚、管腔狹窄、dissecting pseudoaneurysm、double lumen。[^2]
- **追蹤**：殘餘管腔縮窄、流空消失反映血栓化演變。[^1]

## 臨床重點（5 句）
1. **訊號演變**：急性低-等（deoxyHb）→ 亞急性高（metHb）。[^1][^2]
2. **crescent sign**：亞急性 T1 FS 高訊號新月為典型。[^1][^2]
3. **序列**：T1 FS + MRA + DWI，脂肪抑制必要。[^2]
4. **經典**：偏心狹窄 + 新月血腫 + 薄環狀強化。[^2]
5. **殘餘管腔**：隨時間縮窄、流空消失。[^1]

> [!note] 考點：關於dissecting/dissection artery，何者錯誤?
> **「急性血腫通常呈高訊號」錯誤**——急性期（deoxyhemoglobin）通常呈**低-等訊號**，需演變至 methemoglobin 期才呈高訊號。壁內血腫訊號隨時間多樣變化、典型呈偏心/環周新月形高訊號、殘餘管腔隨時間縮窄反映流空減少，皆正確。[^1][^2]
