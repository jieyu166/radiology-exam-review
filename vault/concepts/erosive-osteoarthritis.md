# erosive-osteoarthritis

**Erosive (inflammatory) osteoarthritis 是手部骨關節炎的一種亞型，除了退化性變化外，另具「侵蝕性/發炎性」成分。流行病學上有顯著女性偏好（F:M 約 12:1），典型出現在停經後（postmenopausal）婦女。** 判讀分水嶺：**好發手部 DIP、PIP 與第一 CMC 關節，特徵為「中央性（central）」軟骨下侵蝕（至少兩處分屬不同指間關節），中央侵蝕合併邊緣骨贅產生經典的「gull-wing（海鷗翼）」外觀；缺乏 RA 的邊緣性（marginal）侵蝕與骨質疏鬆。此題以「性別分布」作鑑別：erosive OA 明顯偏女性，可與偏男性的 reactive arthritis／gout、以及無性別偏好的 psoriatic arthritis 區分。**

## Summary
- **性別/年齡（本題重點）**：顯著女性偏好，**F:M 約 12:1**，典型見於**停經後**婦女。[^1]
- **臨床**：表現模擬發炎性關節病（PsA、RA），雙手手指相對急性/亞急性晨僵；但無全身性症狀。[^1]
- **病理/血清**：本質為 OA 亞型，兼具退化性軟骨變化與類 RA 的增生性滑膜炎；RF 陰性、ANA 陰性、ESR/CRP 陰性或輕度上升。[^1]
- **分布**：偏好手部——DIP、PIP、第一 CMC 關節。[^1]
- **影像特徵**：瀰漫性軟骨流失伴關節腔狹窄；**中央性軟骨下侵蝕**（至少兩處分屬不同指間關節），中央侵蝕位置產生經典「**gull-wing**」外觀；可見關節僵直（ankylosis）；**缺乏**邊緣性侵蝕、梭形軟組織腫脹與骨質疏鬆。[^1]
- **鑑別性別線索**：psoriatic arthritis 無性別偏好；reactive arthritis（Reiter）好發男性（約 20–50 歲）；gout 明顯男性為主（約 20:1，年輕更明顯，老年趨於平均）。[^2][^3][^4]

## 影像診斷

### X 光（Plain radiograph，主力）
- 手部 DIP/PIP/第一 CMC；瀰漫性軟骨流失＋關節腔狹窄；**中央性**軟骨下侵蝕→「gull-wing」；可進展至關節僵直；不見邊緣性侵蝕、梭形軟組織腫脹、骨質疏鬆。[^1]

### MRI / 其他
- 一般以 X 光即可診斷；MRI 可顯示活動性滑膜炎與骨髓水腫，但非必要。[^1]

## 鑑別與報告要點

| 疾病 | 性別偏好 | 侵蝕型態/關鍵 |
|---|---|---|
| **Erosive OA** | **女性 F:M ~12:1（停經後）** | 中央性侵蝕、gull-wing；DIP/PIP/1st CMC；無邊緣侵蝕/骨鬆 [^1] |
| Osteoarthritis | — | 同分布但**無侵蝕** [^1] |
| Rheumatoid arthritis | 女性 | **邊緣性**侵蝕、近端關節、骨質疏鬆、分布不同 [^1] |
| Psoriatic arthritis | **無性別偏好** | 邊緣侵蝕、pencil-in-cup、DIP、臘腸指 [^2] |
| Reactive arthritis (Reiter) | **男性（~20–50 歲）** | 下肢為主、不對稱、附著點炎 [^3] |
| Gout | **男性（~20:1）** | 邊緣鑿孔狀（punched-out）侵蝕伴懸垂邊、tophus [^4] |

## 題目
> [!question]- Which one of the following arthritis is more common in females? (2021-257)
> **A（Erosive osteoarthritis）**——erosive OA 有顯著女性偏好（F:M 約 12:1），典型見於停經後婦女。其餘皆非女性為主：B psoriatic arthritis 無性別偏好；C reactive arthritis（Reiter）好發男性（約 20–50 歲）；D gouty arthritis 明顯男性為主（約 20:1，年輕更明顯，老年趨平均）。[^1][^2][^3][^4]
