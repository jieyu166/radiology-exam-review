# ankle-brachial-index

**ABI = 踝動脈收縮壓 / 兩側肱動脈收縮壓中較高者（非兩側之和）。ABI < 0.9 為異常（PAD）；ABI > 1.3 提示動脈鈣化（不可壓縮）。**

## Summary
- 公式：ABI = ankle SBP / **higher** of the two brachial SBPs [^1]
- 正常：1.0 – 1.3 [^1]
- **< 0.9**：peripheral arterial disease [^1]
- **> 1.3**：動脈嚴重鈣化（不可壓縮），多見於糖尿病/CKD [^1]

## 放射科醫師影像判讀重點
- **標準量測法**：病人平躺休息後，以壓脈帶加超音波都卜勒探頭量測雙側肱動脈及雙側踝部(足背動脈 dorsalis pedis 與後脛動脈 posterior tibial)收縮壓；每肢 ABI 之分母採「兩側肱動脈收縮壓中較高者」。[^2]
- **數值判讀分界**：ABI ≤0.90 判定為周邊動脈疾病(PAD)且對血管攝影確認之狹窄具高特異性；0.91–0.99 為臨界；1.00–1.40 為正常。[^2]
- **不可壓縮動脈的陷阱**：ABI >1.40(或血管無法被壓迫)提示動脈壁鈣化、血管僵硬(Mönckeberg 中膜鈣化)，常見於糖尿病與慢性腎病，此時 ABI 會假性正常/升高而低估 PAD——須改以趾肱指數(TBI)評估。[^2]
- **影像對照**：ABI 為生理性篩檢，異常者可續以都卜勒超音波、CTA 或 MRA 定位病灶；判讀 ABI 時務必結合病史與波形，避免鈣化造成誤判。[^2]

## 臨床重點（5 句）
- ABI 是診斷下肢周邊動脈疾病最常用、非侵入且成本低的第一線檢查。[^2]
- 低 ABI 不僅代表下肢缺血，也是全身動脈粥狀硬化與心血管事件風險升高的獨立指標。[^2]
- 周邊動脈疾病常見危險因子包括年齡、吸菸、糖尿病、高血壓與高血脂。[^2]
- 早期 PAD 可無症狀，典型症狀為間歇性跛行，嚴重者出現靜止痛或組織缺損。[^2]
- 處置以危險因子控制、運動治療與抗血小板藥物為基礎，嚴重缺血則考慮血管重建。[^2]
