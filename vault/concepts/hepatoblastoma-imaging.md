# hepatoblastoma-imaging

**肝母細胞瘤（hepatoblastoma）為兒童（尤其 <3-4 歲）最常見原發性肝惡性腫瘤，典型影像為邊界清楚之異質性、低密度（hypoattenuating）腫塊，CT 約 40% 可見緻密塊狀鈣化——並非典型囊性病灶，此為考題常見陷阱。** 判讀分水嶺：**臨床「無痛腹部腫塊 + AFP 明顯升高（~90%）」＋影像「well-defined、hypoattenuating、chunky calcification、spoke-wheel」＝ hepatoblastoma；囊性為主要想 mesenchymal hamartoma、超高血流/大血管想 congenital hepatic hemangioma。**

## Summary
- **典型表現**：**邊界清楚（well-defined）之異質性（heterogeneous）腫塊、低密度（hypoattenuating）**，常合併壞死/出血；纖維隔膜可造成 **spoke-wheel（輻輪）外觀**。[^1][^2]
- **鈣化**：**CT 約 40% 可見緻密塊狀鈣化（chunky dense calcification）**；平片僅約 10% 可見——兩數字為不同模態偵測率（並列）。[^2]
- **非典型表現**：**囊性（cystic）並非典型特徵**——考題常見陷阱；囊性/混合囊實性應優先想 mesenchymal hamartoma。[^1][^2]
- **腫瘤指標**：**血清 AFP 明顯升高（~90%）**；臨床多為無痛性腹部腫塊。[^2]
- **轉移**：最常轉移至**肺（10-20%）**，亦可至骨、腦、淋巴結、眼、卵巢；可壓迫/侵犯肝內血管及 IVC。[^1]
- **相關症候群**：**Beckwith-Wiedemann**（過度生長、易罹 Wilms 與 hepatoblastoma）、**hemihypertrophy（~2%）**、**FAP（家族性腺瘤性瘜肉病）**、早產/低出生體重。[^1][^2]

## 放射科醫師影像判讀重點
- **US（第一線）**：主要為 **echogenic 實質腫塊**，較大者異質、回音多變，即使大也相對邊界清楚（pseudocapsule）；鈣化呈聲影；傾向**推擠而非侵犯**鄰近構造。[^1][^2]
- **CT**：well-defined、hypoattenuating 異質腫塊 + 壞死/出血 + 約 40% chunky 鈣化；同時可評估肺轉移與淋巴結。[^2]
- **MRI（優於 CT）**：對**腫瘤邊界、血管侵犯、淋巴結**顯示優於 CT；T1 低訊號、T2 高訊號、Gd 呈異質強化；DSA 多為 hypervascular。[^2]
- **鑑別徵象**：**無大血管**（有別於血流極豐、可見大血管的 congenital hepatic hemangioma）；血流僅輕-中度、雜亂。[^1]
- **陷阱**：把壞死/出血造成的「較囊性」外觀誤當成真性囊性腫瘤；囊性為主應想 mesenchymal hamartoma。[^1]

## 臨床重點（5 句）
1. **年齡與指標**：兒童（多 <3-4 歲）最常見原發性肝惡性腫瘤，AFP 升高（~90%）為關鍵臨床線索。[^2]
2. **症候群篩檢**：診斷 hepatoblastoma 應留意 Beckwith-Wiedemann、hemihypertrophy、FAP 等相關；反之這些族群需監測 AFP。[^1][^2]
3. **分期與可切除性**：MRI 評估血管侵犯與範圍以判斷可切除性（PRETEXT 分期），影響手術/化療順序。[^2]
4. **轉移評估**：以肺為最常見轉移部位，CT 胸部評估為分期必要。[^1]
5. **鑑別**：congenital hepatic hemangioma（更高血流）、mesenchymal hamartoma（囊性為主）、metastatic neuroblastoma——臨床年齡、AFP 與血流型態為區辨關鍵。[^1]

> [!note] 考點：以下何者非肝母細胞瘤典型影像特徵？
> **囊性（Cystic，B）**——肝母細胞瘤典型為邊界清楚異質性低密度腫塊，CT 約 40% 有緻密塊狀鈣化，並非典型囊性病灶（囊性為主應想 mesenchymal hamartoma）。[^1][^2]
