# clippers

**CLIPPERS 是排除性診斷——目前無特異性血清/CSF標記，靠臨床＋典型影像＋審慎排除其他鑑別後才能下診斷，且停類固醇易復發需長期免疫抑制。** 判讀分水嶺：MRI 呈橋腦為主的「點狀與曲線狀（punctate and curvilinear）」或「胡椒粉狀（peppering）」強化，但「有特異性生物標記可確診」為錯誤敘述。

## Summary
- **好發部位**：以**橋腦（pons）**為主的慢性淋巴球性發炎，但**幕上侵犯也可見**，非侷限橋腦。[^1]
- **典型MRI強化型態**：呈**點狀與曲線狀（punctate and curvilinear）**或稱**「胡椒粉狀（peppering）」強化**。[^1]
- **典型伴隨表現**：**極少血管源性水腫(minimal vasogenic edema)**、**缺乏佔位效應(no mass effect)**——儘管顯影劑後表現顯著，病灶仍幾乎無水腫或明顯佔位效應。[^2]
- **非典型表現**：**出血(hemorrhage)並非**CLIPPERS之典型影像表現。[^2]
- **診斷方式（重要陷阱）**：目前**無特異性血清或CSF生物標記**可供確診；診斷需綜合臨床、影像、（必要時）病理，準則含**亞急性橋腦小腦功能障礙、類固醇治療顯著改善、無周邊神經異常、無其他替代診斷**（即排除性診斷）；好發中年、可能略偏男性。[^1][^3]
- **治療**：對類固醇反應良好，但**停用糖皮質類固醇後常復發（disease exacerbation）**，故需**長期免疫抑制治療**。[^1]

## 放射科醫師影像判讀重點
- **分布（PubMed review）**：**病灶以橋腦及鄰接後腦結構（小腦腳、小腦、延髓、中腦）為主、perivascular pattern 於此最密**；可延伸至脊髓與幕上（thalamus、basal ganglia、capsula interna、corpus callosum、大腦白質）。[^1]
- **特徵強化型態**：**點狀與曲線狀（punctate and curvilinear）gadolinium 強化「peppering」橋腦**；個別強化點多小（typically <3 mm）。[^1][^2]
- **無佔位/水腫**：儘管顯影後表現顯著，**極少血管源性水腫、缺乏佔位效應**；病灶隨類固醇治療減少。[^2]
- **非典型徵象**：**出血非典型**；若見大腫塊/明顯水腫/壞死/持續進展 → 應重新考慮 mimics（尤 lymphoma/PCNSL、血管炎）並考慮切片。[^2][^4]
- **判讀定位**：影像 + 臨床相符為診斷核心，但**無特異性血清/CSF 標記**——屬排除性診斷，須審慎排除替代診斷。[^1][^4]
- **序列建議**：對比後 T1（peppering）、T2/FLAIR（範圍）、追蹤治療反應；病灶對稱與否、範圍延伸皆需描述。[^1]

## 臨床重點（5 句）
1. **本質**：**腦幹為主之慢性淋巴球性（T 細胞為主）發炎性腦脊髓炎**，可治療但診斷困難（無 biomarker）。[^1][^4]
2. **臨床表現**：**亞急性腦幹小腦功能障礙**——步態失調、複視、構音障礙、顏面感覺異常等；無周邊神經異常。[^1][^4]
3. **診斷準則**：亞急性橋腦小腦症狀 + 典型 peppering 影像 + **類固醇治療顯著改善** + **排除替代診斷**（必要時病理）；好發中年、略偏男性。[^1][^4]
4. **mimics 警覺（PubMed）**：許多「CLIPPERS-like」個案追蹤後為**惡性（淋巴瘤）、血管炎或其他發炎病**；部分學者認為 CLIPPERS 可能為前惡性狀態或異質性症候群，非典型表現務必切片。[^4]
5. **治療/預後**：**糖皮質類固醇反應佳，但停藥常惡化，須長期免疫抑制（類固醇節省劑）**；早期介入預後較佳。[^1][^4]

> [!note] 考點：關於CLIPPERS，何者錯誤?
> 「**目前已有特異性血清/CSF標記可確診**」錯誤——CLIPPERS無特異性生物標記，屬排除性診斷。橋腦為主但可有幕上侵犯(對)、典型點狀/曲線狀或胡椒粉狀強化(對)、停類固醇易復發故需長期免疫抑制(對)皆正確。[^1]

## 題目
> [!question]- Which statement is false for CLIPPERS? (2016-263)
> **「已有特異性血清/CSF標記可確診」錯誤（C）**——CLIPPERS目前無特異性生物標記，屬排除性診斷。橋腦為主可有幕上侵犯(對)、典型peppering強化(對)、停類固醇易復發需長期免疫抑制(對)皆正確。[^1]

> [!question]- Which of the following is not a typical imaging finding of CLIPPERS? (2020-409)
> **出血（Hemorrhage，D）**——CLIPPERS典型呈點狀曲線狀強化、極少血管源性水腫、缺乏佔位效應；出血並非典型表現。[^2]
