# aortic-coarctation

**主動脈縮窄判讀分水嶺：縮窄好發於 isthmus（峽部，左鎖骨下動脈遠端／ductus 附近）。分型記時序——preductal（infantile，導管前型）依賴 PDA 供應遠端血流、多在嬰兒期表現、常合併其他心內畸形；postductal（adult，導管後型）為短段狹窄、常晚期才被發現而非嬰兒期。合併症含顱內 berry aneurysm（2.5–10%）、SAH；側支經 subclavian→internal mammary（內乳）→intercostal，造成 inferior rib notching（Roesler 徵，<5 歲罕見）；CXR 有 figure-3 徵。故「post-ductal type presents in infancy（導管後型於嬰兒期表現）」為錯誤敘述。**

## Summary
- **好發部位（isthmus）**：主動脈縮窄最常見於**峽部——左鎖骨下動脈起源遠端、鄰近 ductus arteriosus**；非典型者少見（多在腹主動脈）。[^1][^2]
- **分型與時序（本題重點）**：**preductal（infantile，導管前型）**遠端血流依賴 PDA、closure 可致命、常在嬰兒期表現、常合併其他心內畸形（complex）；**postductal（adult，導管後型）**為短段驟窄、常為 simple coarctation 且**多晚期才被發現，而非嬰兒期**。故「post-ductal type presents in infancy」為**錯誤**。[^2]
- **顱內動脈瘤（berry aneurysm）**：為公認合併／併發症（cerebral aneurysm 約 **2.5–10%**），可致蜘蛛膜下腔出血，屬 A 選項之正確描述。[^1][^2]
- **內乳動脈側支（rib notching）**：側支經 subclavian→**internal mammary（內乳／內胸）動脈**→intercostal，側面／正面 CXR 見擴張內乳動脈與 **inferior rib notching（Roesler 徵，<5 歲罕見）**，屬 C 選項之正確描述。[^1][^2]

## 放射科醫師影像判讀重點
- **CXR**：**figure-3 徵**（近端左鎖骨下動脈凸＋縮窄凹陷＋狹窄後擴張凸；約 50%）、食道鋇劑 **reverse figure-3**；**inferior rib notching（Roesler 徵）**由擴張肋間側支侵蝕肋骨下緣所致，侵犯第 3–8 肋（第 1、2 肋不受影響）、**<5 歲罕見**，單側 notching 提示異常鎖骨下動脈。[^2]
- **CTA**：峽部（左鎖骨下遠端）後外側**shelf-like 局部驟窄**；擴張側支（內乳、肋間）代表血流動力學顯著阻塞；多平面／3D 重組利於術前術後評估。[^2]
- **MR／MRA**：morphology（HASTE 黑血、SSFP 亮血、C+ MRA candy-cane 軸）＋功能評估；**indexed 最小橫截面積 <0.33 cm²/m²**、**心率校正 deceleration time ≥0.30 s⁻⁰·⁵** 預測嚴重（gradient ≥20 mmHg）；4D flow 評估側支血流與渦流。[^2]
- **側支路徑（3 條）**：subclavian→internal mammary→intercostal；subclavian→thyrocervical／costocervical→intercostal；subclavian→vertebral→anterior spinal→intercostal。[^2]
- **合併與併發**：bicuspid aortic valve（50–85%）、VSD、PDA、Turner syndrome（約 20% 有 coarctation）、Shone complex；併發顱內 berry aneurysm±SAH、夾層、主動脈瘤、左心室肥厚（LVH）。[^2]

## 臨床重點（5 句）
- 佔先天性心臟病約 5–10%，男性居多（M:F≈2:1）。[^1][^2]
- 新生兒若嚴重縮窄或導管關閉可致心衰竭；兒童／成人多以上下肢血壓差、股動脈搏動減弱、跛行、高血壓表現。[^2]
- 未修補者平均死亡年齡 35–42 歲，多死於夾層／破裂、心衰、心肌梗塞、腦出血。[^2]
- 治療：嬰兒首選外科修補；較大兒童／成人 native 或 recoarctation 首選 balloon angioplasty；recoarctation 多用 stent。[^2]
- 所有患者須終生由熟悉先天性心臟病之心臟科追蹤（高血壓、冠心病、夾層風險持續）。[^2]

## 題目
> [!question]- Which description about features of coarctation is incorrect? (2022-390)
> **the post-ductal type presents in infancy（D，關鍵）為錯誤**——導管後（adult／postductal）型多為 simple coarctation、常晚期才被發現；於**嬰兒期**表現者為 preductal（infantile）／complex coarctation（遠端血流依賴 PDA）。其餘正確：(A) berry aneurysm 為公認合併症（cerebral aneurysm 2.5–10%）；(B) isthmus（峽部）為最常見部位；(C) 側面 CXR 可見擴張之內乳（internal mammary）動脈側支（併 inferior rib notching）。[^1][^2]
