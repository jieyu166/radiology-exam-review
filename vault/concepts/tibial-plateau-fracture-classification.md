# tibial-plateau-fracture-classification

**三柱分型（Luo 2010）以「術前 CT」把脛骨平台分為內側、外側、後柱三柱，依受累柱數與皮質破裂與否分為 0／1／2／3 柱骨折；核心價值在於彌補 Schatzker 與 AO-OTA 系統「無法描述冠狀面／後柱骨塊」的盲點。** 判讀分水嶺：**傳統 Schatzker/AO-OTA 以正位 X 光為本、缺後柱語彙；後外側或後內側分離骨塊需 dorsal plating（後方鋼板）——放射報告若能指出後柱骨塊，直接改變手術入路。** 柱界定義於軸向 CT：以髁間隆起中心（O）為中心，連 O–脛骨結節（A）、O–腓骨頭最前點（C）、O–後內側嵴（D）畫線分出內／外／後柱，後柱再以後溝（B）分後內、後外亞區。

## Summary
- **三柱概念**：三柱分型於 2010 年提出，依賴術前 CT，將脛骨平台分為內側柱、外側柱、後柱；能描述冠狀面骨折與後柱骨塊，這是 Schatzker 與 AO-OTA 系統所缺。[^1][^2]
- **0 柱（Zero-column）**：純關節面壓陷、**無皮質（柱壁）破裂**、無劈裂型骨折線；最常見於外側柱（骨小樑較少、力學較弱），病人多在第 4–5 十年、骨密度下降者風險高；對應 Schatzker III 純壓陷。[^1]
- **1 柱（One-column）**：僅內、外或後柱其一，骨折線破壞該柱皮質；關鍵是**單一分離骨塊的劈裂型骨折**。即使骨折線延伸入後柱，只要僅一塊骨塊仍算 1 柱；需第二塊分離骨塊才升級為 2 柱。對應 Schatzker I、II（但後柱單獨骨折無 Schatzker 對應）。[^1]
- **2 柱（Two-column）**：三柱中受累兩柱，**須有兩塊分離骨塊、各自有骨折線延伸至該柱皮質**。例：外側平台若有前外側骨折＋另一後外側骨塊即為 2 柱；重點在後外側／後內側分離骨塊需後方 dorsal plating 才有最佳手術結果。對應 Schatzker IV（外＋後柱組合則無 Schatzker 對應）。[^1]
- **3 柱（Three-column）**：三柱皆受累、每柱骨折線皆達該柱皮質，**每柱至少一塊分離骨塊**；多為高能量、粉碎性；對應 Schatzker V、VI（但後柱成分無 Schatzker 對應），可能需三柱固定。[^1]

## 影像診斷
### X 光（平片）
- 常低估損傷嚴重度；應留意 lipohemarthrosis（脂肪-血關節積液）作為隱匿骨折線索。傳統 Schatzker/AO-OTA 依正位片，無法準確描述冠狀面後柱骨塊。[^1][^2]

### CT（三柱分型的依據）
- **術前 CT（含軸向與 3D 重組）為三柱分型的基礎**：於軸向像用 O/A/B/C/D 諸點畫柱界，判定受累柱數、分離骨塊數與皮質破裂。CT 能顯示後柱／冠狀面骨塊，提供手術入路（是否需後方 dorsal plating）與固定計畫的關鍵資訊。[^1][^2]

### MRI
- 有助評估關節周圍軟組織：半月板（~30%）、韌帶（~25%）損傷、軟骨與骨髓水腫。[^2]

## 鑑別與報告要點
| 柱數 | 定義關鍵 | Schatzker 對應 |
|---|---|---|
| 0 柱 | 純關節面壓陷、**皮質完整** | III（純壓陷） |
| 1 柱 | 單柱、單一分離骨塊、皮質破裂 | I、II（後柱單獨無對應） |
| 2 柱 | 兩柱、**兩塊分離骨塊**、需 dorsal plating 後柱骨塊 | IV（外＋後無對應） |
| 3 柱 | 三柱皆受累、每柱皆有分離骨塊 | V、VI（後柱成分無對應） |

- 報告務必指出**後柱／後外側／後內側分離骨塊**——直接影響手術入路與後方鋼板決策。

## 題目
> [!question]- Which one is correct about Three-Column Classification System for tibial plateau fractures? (2021-204)
> **E（All above are correct）**——選項 A–D 對 0／1／2／3 柱的定義皆正確：A 0 柱＝純關節面壓陷無 cleavage 骨折；B 1 柱＝單柱劈裂、皮質破裂、單一分離骨塊；C 2 柱＝兩柱各有分離骨塊、骨折線達皮質（後外側骨塊需 dorsal plating）；D 3 柱＝三柱皆受累、每柱骨折線達皮質。四項定義與 RadioGraphics 三柱分型逐字相符。[^1]
