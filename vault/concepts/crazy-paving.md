# crazy-paving

**Crazy-paving 就像濕地上的亂鋪石板：毛玻璃（地面）＋小葉間隔/內隔增厚（縫隙）；原型是 PAP，但 DDx 廣泛，幾乎「填充肺泡＋增厚間隔」的病都會有。** 判讀分水嶺：**crazy-paving＝GGO + 疊加 interlobular + intralobular 間隔增厚（非特異性）；常見 PAP（絕大多數 PAP 有）、肺水腫（最常見）、ARDS/AIP、肺泡出血、PCP、病毒（COVID-19）、COP、NSIP、lipoid pneumonia、黏液腺癌；『最不會出現』想 RB-ILD——它以上肺氣道中心結節為主，兩要件都不齊。** 記憶鉤：**「RB-ILD 是煙民小結節，不是鋪路病」**。

## Summary
- **本質**：**GGO ＋ 疊加的小葉間隔（interlobular）+ 小葉內間隔（intralobular）增厚（網狀）**；非特異性所見。[^1][^2]
- **常見病因**：**肺水腫（最常見）**、ARDS、細菌性肺炎、AIP、**PAP（絕大多數 PAP 有 crazy-paving）**。[^1][^2]
- **較少見**：藥物/放射性肺炎、肺泡出血/Goodpasture、慢性嗜酸性肺炎、UIP+DAD、mycoplasma、TB、**PCP、COVID-19**、cryptococcosis、**COP**、NSIP、lipoid pneumonia、黏液腺癌。[^1][^2]
- **最不會出現**：**RB-ILD（呼吸性細支氣管炎相關 ILD）**——以上肺 centrilobular GGO 結節/支氣管壁增厚為主，非瀰漫毛玻璃鋪路。[^1]

## 放射科醫師影像判讀重點
- **兩要件並存**：瀰漫 GGO ＋ 疊加間隔增厚 → 才叫 crazy-paving；缺一不算。[^1][^2]
- **臨床定 DDx**：急性（水腫/ARDS/出血/PCP）vs 慢性（PAP/lipoid/黏液腺癌）以病程分流。[^2]
- **PAP 原型**：對稱 perihilar、geographic 分界、絕大多數呈 crazy-paving。[^2]
- **陷阱**：RB-ILD 以氣道中心結節為主，非鋪路病。[^1]
- **非特異**：crazy-paving 本身不定診斷，須合併分布/病程/臨床。[^2]

## 臨床重點（5 句）
1. **crazy-paving＝GGO + 間隔增厚**、非特異。[^1][^2]
2. **最常見病因**：肺水腫；**PAP 為原型**。[^1][^2]
3. **廣泛 DDx**：ARDS/出血/PCP/COP/NSIP/黏液腺癌等。[^1]
4. **RB-ILD 最不會有**（氣道中心結節）。[^1]
5. **須合併病程/分布**判讀。[^2]

> [!note] 考點：何者最不會有 crazy-paving?
> **Respiratory bronchiolitis-ILD（RB-ILD）**——以氣道中心結節為主。NSIP、COP、PCP、PAP 皆可呈 crazy-paving。[^1][^2]
