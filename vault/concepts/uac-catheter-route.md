# uac-catheter-route

**UAC 與 UVC 都自臍部進入，但 UAC 先向「尾側下行」入髂動脈系統再折返上行；正確的最終位置是「主動脈(aorta)」——高位線 T6-T10 降主動脈、低位線 L3-L4 遠端腹主動脈，髂動脈只是過渡血管、停在該處即屬錯位。**

## Summary
- **UAC 正常路徑** [^1][^2]：Umbilical artery → internal iliac artery → common iliac artery → **aorta**。
- **正確 tip 位置**：理想高位線位於降胸主動脈 **T6-T10**（腎動脈/腸繫膜上動脈與主動脈弓分支之間）；可接受的低位線位於遠端腹主動脈 **L3-L4**（腎動脈起源以下）。[^2]
- **「主動脈」才是答案**：internal iliac artery、common iliac artery 皆為導管行進途中的過渡血管，若 tip 停留其中即為 low malposition；middle hepatic vein 與 IVC 屬靜脈系統，是 UVC 相關結構，與 UAC 無關。[^1][^2]

## 放射科醫師影像判讀重點
- **UAC vs UVC 分辨關鍵**：兩管皆自臍部進入，UAC 於 X 光上先向**尾側(caudal)下行**入骨盆髂動脈系統，再折返向上沿主動脈上行；UVC 則自臍部**直接上行**且偏前。此「初始走向」是床邊分辨兩管最實用的徵象。[^2]
- **兩個可接受位置**：高位線 T6-T10（避開 T5 以上主動脈弓分支與 T12-L1 腹主動脈分支開口）、低位線 L3-L4；避免 tip 落在腹主動脈分支開口(腹腔動脈、SMA、腎動脈)以降低內臟/腎缺血風險。[^2]
- **常見錯位**：Low → internal iliac artery 或其分支(superior/inferior gluteal、pudendal)；High → 主動脈弓或其分支、甚至經 ductus arteriosus 入肺動脈；Wrong vessel → 腹腔動脈、SMA、腎動脈、下肢動脈。首次置放 >50% 位置不正確。[^2]
- **併發症判讀**：血栓、動脈瘤/假性動脈瘤(可延遲表現，建議首年追蹤超音波)；tip 過高(>T5)危及主動脈弓分支、tip 在 T12-L1 危及腹主動脈分支(SMA→腸缺血/壞死性腸炎、腎動脈→高血壓/腎損傷)；低位線較易發生主動脈血栓與肢體缺血/生長障礙。[^2]

## 題目
> [!question]- Which position is correct for umbilical arterial catheters? (2022-501)
> **A（Aorta）** UAC 正常路徑為 umbilical artery → internal iliac artery(B) → common iliac artery(C) → **aorta(A)**；正確的最終 tip 位置在主動脈：理想高位線 T6-T10 降胸主動脈、可接受低位線 L3-L4 遠端腹主動脈。Internal iliac artery(B)、common iliac artery(C) 只是行進途中的過渡血管，停留其中屬 low malposition；middle hepatic vein(D)、IVC(E) 屬靜脈系統，是 UVC 相關結構而非 UAC。故正解為 A。[^1][^2]
