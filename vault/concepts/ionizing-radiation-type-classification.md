# ionizing-radiation-type-classification

**游離輻射有兩套分類：①「粒子型 vs 電磁波型」——X 光與 γ 射線本質皆為『電磁波』（僅來源不同：X 光來自軌域電子躍遷/制動輻射，γ 射線來自原子核衰變），屬電磁波型，非粒子型；②「直接 vs 間接」——帶電粒子（α、β）為直接游離；不帶電之光子（X 光/γ）與中子為間接游離，須先與物質作用產生荷電粒子才致游離。** 判讀分水嶺：**X 光與 γ「本質相同、只差來源」＝電磁波（非粒子）；不帶電（光子/中子）＝間接游離、帶電（α/β）＝直接游離。**

## Summary
- **粒子型游離輻射**：由具足夠動能之粒子（α、β、中子、質子等）以其**動能或電位能**使物質游離或產生制動輻射。[^1]
- **電磁波型游離輻射（X 光、γ）**：純粹為能量，將能量傳給物質致激發與游離；**X 光與 γ 本質相同（皆電磁波），僅來源不同**——X 光來自軌域電子躍遷或制動輻射（核外），γ 來自原子核衰變。[^1]
- **直接游離輻射**：**帶電粒子（α、β）**，碰撞時能直接引起游離。[^1][^2]
- **間接游離輻射**：**不帶電之光子（X 光/γ）與中子**，須先與物質作用（光電、康普吞、成對發生、核反應）**產生荷電二次粒子**後再致游離；中子多由核反應產生、不帶電，經與氫核作用間接游離。[^1][^2]

## 放射科醫師影像判讀重點
- **X 光 vs γ**：型態上完全相同（電磁波、高穿透），差別只在「產生來源」（核外 vs 核內），故屬電磁波型而非粒子型。[^1]
- **帶電否定直/間接**：帶電（α/β）＝直接；不帶電（光子/中子）＝間接——是分類的關鍵判準。[^2]
- **中子定位**：不帶電、多由核反應產生，屬間接游離（經氫核反衝等）。[^2]
- **二次電子概念**：X 光/γ 之游離大多經其產生之二次電子完成（Compton/光電）。[^2]
- **防護權重（ICRP 103）**：**不同輻射型態之生物效應以 radiation weighting factor（w_R）表述——光子/電子 w_R=1、α 粒子 w_R=20、中子依能量 2.5-20**；反映高 LET（α/中子）之直接/密集游離傷害較大。[^3]
- **考點提醒**：「X 光與 γ 為粒子型」是常見錯誤敘述（應為電磁波型）。[^1]

## 臨床重點（5 句）
1. **兩分類**：粒子型 vs 電磁波型；直接 vs 間接。[^1][^2]
2. **X 光/γ**：電磁波型，只差來源（核外/核內）。[^1]
3. **直接**：帶電粒子（α/β）。[^2]
4. **間接**：光子（X 光/γ）與中子，須先產生荷電粒子。[^2]
5. **陷阱**：X 光/γ 非粒子型。[^1]

> [!note] 考點：游離輻射型態分類，何者敘述為非？
> **X-ray 與 γ-ray 型態上完全相同、屬粒子型游離輻射（A）為錯誤**——X 光與 γ 本質皆為電磁波（僅來源不同），屬**電磁波型**，並非粒子型。粒子型藉粒子動能/電位能致游離、電磁波型藉能量傳遞致激發游離、中子不帶電多由核反應產生屬間接游離輻射，皆為正確。[^1][^2]
