# cardiac-mediastinal-contours-cxr

**正面胸片上心臟／縱膈的每一段輪廓由特定構造構成；記熟「哪條邊由誰形成」，才能反推某條邊消失或膨出代表什麼病灶（silhouette sign 的解剖基礎）。** 判讀分水嶺：**右緣主要是「靜脈系＋右心房」（SVC → 右心房 → IVC），左緣才是「動脈系＋左心」（主動脈結 → 肺動脈幹 → 左心耳 → 左心室）**。因此「主動脈」屬**左緣**（主動脈結），並非右心緣——這正是本題答案。唯一陷阱：**年長者升主動脈可因主動脈迂曲（unfolding）投影到 SVC 右側**，但那是右上縱膈輪廓，不是心臟（右心房）的邊界。記憶鉤：**右邊看靜脈與右房，左邊看主動脈與左心。**

## Summary
- **右側心緣／縱膈輪廓（由上而下）**：右氣管旁條紋（right paratracheal stripe，見於約 2/3 正常片，由右頭臂靜脈＋SVC 構成）→ 奇靜脈弓（azygos arch）→（年長者升主動脈可投影至 SVC 右側）→ **上腔靜脈（SVC）→ 右心房（RA）→ 下腔靜脈（IVC）**。[^1]
- **左側心緣／縱膈輪廓（由上而下）**：左氣管旁條紋（左總頸動脈、左鎖骨下動脈、左頸靜脈）→ **主動脈弓／主動脈結（aortic knob）± aortic nipple（左上肋間靜脈）→ 肺動脈幹（pulmonary trunk）→ 左心耳（left atrial appendage）→ 左心室（LV）**。[^1]
- **關鍵對比**：右心緣＝**靜脈系（SVC/IVC）＋右心房**；左心緣＝**主動脈（結）＋肺動脈幹＋左心耳＋左心室**。主動脈屬左緣，不構成右心房緣。[^1]
- **「moguls of the heart」（左緣三丘）**：左緣由上而下的凸起——第一丘＝主動脈結、第二丘＝肺動脈幹、第三丘＝左心耳；第三丘異常膨出（third mogul sign）提示左心房擴大。[^1]
- **臨床用途**：熟悉正常輪廓才能辨識膨出（如左心房擴大、肺動脈段突出）或邊界消失（silhouette sign 定位病灶所在肺葉），以及縱膈增寬等異常。[^1][^2]

## 影像診斷
### 正面（PA/AP）胸片
右緣由上而下：right paratracheal stripe（右頭臂靜脈＋SVC）、azygos arch、SVC、**右心房**、IVC（心膈角處）；年長者升主動脈迂曲可投影至 SVC 右側（右上縱膈，非右心房緣）。左緣由上而下：主動脈結、肺動脈幹、左心耳、左心室。[^1]

### 側面（lateral）胸片
前緣（由上而下）：上縱膈（大血管、胸腺）、升主動脈、右心室流出道／右心室；後緣：左心房（上）、左心室（下）與 IVC。側位有助判斷心室擴大方向與胸骨後透亮區。[^1]

### CT 對照
胸片上的「線與條紋」皆有其解剖基礎（right paratracheal stripe、azygoesophageal recess、anterior/posterior junction line 等）；辨識某條線／條紋移位可在進一步 CT 前先建立鑑別診斷。[^2]

## 鑑別與報告要點
| 輪廓段 | 構成構造 | 異常意義 |
|---|---|---|
| 右緣上段 | right paratracheal stripe（右頭臂靜脈＋SVC）、azygos arch、SVC | 增寬→縱膈病灶；azygos 增大→體液過多/奇靜脈連續 IVC 中斷 [^1][^2] |
| 右緣下段 | **右心房**、IVC（心膈角） | 膨出→右心房擴大 [^1] |
| 左緣（moguls） | 主動脈結 → 肺動脈幹 → 左心耳 → 左心室 | 肺動脈段突出→肺高壓/左至右分流；第三丘膨出→左心房擴大 [^1] |
| 主動脈 | 屬**左緣**主動脈結（右側僅年長者升主動脈迂曲投影） | **不構成右心房緣**——本題陷阱 [^1] |

## 題目
> [!question]- Right border of the heart in a chest X-ray, is not formed by? (2021-329)
> **D（Aorta）**——正面胸片右心緣由上而下由 **SVC（B）→ 右心房（C）→ IVC（A，位於心膈角）** 構成，屬靜脈系＋右心房。主動脈（結）構成的是**左緣**，不形成右心房緣；僅在年長者因升主動脈迂曲（unfolding）投影到 SVC 右側，且那屬右上縱膈輪廓而非心臟邊界。故「不構成右心緣」者為 D 主動脈。[^1]
