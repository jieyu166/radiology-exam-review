# forearm-fracture-dislocation-eponyms

**前臂骨折脫位口訣「近端 Monteggia、遠端 Galeazzi、頭端 Essex-Lopresti」：Monteggia＝尺骨近端骨折 + 橈骨頭脫位；Galeazzi＝橈骨遠端骨折 + 遠端橈尺關節（DRUJ）脫位；Essex-Lopresti＝橈骨頭骨折 + DRUJ 脫位 +『骨間膜（interosseous membrane）破裂』（縱向前臂不穩定）。** 判讀分水嶺：**Essex-Lopresti 與 Galeazzi 都有 DRUJ 脫位，差別在骨折部位（橈骨頭 vs 橈骨遠端）＋ Essex-Lopresti 多了骨間膜斷裂 → 是縱向不穩定，DRUJ 傷易被漏診。記憶：MUGR（Monteggia-Ulna、Galeazzi-Radius）。**

## Summary
- **Monteggia fracture**：**尺骨近 1/3 骨折 + 橈骨頭脫位**（近端橈尺關節 PRUJ）。[^1]
- **Galeazzi fracture**：**橈骨遠 1/3 骨折 + 遠端橈尺關節（DRUJ）脫位**。[^1]
- **Essex-Lopresti fracture**：**橈骨頭骨折 + DRUJ 脫位 + 前臂骨間膜（interosseous membrane）破裂**——與 Galeazzi 差在骨折部位為橈骨頭、且伴骨間膜斷裂之**縱向不穩定**。[^1][^2]
- **Colles fracture**：**橈骨遠端約一吋處之橫向關節外骨折**，遠端骨片連同腕骨與手部**向背側移位**（dinner-fork/餐叉畸形）。[^3]

## 放射科醫師影像判讀重點
- **看骨折就找對側關節**：橈骨/尺骨單一骨折時，務必檢查兩端橈尺關節（PRUJ/DRUJ）——單一前臂骨骨折 + 明顯短縮/成角，常暗示另一端脫位。[^1]
- **Essex-Lopresti 陷阱**：橈骨頭骨折時易只顧肘部，**DRUJ 脫位/骨間膜斷裂常被漏診** → 造成長期腕痛、僵硬、不穩、radiocapitellar 撞擊致外側肘痛。[^2]
- **Monteggia vs Galeazzi**：MUGR——**M**onteggia＝**U**lna（近端）；**G**aleazzi＝**R**adius（遠端）。[^1]
- **Colles vs Smith**：Colles＝背側移位（餐叉）；Smith（反 Colles）＝掌側移位（花園鏟）。[^3]
- **機轉**：Essex-Lopresti 為軸向壓縮力沿前臂（PRUJ→骨間膜→DRUJ）傳導，肘伸直高能量墜落所致。[^2]

## 臨床重點（5 句）
1. **三症候群定位**：近端 Monteggia、遠端 Galeazzi、橈骨頭 Essex-Lopresti。[^1]
2. **Essex-Lopresti 關鍵**：橈骨頭骨折 + DRUJ 脫位 + 骨間膜破裂＝縱向不穩定。[^1][^2]
3. **勿漏對側關節**：單骨骨折要查另一端橈尺關節。[^1]
4. **Colles**：橈骨遠端關節外橫骨折 + 背側移位（餐叉畸形）。[^3]
5. **臨床後果**：Essex-Lopresti DRUJ 漏診致慢性腕痛/不穩。[^2]

> [!note] 考點：橈骨頭骨折合併遠端橈尺關節脫位稱為？
> **Essex-Lopresti fracture（C）**——橈骨頭骨折（非橈骨遠端）+ DRUJ 脫位（+ 骨間膜破裂）。Monteggia＝尺骨近端骨折 + 橈骨頭脫位；Galeazzi＝橈骨遠端骨折 + DRUJ 脫位。[^1][^2]

## 題目
> [!question]- The combination of radial head fracture and dislocation of distal radio-ulnar joint is called? (2020-293)
> **Essex-Lopresti fracture（C）**——橈骨頭骨折 + DRUJ 脫位（+ 骨間膜破裂）。Monteggia＝尺骨近端骨折 + 橈骨頭脫位；Galeazzi＝橈骨遠端骨折 + DRUJ 脫位。[^1][^2]

> [!question]- Which statement is true as following? (2020-367)
> **Monteggia/Galeazzi/Colles 三者描述皆正確（D）**——Monteggia＝尺骨近端骨折 + 橈骨頭脫位；Galeazzi＝橈骨遠端骨折 + DRUJ 脫位；Colles＝橈骨遠端一吋處橫向關節外骨折 + 遠端骨片向背側移位。[^1][^3]
