# male-breast-cancer

**男性乳癌預後與『同齡同分期』女性相近——並非較好;但男性常較晚期診斷（症狀少報），平均診斷年齡 60-64 歲、晚於女性;典型呈乳暈下無鈣化腫塊。** 判讀分水嶺：**Klinefelter 症候群增加風險;乳房攝影／US 見偏心於乳暈下的不規則腫塊,常被同時存在的男性女乳症（gynecomastia）遮蔽;鈣化較女性乳癌少且較粗;預後等同同齡同期女性,延遲診斷才是存活差異主因。**

## Summary
- **預後**：與**同齡、同分期女性相近**（非較好）;男性常**較晚期診斷**（較少回報症狀 → 延誤）。[^1]
- **危險因子**：**Klinefelter 症候群**增加乳癌風險;BRCA2、家族史、雌激素過多。[^1]
- **流行病學**：**佔所有乳癌僅 ~0.5–1%、男性惡性腫瘤 <0.25%**;平均診斷年齡約 **60–70 歲、晚於女性**;組織學絕大多為 IDC/DCIS，**invasive lobular carcinoma 極罕見（男性正常乳房無小葉/腺泡）**。[^1][^2]
- **影像**：典型**乳暈下（subareolar）無鈣化腫塊**,常圓／卵圓／分葉,可被併存的 **gynecomastia 遮蔽**;鈣化較女性乳癌**少且較粗**。[^1]

## 放射科醫師影像判讀重點
- **最佳診斷線索（STATdx）**：**乳暈下/中央、略偏心於乳頭之不規則分葉腫塊、界不清**；較少為卵圓/圓形界清（US 可 complex cystic-solid）；**mass 見於 80-90%、鈣化 13-31%**（較女性少、較粗大圓、多在腫塊內）。[^3]
- **與 gynecomastia 區分（STATdx，關鍵）**：**癌偏離乳頭、凸緣；gynecomastia 以乳頭為中心、向周邊漸尖**；**gynecomastia 可併存並遮蔽癌**——臨床/乳攝不能明確歸因 gynecomastia 時 US 為必要。[^3]
- **US（STATdx）**：不規則分葉凸緣低回音、界不清/角狀、後方陰影或增強；**complex cystic-solid 想 papillary DCIS/EPC/myofibroblastoma**；評估腋淋巴結（無 fatty hilum/皮質不對稱增厚可疑）。[^3]
- **MR（STATdx）**：一般不需，除非疑胸壁侵犯；C+ 快速強化 + washout 令人擔憂。[^3]
- **檢查技巧（STATdx）**：CC + MLO 起始、**reverse CC（由下）可納入更多男性乳房組織**、必要時放大/spot/tangential。[^3]
- **DDx（STATdx）**：**gynecomastia（火焰狀）、fat necrosis（rim 鈣化/oil cyst/外傷史）、乳外轉移（攝護腺最常、黑色素瘤/肺/淋巴瘤）、myofibroblastoma、granular cell tumor、lipoma/angiolipoma、膿瘍**。[^3]

## 臨床重點（5 句）
1. **流行病學（STATdx）**：**佔美國乳癌 0.2-0.9%、男性癌 <1%**；**平均診斷 65 歲（晚於女性 60）、平均大小 2.0-3.5 cm（大於女性）**；非裔/Ashkenazi 猶太裔較多。[^3]
2. **病理/分子（STATdx）**：**87% IDC-NST、ILC 極罕（男性乳房無 lobule）**；**ER(+) 92%、HER2(+) 12%、triple-negative 5%（較女性更常 ER+、較少 HER2+/TN）**；伴 DCIS 35-50%（多高惡度）、EPC 過度代表。[^3]
3. **遺傳（STATdx）**：**BRCA2 突變 ~6%（最強遺傳關聯，帶因者 70 歲前 7% 罹乳癌）、Klinefelter RR 50 倍**；BRCA1/CHEK2/PALB2/PTEN/TP53 較少；家族史（乳/攝護腺癌）增風險。[^3]
4. **危險因子（STATdx）**：年齡、**雌激素相對睪固酮增加**（睪丸疾病/orchiectomy/mumps orchitis、攝護腺癌 Lupron、跨性別 >10 年高劑量荷爾蒙、肥胖、過量飲酒、頭部外傷致 prolactin↑）。[^3]
5. **預後/治療（STATdx）**：**同分期預後與女性相近，但男性較晚期呈現→整體預後較差**；轉移骨/肺>肝、5-15% 第二原發癌；治療（改良型根治性乳房切除 > BCT、前哨淋巴結、ER+ 用 tamoxifen/AI）；**BRCA2 帶因男性 35 歲起自我檢查、對側乳房每年乳攝**。[^3]

> [!note] 考點：關於男性乳癌,何者「為偽（false）」?
> 「**整體預後比女性好**」為偽——男性乳癌預後與**同齡同分期女性相近**,且常較晚期診斷。Klinefelter 增加風險、平均 60-64 歲(晚於女性)、乳暈下無鈣化腫塊皆正確。[^1]

## 題目
> [!question]- 關於 male breast cancer,何者「為偽」? (2017-177)
> 「**整體預後比女性好**」為偽——預後與**同齡同分期女性相近**,且男性常較晚期診斷。Klinefelter 增加風險、平均 60-64 歲晚於女性、乳暈下無鈣化腫塊皆正確。[^1]

> [!question]- Which description about male breast cancer is correct? (2022-252)
> D「以上皆是」——gynecomastia 會遮蔽腫塊致偵測困難，斷層合成較 2D 更能區分纖維腺體與腫塊並顯示不規則毛刺緣，三者皆正確。[^3]
