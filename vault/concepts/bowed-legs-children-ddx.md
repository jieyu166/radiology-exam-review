# bowed-legs-children-ddx

**兒童弓形腿（bowed legs/genu varum）最常見病因是『生理性（physiologic）』——開始走路後的正常發育性內翻，2-3 歲自然轉外翻、6-7 歲恢復成人型態；其餘病理性病因含佝僂病（rickets）與 Blount disease（脛骨近端內側幹骺端-骨骺 Drennan 角 >11°），但『肌肉無力（muscular weakness）』本身並非常見病因。** 判讀分水嶺：**physiologic：雙側對稱、2-3 歲轉外翻、6-7 歲成人型；Blount＝medial proximal tibia 生長障礙、metaphyseal-diaphyseal(Drennan)角 >11°（生理性 <11°）、內側乾骺端 beak；NF1＝脛骨前外側弓形 + 腓骨發育不全；rickets/scurvy/syphilis(saber shin) 亦是。**

## Summary
- **生理性弓形（最常見）**：開始走路後正常發育；**雙側對稱、2-3 歲轉外翻、6-7 歲恢復成人型態**。[^1]
- **先天性弓形**：子宮內姿勢異常，脛/腓骨凸向後內側、常伴下肢長度不等。[^1]
- **Rickets（佝僂病）**：維生素 D 缺乏、骨礦化不良（乾骺端杯狀/毛刷狀、physeal 增寬）。[^1]
- **Blount disease（tibia vara）**：**medial proximal tibial physis 生長障礙**；**metaphyseal-diaphyseal（Drennan）角 >11°**（生理性 <11°）、內側乾骺端 beak、內側骨骺楔形/碎裂；infantile（雙側、肥胖/早走）vs adolescent（單側、肥胖）。[^1][^2]
- **其他**：scurvy、**NF1（脛骨前外側弓形 + 腓骨發育不全 → pseudarthrosis）**、syphilis（saber shin）、骨骼發育不良。[^1]
- **關鍵排除——Muscular weakness**：**非**弓形腿常見病因（無骨骼/生長板機轉）。[^1]

## 放射科醫師影像判讀重點
- **physiologic vs Blount**：量 **Drennan 角**——<11° 偏生理性、>11° 偏 Blount（11-16° 灰區需追蹤）。[^2]
- **Blount 徵象**：內側乾骺端 beak + 內側骨骺楔形/碎裂 + 外側皮質仍直。[^2]
- **rickets**：全身乾骺端杯狀/毛刷、physeal 增寬、骨質稀疏——與局部 Blount 區分。[^1]
- **NF1 型**：脛骨前外側弓形 + 腓骨發育不全，勿與生理性混淆（後者對稱、無局部異常）。[^1]
- **追蹤**：生理性隨年齡自癒；病理性（Blount/rickets/NF1）需矯正/治療。[^1][^2]

## 臨床重點（5 句）
1. **最常見**：生理性（2-3 歲轉外翻、6-7 歲成人型）。[^1]
2. **Blount**：Drennan 角 >11°、內側乾骺端 beak。[^1][^2]
3. **rickets**：礦化不良、乾骺端杯狀。[^1]
4. **NF1**：前外側弓形 + 腓骨發育不全。[^1]
5. **非病因**：muscular weakness。[^1]

> [!note] 考點：何者「不是」兒童弓形腿的常見病因?
> **Muscular weakness（C）**——肌肉無力並非弓形腿的常見病因機轉。Physiologic（A，最常見）、Rickets（B）、Blount disease（D，脛骨幹骺端-骨骺角 >11°）皆為常見/重要病因。[^1][^2]

### 參考來源

## 題目
> [!question]- Which one is not the common cause of bowed legs in children? (2017-338)
> **Muscular weakness（C）**——並非弓形腿的常見病因機轉。Physiologic（最常見）、Rickets、Blount disease（脛骨幹骺端-骨骺角 >11°）皆為常見/重要病因。[^1][^2]
