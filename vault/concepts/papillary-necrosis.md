# papillary-necrosis

**腎乳頭壞死病因口訣「NSAID」：NSAIDs/Sickle cell/Analgesic nephropathy/Infection/Diabetes（另加 obstruction、RVT）。** 平片通常正常，鐮型球患者約 50%（非 90%）發生；兩型：medullary＝乳頭中央空蝕（lobster-claw）；papillary/total＝整顆乳頭脫落（signet ring + clubbed calyx）。判讀分水嶺一：**三大陷阱——平片非特徵鈣化、sickle cell 50% 非 90%、medullary 型是中央侵蝕非整顆缺失**；判讀分水嶺二：**papillary/total 型脫落乳頭可成 collecting system 填充缺損致阻塞**。

## Summary
- **病因（NSAID 記憶法）**：**N**SAIDs、**S**ickle cell anemia、**A**nalgesic nephropathy、**I**nfection（pyelonephritis、TB）、**D**iabetes mellitus；另 urinary obstruction、renal vein thrombosis。故「analgesics、DM、sickle cell」**正確**（2016-198 正解 A）。[^1]
- **平片**：**通常正常**；壞死乳頭可周邊鈣化（脫落但滯留者呈環狀鈣化）、鈣化約 2–6 mm，但非「特徵性鈣化」→ 故「平片常顯特徵性鈣化」**錯誤**（B 錯）。[^1][^2]
- **鐮型球（sickle cell）**：約 **up to 50%** 發生乳頭壞死（非 90%）→ C 錯。[^2]
- **兩型**：[^1][^2]
  - **Medullary（partial / in situ）型**：乳頭**中央空蝕**（central erosion / lobster-claw forniceal excavation），乳頭**未整顆脫落** → 故「medullary 型＝整個乳頭缺失」**錯誤**（D 錯）。
  - **Papillary（total）型**：**整顆乳頭脫落**，呈 **signet ring + clubbed calyx**；脫落乳頭成 collecting system/輸尿管 filling defect、可致阻塞。
- 機轉：髓質/乳頭因高滲、低灌流缺血壞死。[^1]

## 放射科醫師影像判讀重點
- **機轉（Jung）**：**腎髓質與乳頭因其血供排列特殊＋高滲環境，特別易缺血壞死**——故 papillary necrosis 是「描述性名詞」而非單一病理實體，多種病因共通此路徑。[^3]
- **CT 核心徵（Jung，優於 IVU）**：**對比劑填充之髓質裂隙（clefts）、被排泄對比劑環圍繞之不強化病灶、髓質高衰減鈣化**——CECT 較 IVU/US 更完整顯示全譜徵象、可早期偵測（可逆期）。[^3]
- **兩型辨識（考點）**：**medullary（partial/in situ）型＝乳頭中央空蝕（lobster-claw forniceal excavation）、乳頭未整顆脫落；papillary（total）型＝整顆乳頭脫落（signet ring＋clubbed calyx）**——後者脫落乳頭成 filling defect。[^1][^2]
- **脫落併發症（Jung）**：**乳頭脫落→腎盂/輸尿管填充缺損＋可含鈣化→水腎/阻塞**；癒合期乳頭尖端變鈍、腎臟萎縮為常見後遺。[^3]
- **平片陷阱（考點）**：**平片通常正常**（壞死時偶見不規則鈣化 2–6 mm 或滯留乳頭環狀鈣化），非「特徵性鈣化」。[^2][^3]

## 臨床重點（5 句）
1. **病因記憶（NSAID）**：**N**SAIDs、**S**ickle cell、**A**nalgesic nephropathy、**I**nfection（腎盂腎炎/TB）、**D**iabetes；另加 obstruction、renal vein thrombosis。[^1][^3]
2. **鐮型球比例（考點）**：**約 up to 50%** 鐮型球病患發生乳頭壞死（非 90%）。[^2]
3. **臨床表現**：血尿、脅腹痛（脫落乳頭致絞痛/阻塞）、反覆感染；部分無症狀偶然發現。[^3]
4. **早期可逆（Jung）**：**早期辨識、去除病因（停止止痛藥、控糖、治療感染）可逆轉缺血過程**——故熟悉 CT 徵象具治療意義。[^3]
5. **後遺**：反覆發作致腎乳頭多發缺損、腎功能下降與腎萎縮；脫落乳頭偶為輸尿管結石核心。[^3]

> [!note] 考點：關於 papillary necrosis 何者「為真」?
> 「病因為 analgesics、DM、sickle cell」**為真**（NSAID 記憶法）。平片常顯特徵鈣化（錯，多正常）、90% sickle cell 發生（錯，約50%）、medullary 型＝整個乳頭缺失（錯，medullary 為中央侵蝕）皆假。[^1][^2]
