# iatrogenic-femoral-pseudoaneurysm

**穿刺／導管術後最常見的血管併發症之一：血液自穿刺點滲出、被外膜與周邊軟組織包住形成只有 adventitia 為壁的假性動脈瘤（IPA）。動脈導管術是「醫源性」假性動脈瘤最常見成因,好發共同股動脈。** 判讀分水嶺：**都卜勒 yin-yang（陰陽）血流＋頸部 to-and-fro（來回）波形＝假性動脈瘤;治療取捨看『有無併發症＋大小』——無併發症小者可觀察、無併發症較大者首選 US-guided thrombin injection（成功率 >90%）,有併發症者才走開刀。切勿把『>3cm 無併發症』直接送開刀。**

## Summary
- **本質**：假性動脈瘤（false aneurysm）＝動脈壁連續性中斷,血液外漏但被**僅存的外膜（tunica adventitia）或周邊軟組織**包裹;與真性動脈瘤（三層皆完整）不同,破裂風險較同尺寸真性動脈瘤高、故通常需處置。[^1]
- **成因分層**：外傷、發炎（胰臟炎/感染）、腫瘤侵蝕、血管炎皆可;**醫源性中以動脈導管術（arterial catheterization）最常見**,其次為切片、手術;**共同股動脈為導管路徑相關假性動脈瘤的常見部位**。[^1][^2]
- **發生率與風險因子**：穿刺點形成假性動脈瘤在**診斷性血管術約低至 1%**,**治療性（介入）術上升至 3.2%–7.7%**;風險隨**大口徑鞘（large-bore sheath）、術中/術後抗凝與抗血小板治療**增加,其他報導的風險因子含女性、高齡、合併靜脈穿刺、高血壓、嚴重鈣化血管。[^2]
- **自然史**：小者可能自發血栓化,但**目前無法可靠預測哪些會自行栓塞**;未處置者可能感染、壓迫神經血管、致深部靜脈血栓/栓塞或破裂出血。[^2]
- **治療階梯（依部位、破裂風險、臨床情境與共病量身訂做）**：**觀察**（小且無症狀者）→ **US-guided compression** → **US-guided percutaneous thrombin injection（首選微創,成功率 >90%,注射量約 0.5–1.0 mL）** → **開放手術修補（open surgical repair）／血管內治療（栓塞、覆膜支架）**;**開刀主要保留給有併發症或微創失敗者**。[^2]

## 影像診斷

### 超音波（首選診斷與導引工具）
- **灰階**：動脈旁無回音／混合回音囊袋,可見與母動脈相通的「頸部（neck）」。[^1]
- **彩色都卜勒——yin-yang sign**：囊內湍流呈紅藍各半的「陰陽」漩渦樣血流,為假性動脈瘤特徵。[^1]
- **脈衝都卜勒——to-and-fro sign**：於頸部取樣可見收縮期進、舒張期出的「來回」波形,反映血流在囊袋與母動脈間往返。[^1]
- **US 亦為治療平台**：導引壓迫與 thrombin 注射皆在 US 下進行;注射時 thrombin 打入囊袋直到血流停止（通常數秒內）。[^2]

### CT 血管攝影 / MRA
- **CTA**：動脈旁平滑壁囊袋,**非增強呈低衰減、增強期呈與母動脈同步的高衰減**,可見交通頸部;對近端肢體假性動脈瘤敏感度/特異度高。[^1][^2]
- **用途**：評估位置、頸部、周邊血腫與相鄰結構,規劃介入或手術;US 顯示不佳（肥胖、深部、腸氣干擾）時尤有用。[^2]

## 鑑別與報告要點

| 項目 | 重點 | 來源 |
|---|---|---|
| 與真性動脈瘤區別 | 假性只有外膜/軟組織為壁,破裂風險較高、多需治療 | [^1] |
| 診斷徵象 | yin-yang（彩都）＋to-and-fro（脈衝）＋交通頸部 | [^1] |
| 最常見醫源成因 | 動脈導管術（＞切片、手術） | [^1][^2] |
| 風險因子 | 大口徑鞘、抗凝/抗血小板;女性、高齡、合併靜脈穿刺、高血壓、鈣化血管 | [^2] |
| 治療首選（無併發症、非小） | **US-guided thrombin injection（>90% 成功）**,非開刀 | [^2] |
| 開刀適應症 | 有併發症（血流動力不穩、神經/脈搏缺損、擴大血腫、廣泛皮膚軟組織受損、疑感染）或微創失敗 | [^2] |
| 報告需含 | 大小、頸部、與母動脈關係、周邊血腫、有無壓迫/破裂徵象 | [^2] |

## 題目
> [!question]- 關於經皮介入後之股動脈假性動脈瘤（IPA），下列敘述何者「錯誤」？ (2021-174)
> **D（無併發症、>3cm 者「開放手術優於 US 導引 thrombin 注射」）為錯誤**——無併發症之較大 IPA **首選 US-guided percutaneous thrombin injection（成功率 >90%）**,開刀主要保留給有併發症（血流動力不穩、神經/脈搏缺損、擴大血腫、廣泛軟組織受損、疑感染）或微創失敗者。A（發生率 <1% 之診斷性介入）大致正確、B（風險因子含肥胖、鞘徑 >6 Fr 等大口徑鞘）正確、C（無併發症小 IPA 序列 US 觀察）為可接受的保守處置,皆非最錯者。[^1][^2]
