# cerebral-microbleeds

**T2\* GRE/SWI 上多發低訊號焦點（cerebral microbleeds）的常見病因四大類：cavernous malformations（Zabramski type IV）、慢性高血壓性腦病變、cerebral amyloid angiopathy（CAA）、diffuse axonal injury（DAI）——神經纖維瘤病第一型（NF1）不在此清單（NF1 為 T2/FLAIR 高訊號 UBOs，非微出血）。** 判讀分水嶺：**用「分佈」定因——lobar/皮質-皮質下、spares 基底核＝CAA（老人）；深部（基底核/視丘/腦幹/小腦/放射冠）＝慢性高血壓；灰白質交界 + 胼胝體壓部 + 背外側腦幹＝DAI（外傷）。**

## Summary
- **本質**：小灶慢性腦內出血（hemosiderin），常僅在**磁化率序列（T2\* GRE、SWI）**上以低訊號 blooming 呈現。[^1][^2]
- **常見病因（分佈導向）**：[^1][^2]
  - **CAA**：**皮質-皮質下交界（lobar）**、**通常 spares 基底核**（老人、lobar 出血）。
  - **慢性高血壓性腦病變**：**基底核、視丘、腦幹、小腦、放射冠（深部）**。
  - **DAI/DVI（外傷）**：**灰白質交界、胼胝體壓部、背外側腦幹**。
  - **Cavernous malformation（Zabramski type IV）**：隱匿性海綿狀血管瘤之「黑點」。
- **少見病因**：出血性微轉移（黑色素瘤/腎細胞癌/甲狀腺/絨毛膜癌）、CADASIL、放射誘發血管病變、腦血管炎、ARIA-H（抗類澱粉治療相關）、血栓性微血管病、顱內栓塞（脂肪/氣體/敗血）、COL4A1/2 小血管病。[^2]
- **非典型病因**：**NF1 不屬於**——NF1 腦部為 **T2/FLAIR 高訊號 UBOs**，非 T2\* 多發低訊號微出血。[^1]

## 放射科醫師影像判讀重點
- **序列**：**SWI 最敏感**（＞T2\* GRE），blooming 會放大微出血、也可能高估數目/大小。[^2]
- **分佈定因（核心）**：**lobar→CAA**、**深部→高血壓**、**灰白交界+胼胝體壓部+背外側腦幹→DAI**——這是床邊快速鑑別。[^2]
- **CAA vs 高血壓**：CAA spares 基底核（老人、可合併 lobar ICH、皮質表面 siderosis）；高血壓則深部為主（合併腔隙梗塞、白質病變）。[^2]
- **鈣化鑑別**：SWI 相位圖可分辨鈣化（反磁）與血產物（順磁）——見 [[gre-hemorrhage-detection]]。
- **陷阱**：對稱基底核鈣化、海綿竇/靜脈流空、氣骨界面偽影勿誤判為微出血。[^2]

## 臨床重點（5 句）
1. **只在 SWI/GRE 現形**：一般序列看不到，須用磁化率序列偵測。[^2]
2. **分佈定因**：lobar→CAA、深部→高血壓、灰白交界→DAI。[^2]
3. **臨床意義**：微出血數目/分佈影響抗凝/溶栓風險評估與認知退化預測。[^2]
4. **NF1 非病因**：NF1 為 UBOs（T2/FLAIR 高訊號），非微出血。[^1]
5. **少見但要記**：出血性微轉移、CADASIL、放射/血管炎、ARIA-H。[^2]

> [!note] 考點：何者「非」T2* GRE多發低訊號焦點之病因?
> **Neurofibromatosis type I（C）**——非典型病因（NF1 為 T2/FLAIR 高訊號 UBOs）。Cavernous malformations（Zabramski IV）、diffuse axonal injury、cerebral amyloid angiopathy 皆為常見病因。[^1][^2]

### 參考來源

[^2]: Gaillard F, et al. *Cerebral microbleed*. Radiopaedia, rID-4560, DOI 10.53347/rID-4560——**分佈導向鑑別：CAA＝皮質-皮質下交界、spares 基底核；慢性高血壓＝基底核/視丘/腦幹/小腦/放射冠；DAI/DVI＝灰白質交界、胼胝體壓部、背外側腦幹**；其他（CADASIL、放射血管病變、血管炎、出血性微轉移、ARIA-H）；SWI 最敏感。
