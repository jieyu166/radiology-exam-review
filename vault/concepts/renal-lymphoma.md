# renal-lymphoma

**腎淋巴瘤多為續發（系統性 NHL 浸潤，原發罕見 <1%）、腎臟為淋巴瘤最常侵犯之腹部器官；典型『多發雙側乏血管腫塊』。可侵犯腎竇酷似 urothelial carcinoma；瀰漫浸潤致腎腫大 + 不均強化 + 急性腎衰；單發腫塊（>20%）常難與 RCC 區分。** 判讀分水嶺：**最常見＝多發實質腫塊（雙側、乏血管、均質、輕度強化，<60%）；腎竇浸潤酷似移行細胞癌；瀰漫浸潤＝腎腫大 + 輪廓破壞 + 不均強化；後腹腔淋巴瘤『包繞腎血管/輸尿管而不阻塞』為旁證。**

## Summary
- **本質**：多為**續發（系統性 B 細胞 NHL）**；**原發腎淋巴瘤罕見（<1%）**；**腎臟為淋巴瘤最常侵犯之腹部器官**。[^1][^2]
- **多發實質腫塊（最常見）**：**<60%**、**多雙側**、乏血管、均質、輕度強化。[^1][^2]
- **單發腫塊型**：**>20%**，**常難與 RCC 區分**（非容易）。[^1][^2]
- **腎竇浸潤型**：可優先侵犯腎竇，**酷似 urothelial（移行細胞）carcinoma**。[^1]
- **瀰漫浸潤型**：瀰漫浸潤致**腎腫大 + 輪廓破壞 + 不均強化 + 急性腎衰**（非均質強化）。[^1][^2]
- **旁證**：後腹腔淋巴瘤常**包繞腎血管/輸尿管而不阻塞**（軟、可塑）；**後腹腔淋巴結腫大 ≥50%**；flank pain 最常見症狀。[^2]

## 放射科醫師影像判讀重點
- **乏血管均質**：多發腫塊乏血管、均質、輕度強化，異於富血管 RCC。[^1][^2]
- **腎竇型 vs TCC**：腎竇軟組織浸潤似 urothelial ca，但淋巴瘤包繞不阻塞、常伴他處淋巴瘤。[^1]
- **瀰漫型 + AKI**：腎瀰漫增大 + 不均強化 + 腎功能惡化 → 想淋巴瘤浸潤。[^2]
- **contiguous 型**：後腹腔病灶延伸包繞腎血管/輸尿管而不阻塞為特徵旁證。[^2]
- **鑑別**：單發型難與 RCC 分（需切片/PET/系統評估）。[^1][^2]

## 臨床重點（5 句）
1. **續發 NHL**、腎為最常侵犯腹部器官、原發罕見。[^1][^2]
2. **多發雙側乏血管腫塊**（最常見）。[^1][^2]
3. **腎竇型**酷似 urothelial ca。[^1]
4. **瀰漫型**：腎腫大 + 不均強化 + AKI。[^1][^2]
5. **旁證**：包繞血管不阻塞、後腹腔淋巴結。[^2]

> [!note] 考點：關於腎及腎周淋巴瘤侵犯型態，何者「正確」?
> 「**淋巴瘤可優先侵犯腎竇，酷似 urothelial carcinoma**」正確。最常見多發腫塊型為雙側（非單側）、單發腫塊難與 RCC 區分（非容易）、瀰漫浸潤多為不均強化（非均質）。[^1][^2]
