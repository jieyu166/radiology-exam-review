# pericardial-calcification

**心包鈣化＝「發炎/出血後留下的鈣」——凡能造成心包炎或心包積血的病因都可能導致鈣化，反之非發炎性的肌炎（dermatomyositis）不在其列。** 記憶主軸：感染性心包炎（尤其結核，鈣化最厚最典型）、外傷/術後或抗凝血造成的心包積血、放射治療、尿毒症、膠原血管病、風濕性心臟病後遺、腫瘤侵犯、idiopathic。判讀分水嶺：**心包鈣化本身不等於縮窄性心包炎**——須合併縮窄/限制的生理表現才有診斷意義；CT 是偵測鈣化最敏感的模態。

## Summary

### 病因（凡致心包發炎或積血者皆可）
- **感染性心包炎**：結核、黴菌、病毒、化膿性（pyogenic）。**結核性鈣化最厚、最顯著**，呈厚而不定形的斜位環或弧狀。[^1]
- **外傷 / 心包積血（hemopericardium）**：鈍傷、心臟手術後，以及**抗凝血治療致出血後鈣化**（本題選項 C 的機轉）。[^1][^2]
- **放射治療（縱膈照射）**：本題選項 A；亦為現代縮窄性心包炎最常見成因之一。[^1][^2]
- **尿毒症（uremic pericarditis）**。[^1]
- **膠原血管病 / 結締組織病**：SLE、RA、scleroderma。[^1][^2]
- **風濕性心臟病後遺**。[^1]
- **腫瘤侵犯**：肺癌、乳癌、縱膈淋巴瘤等致心包發炎。[^1]
- **鈣化性心包腫塊或囊腫**、**idiopathic（有時查無成因）**。[^1]
- **methysergide** 治療所致縮窄性心包炎屬罕見「案例報告」層級（本題選項 B）。⚠️ 此點見於官方詳解，未在 Radiopaedia/RadioGraphics 正文查得，僅屬個案文獻。
- **不造成心包鈣化**：dermatomyositis（皮肌炎）——其鈣化（calcinosis）以皮下/肌肉軟組織為主，非心包（本題正解 E）。⚠️ 此為排除性事實，合格出處未正面列出「dermatomyositis 不致心包鈣化」，係由病因清單不含之推論。

### 影像特徵
- **胸片（plain film）**：沿心緣的**曲線狀（curvilinear）鈣化**（側位片較清楚），可延伸至肺動脈流出道；因左心房被心包包覆較少，可見相對左房擴大。[^1]
- **CT**：**多切面 CT 是偵測心包鈣化最敏感的模態**；曲線狀或結節狀緻密鈣化沿心包分布；心包增厚 >4 mm 合併鈣化支持縮窄性心包炎；gated CT 可評估心室相互依賴與 septal bounce。[^1][^2]
- **好發位置**：右側、前方、橫膈面周圍較多。[^1]

### 臨床意義
- 心包鈣化常與**縮窄性心包炎**相關，但**鈣化或增厚本身皆非縮窄的診斷依據**，須合併縮窄/限制生理表現才有意義。[^2]
- 縮窄性心包炎的**現代最常見成因為心臟手術與放射治療**，其次為感染（病毒/結核）、結締組織病、尿毒症、腫瘤或 idiopathic。[^2]
- 治療：心包切除術（pericardiectomy）可能治癒。[^1]

## 影像診斷

### X 光
- 心緣曲線狀鈣化，側位片辨識度較佳；可延伸至肺動脈流出道。[^1]

### CT
- 首選且最敏感；曲線/結節狀緻密鈣化，右側前方橫膈面為主；增厚 >4 mm＋鈣化＋臨床縮窄 → 高度提示縮窄性心包炎。[^1][^2]

### MRI
- 鈣化在 MRI 呈低訊號、不如 CT 敏感；優勢在於評估心包增厚之發炎（gadolinium 增強）與縮窄之心臟形態變化（右室管狀狹小、septal bounce）。[^2]

## 鑑別與報告要點

| 項目 | 重點 |
|---|---|
| 最敏感偵測模態 | CT（多切面）[^1] |
| 最厚/最典型鈣化成因 | 結核性心包炎 [^1] |
| 縮窄現代最常見成因 | 心臟手術、放射治療 [^2] |
| 鈣化 vs 縮窄 | 鈣化≠縮窄，須合併生理表現 [^2] |
| 主要鑑別 | 限制型心肌病、心肌鈣化（多左側/心尖、局部）[^1] |

## 題目

> [!question]- Pericardial calcification is caused by all **except**? (2021-038)
> **E（Dermatomyositis 不造成心包鈣化）**——心包鈣化源於心包發炎或積血後的鈣沉積：A 放射治療、C 抗凝血致心包積血後鈣化、D 良性（含感染性）心包炎皆為公認成因；B methysergide 屬罕見縮窄性心包炎的案例報告層級但仍屬「可致」。皮肌炎的鈣化以皮下/肌肉軟組織 calcinosis 為主，不累及心包，故為唯一「except」。
