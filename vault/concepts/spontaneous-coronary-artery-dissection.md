# spontaneous-coronary-artery-dissection

**SCAD 是「非動脈粥樣硬化、非醫源性、非外傷」的心外膜冠狀動脈剝離，好發於年輕至中年女性，是年輕女性與周產期心肌梗塞的重要成因（可造成 ACS 到猝死的全譜表現）。判讀分水嶺：SCAD 最常侵犯「中段至遠段」小口徑血管（proximal 受侵犯 <10%），這與導管攝影/CCTA 的空間解析度限制交織——CCTA 對「近段」較大血管診斷力最佳；而 CCTA 的關鍵優勢正是能非侵入性地評估「血管壁」並直接顯示「壁內血腫(intramural hematoma)」，這是相對於單看管腔的導管攝影的加分點。此外因與 fibromuscular dysplasia(FMD)高度共病，指引建議對所有 SCAD 病患做「腦到骨盆(brain-to-pelvis)」的血管影像篩檢。**

## Summary
- **定義**：SCAD＝心外膜冠狀動脈的**非醫源性**剝離，**與動脈粥樣硬化及外傷無關**（intima 與 media 之間形成假腔／壁內血腫壓迫真腔）。[^1]
- **流行病學**：好發**年輕至中年女性（約 84% 為女性）**；佔冠脈攝影中約 0.1%，平均年齡約 44 歲（另有報告 peak 於 47–53 歲）；為**周產期心肌梗塞最重要成因（約 15–20%）**。[^1][^3]
- **臨床（本題 A 正解依據）**：表現從**急性冠心症(ACS)／心肌梗塞**到**猝死**皆有——**SCAD 確實可造成心肌梗塞**。[^1][^2][^3]
- **好發節段（推翻 C）**：**多數侵犯冠狀動脈的「中段至遠段(mid-to-distal)」**；**僅 <10% 侵犯近段 LAD、迴旋支、右冠或左主幹**。[^3]
- **CCTA 角色與優勢（推翻 D）**：導管冠脈攝影仍為主要診斷工具，但**CCTA 可非侵入性評估「血管壁」並偵測「壁內血腫」**（管腔外壁增厚、新月狀高衰減），為其相對優勢；CCTA 對**近段較大血管**診斷力最佳，遠段小血管受空間解析度限制。[^2][^3]
- **共病與篩檢（推翻 B）**：**FMD 為最常見共病（部分報告高達 86%）**；因腦、頸、腎、髂等血管床常同時受累，**指引建議所有 SCAD 病患接受「腦到骨盆」血管影像篩檢**——故 SCAD 病患**確實受益**於腹部／骨盆 MR/CT 血管攝影。[^1][^3]
- **其他關聯**：懷孕／產後、結締組織疾病（Ehlers-Danlos type IV、Marfan、Loeys-Dietz、pseudoxanthoma elasticum）、SLE、古柯鹼等。[^1]

## 放射科醫師影像判讀重點
- **三種血管攝影型態（Saw/Yip 分型概念）**：SCAD 在冠脈攝影上可呈①型（多重放射線透亮腔、造影劑滯留於管壁）、②型（長段瀰漫性平滑狹窄，最常見）、③型（局灶／管狀狹窄，貌似粥狀硬化）；判讀時對年輕女性「非典型粥狀硬化型」的長平滑狹窄要高度懷疑 SCAD。[^2][^3]
- **CCTA 判讀主軸**：SCAD 的直接徵象是**壁內血腫**——冠狀動脈管壁呈**新月狀／環狀增厚、管腔外高衰減**且**真假腔並存**；CCTA 能直接顯示「血管壁」而非僅顯示管腔，這是相對導管攝影的優勢。務必於多期像評估壁厚與管腔狹窄，並可用於追蹤剝離「癒合(resolution)」。[^2][^3]
- **節段偏好與模態限制的交織**：因 SCAD 好發**中遠段小口徑血管**，這些節段常因空間解析度不足而使 CCTA 敏感度下降；**CCTA 對近段大血管診斷力最佳**，故臨床上 CCTA 較適用於血流動力學穩定、或懷疑近段病灶／導管攝影不確定時。判讀報告勿把「CCTA 較適用近段」誤讀為「SCAD 好發近段」。[^2][^3]
- **系統性血管篩檢（延伸判讀責任）**：辨識出 SCAD 後，放射科應主動建議或執行**腦到骨盆的 CT/MR 血管攝影**尋找 FMD 徵象（string-of-beads、focal stenosis）與動脈瘤／剝離，尤其腎動脈、頸動脈、髂動脈。[^1][^3]
- **DDx 判讀陷阱**：③型 SCAD 貌似局灶粥狀硬化狹窄；需結合病人族群（年輕女性、無傳統危險因子、周產期）與壁內血腫徵象鑑別，避免誤置支架（SCAD 多主張保守治療，介入本身可能延長剝離）。[^2][^3]

## 臨床重點（5 句）
- SCAD 是非動脈粥樣硬化、非醫源性的冠狀動脈剝離，好發年輕至中年女性。[^1]
- 它可造成從 ACS／心肌梗塞到猝死的全譜表現，是周產期心肌梗塞的重要成因。[^1][^3]
- 最常侵犯冠狀動脈的中段至遠段，近段受侵犯者不到 10%。[^3]
- CCTA 可非侵入性評估血管壁並偵測壁內血腫，對近段血管診斷力最佳。[^2][^3]
- 因與 FMD 高度共病，建議所有 SCAD 病患做腦到骨盆的血管影像篩檢。[^1][^3]

## 陷阱
- 「SCAD 最常侵犯 proximal 冠狀動脈」為錯誤——實際上**中遠段最常見，近段 <10%**；勿把「CCTA 較適用近段」與「病灶好發近段」混為一談。[^3]
- 「CCTA 無法評估血管壁、無法偵測壁內血腫」為錯誤——**CCTA 的優勢正是能顯示血管壁與壁內血腫**（相對於僅顯示管腔的導管攝影）。[^2][^3]
- 「SCAD 病患不需要腹部／骨盆 MRA」為錯誤——因高共病 FMD／動脈瘤，**指引建議腦到骨盆血管篩檢**。[^1][^3]

> C 錯：最常侵犯**中段至遠段**，近段受侵犯 <10%。[^3]
