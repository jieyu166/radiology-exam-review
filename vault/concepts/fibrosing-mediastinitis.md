# fibrosing-mediastinitis

**纖維化縱膈炎＝縱膈軟組織的慢性發炎與過度纖維化，壓迫甚至阻塞縱膈結構（上腔靜脈、肺靜脈/動脈、中央氣道、食道），臨床以 SVC 症候群、呼吸道阻塞、咳血/broncholithiasis 表現；好發年輕成人。** 判讀分水嶺一：**病因＝美國最常為組織漿菌病（Histoplasma，多呈局部鈣化型）、結核、結節病、放療、藥物（methysergide），其餘多為 idiopathic（屬 IgG4 相關疾病）；血吸蟲（Schistosoma）不是病因。** 判讀分水嶺二：**局部型（~80%，常鈣化、腫塊狀）vs 瀰漫型（~20%，浸潤性軟組織、常 IgG4 相關）——看『有無鈣化＋是局部腫塊或浸潤縱膈脂肪』分型。**

## Summary
- **本質**：縱膈軟組織**慢性發炎＋過度纖維化**，導致縱膈結構受壓/阻塞。[^1]
- **臨床**：以**上腔靜脈、肺靜脈/動脈、中央氣道或食道之阻塞/壓迫**表現，可有 broncholithiasis；好發**年輕成人**。[^1]
- **病理分型**：**局部型（focal）約 80%**、**瀰漫型（diffuse）約 20%**。[^1]
- **病因（考點）**：**idiopathic（多數，屬 IgG4 相關疾病）；感染＝Histoplasma capsulatum（美國最常見、常局部型）、Mycobacterium tuberculosis；並存胸內惡性腫瘤；sarcoidosis；放射治療；藥物（methysergide）**。[^1]（選項 A sarcoidosis、B TB、C Histoplasma 皆為病因）
- **非病因**：**Schistosoma mansoni（血吸蟲）不是纖維化縱膈炎的病因**。[^1]（選項 D＝正解）
- **關聯**：Riedel 甲狀腺炎、後腹膜纖維化、Behçet（罕）、RA、SLE 等自體免疫。[^1]

## 影像診斷

### X 光（Plain radiograph）
- 可不明顯；表現為**非特異性縱膈增寬**、正常縱膈界線的變形/消失；**縱膈和/或肺門鈣化（約 85%）**，鈣化在局部型較常見。[^1]

### CT（主力）
- 表現多變、依侵犯型態而異，**典型侵犯中縱膈**：
  - **局部型**：縱膈或肺門腫塊，**常伴鈣化**（尤其先前有組織漿菌病者）。[^1]
  - **瀰漫型**：**軟組織密度浸潤、消除正常縱膈脂肪平面、包繞或侵犯鄰近結構**。[^1]
- 其他：**氣管支氣管狹窄、支氣管內鈣化併肺葉/節塌陷、肺實質陰影、胸膜增厚/鈣化、既往肉芽腫（結核或組織漿菌之癒合病灶）、支氣管動脈怒張（因血管受阻）**；肺靜脈-淋巴回流受壓可致**間質性型態與 crazy-paving**。[^1]

### MRI
- 型態與 CT 相似；**T1 多異質但整體與肌肉等訊號、T2 多變（同一病灶內可見高與低訊號）、T1 C+（Gd）異質性強化**。**成熟纖維/鈣化組織之 T2 低訊號**是與腫瘤鑑別的重要線索。[^1]

## 鑑別與報告要點

| 項目 | 內容 | 備註 |
|---|---|---|
| 主要 DDx | 惡性縱膈腫瘤/淋巴瘤、轉移、結節病淋巴結腫 | 纖維化縱膈炎有鈣化＋成熟纖維 T2 低訊號、慢性、常伴 SVC/氣道慢性阻塞 |
| 病因記憶 | 美國＝Histoplasma（局部鈣化型）；其他 TB、sarcoidosis、放療、藥物（methysergide）、idiopathic（IgG4-RD） | Schistosoma **不是** |
| 報告重點 | 描述受壓/阻塞的關鍵結構（SVC、肺動/靜脈、中央氣道、食道）、鈣化、側支循環（支氣管動脈怒張） | 血管/氣道阻塞決定臨床嚴重度 |
| 分型 | focal ~80%（鈣化、腫塊）vs diffuse ~20%（浸潤、IgG4） | |

## 題目
> [!question]- Which of the following is NOT a common etiology of fibrosing mediastinitis? (2021-294)
> **D（Schistosoma mansoni）**——正解。血吸蟲**不是**纖維化縱膈炎的病因。A（sarcoidosis）、B（Mycobacterium tuberculosis）、C（Histoplasma capsulatum，美國最常見、常局部型）皆為公認病因；其餘病因尚含 idiopathic（多屬 IgG4 相關疾病）、並存胸內惡性、放療與藥物（methysergide）。
