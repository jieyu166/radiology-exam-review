# bronchial-artery-embolization-hemoptysis

**支氣管動脈栓塞（BAE）是大量咳血的第一線微創治療，對「良性、慢性發炎性」病因（肺結核、結核後遺症、支氣管擴張、麴菌球）效果最好；對「肺部惡性腫瘤」獲益最差（多為姑息、再出血率高）。責任血管以支氣管動脈與非支氣管全身性側枝（肋間、內乳、鎖骨下分支）為主——脊髓前動脈（anterior spinal artery）不是責任血管，而是最需避開的「地雷」，誤栓會造成脊髓缺血/截癱。**

## Summary
- **適應症/常見病因**：BAE 最常見的適應症為肺結核（TB）、結核後遺症（post-tubercular sequelae）、支氣管擴張與麴菌球（aspergilloma）。[^1][^2]
- **療效**：立即臨床成功率（咳血完全停止）約 **70–99%**，但復發率高（**10–57%**），原因為初次栓塞不完全、已栓塞動脈再通、以及新側枝生成。[^2]
- **獲益最差族群**：肺部**惡性腫瘤**引起的咳血對 BAE 獲益最少，多屬姑息性、再出血率高；麴菌球、空洞、reactivation/MDR-TB 亦與較高復發率相關。[^2]
- **責任血管**：以**支氣管動脈**（右/左/共幹/右肋間支氣管幹 ICBT）與**非支氣管全身性側枝**（intercostal、internal mammary branches、subclavian 分支）為主。[^2]
- **禁忌/地雷**：分支供應心臟、**脊髓（脊髓前動脈 anterior spinal artery）**或腦部者為絕對禁忌；誤栓可致脊髓缺血、截癱、中風或皮質盲。[^1]

## 放射科醫師影像判讀重點
- **術前 CTA**：辨識肥大、扭曲的支氣管動脈（管徑 >2 mm）與非支氣管側枝（經胸膜增粗的肋間/內乳動脈、胸膜外脂肪內迂曲血管）是定位出血源的關鍵；右肋間支氣管幹（ICBT）為最常見責任血管之一。[^1][^2]
- **anterior spinal artery 辨識**：血管攝影見自 ICBT 或肋間動脈發出、沿中線走行的「髮夾狀」脊髓動脈時，須避免非目標栓塞——這是 BAE 最嚴重併發症的來源，並非咳血的責任血管。[^1]
- **咳血血流動力學**：約 90% 咳血源自**體循環（支氣管動脈系統）**、僅少數源自肺動脈（如結核空洞旁的 Rasmussen 假性動脈瘤）；惡性腫瘤的新生血管脆弱、易再出血，故 BAE 效果較差。[^1][^2]
- **併發症**：最常見為短暫胸/背痛、吞嚥困難與栓塞後症候群（up to 30%）；嚴重併發症包括非目標栓塞（下肢缺血、缺血性大腸炎、支氣管食道瘻管、支氣管梗塞）與脊髓缺血/中風。[^1]

### 咳血／肺出血的 CT 表現（考點列舉）
咳血本身於 CT 可有多種表現，判讀時應綜合肺實質、氣道與血管三方面（皆可為咳血之 CT findings）：[^3]
- **肺泡內出血** → **毛玻璃樣（ground-glass opacity）或實變（consolidation）**。[^3]
- **亞急性出血** → 可見**間隔線（septal lines）**。[^3]
- **支氣管樹內血塊** → 氣道內**充填缺損（filling defects）**。[^3]
- **較大氣道被血塊阻塞** → **肺塌陷（atelectasis）**。[^3]
- **遠端氣道血塊** → **小葉中心結節（centrilobular nodules）**，可呈 **tree-in-bud** 外觀。[^3]
- **支氣管動脈肥大（hypertrophy）**：肥大時流向支氣管動脈的心輸出量可自正常約 1% 增至最高約 30%；這些肥大血管管壁薄而脆、承受體循環壓力，易破入氣道而致咳血。[^3]
- **考點**：上述（GGO/consolidation、bronchial artery hypertrophy、bronchial tree 內 filling defects、atelectasis）**皆可為咳血之 CT 表現**，故「以上皆是」型題目正解為「全部皆可」。[^3]

## 題目
> [!question]- Which of the following pathologies presented with hemoptysis has benefited least from bronchial artery embolization (BAE)? (2022-433)
> **B（pulmonary malignancy）** BAE 對「良性、慢性發炎性」咳血（特發性支氣管擴張、活動性肺結核、結核後遺症）效果最好，這些正是 BAE 的核心適應症；相對地，**肺部惡性腫瘤**的新生血管脆弱、腫瘤持續進展，BAE 多屬姑息，再出血率高、長期獲益最差。[^2] → [[bronchial-artery-embolization-hemoptysis]]

> [!question]- Which of the following is not a common culprit artery for hemoptysis? (2022-434)
> **D（anterior spinal artery）** 咳血責任血管以支氣管動脈及非支氣管全身性側枝為主——**internal mammary artery（B）、bronchial artery（B 正解為支氣管動脈本身）、intercostal artery（C）** 皆為常見責任血管。**脊髓前動脈（anterior spinal artery）不是責任血管**，而是 BAE 時必須辨識並避開的地雷血管（誤栓致脊髓缺血/截癱），為絕對禁忌。[^1][^2] → [[bronchial-artery-embolization-hemoptysis]]

> [!question]- 下列何者不屬於 Hemoptysis 之 CT findings? (2021-190)
> **E（以上皆可以是 hemoptysis 之 CT findings）** ——**Ground-glass opacity（A，肺泡出血）、bronchial artery hypertrophy（B）、filling defects in bronchial tree（C，氣道內血塊）、atelectasis（D，大氣道被血塊阻塞）皆為咳血之 CT 表現**（另有 septal lines、centrilobular/tree-in-bud nodules），故正解為「全部皆可」。[^3] → [[bronchial-artery-embolization-hemoptysis]]
