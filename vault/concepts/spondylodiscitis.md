# spondylodiscitis

**化膿性椎間盤炎（spondylodiscitis）＝細菌感染相鄰兩節椎體和中間的椎間盤。** 典型 MRI 是終板兩側骨髓 T1 變暗、終板輪廓消失、椎間盤 T2 變亮並增強，旁邊有發炎軟組織或膿瘍[^1][^2]。要分「感染」還是「退化（Modic type 1）」，**最重要的是椎旁或硬膜外有沒有發炎軟組織**（但 Charcot 脊椎也可能有椎旁軟組織，這條不適用於它[^18][^19]）；單看椎間盤 T2 亮不亮不夠，因為 Modic type 1 也會增強[^3][^4][^5]。

## Summary

- **怎麼來的**：多數經血液散播；成人從終板附近的椎體開始，再侵犯椎間盤[^1][^6]。
- **誰造成的**：最常見金黃色葡萄球菌[^1][^2]。
- **好發位置**：腰椎最多，其次胸椎、頸椎[^1]。
- **首選檢查**：MRI（敏感度約 96–97%、特異度約 92–93%）[^1][^7]。
- **確診**：血液培養或血清學找不到菌時，做影像導引切片[^7]。
- **治療後**：骨頭變化常比臨床慢、看起來更糟，要看軟組織；臨床改善時不需常規追蹤 MRI[^7][^8]。

## 定義與術語

- **終板（endplate）**：椎體上下面貼著椎間盤的那層骨板。
- **Modic type 1**：退化造成的終板旁骨髓水腫，MRI 上 T1 暗、T2 亮，可以增強[^3]。
- **Phlegmon**：還沒液化的發炎軟組織，增強時整塊亮。
- **膿瘍（abscess）**：已液化，增強時只有邊緣亮、中間不亮[^4]。
- **硬膜外膿瘍（epidural abscess）**：膿長在脊髓硬膜外面的空間，會壓迫脊髓或馬尾。
- **Claw sign**：DWI 上正常和異常骨髓交界處出現成對的爪狀亮帶，偏向退化[^9]。

## 影像診斷

### 重要徵象一覽

| 徵象 | 序列 | 長什麼樣子 | 意義 |
| --- | --- | --- | --- |
| 終板兩側骨髓 T1 低訊號 | T1 | 椎間盤上下兩節椎體都暗、終板輪廓消失 | 典型感染表現[^1] |
| 椎間盤 T2 高訊號＋增強 | T2／增強 | 椎間盤像水一樣亮、打藥後亮 | 支持感染，但單獨不夠[^4][^10] |
| 椎旁或硬膜外發炎 | T2／增強 | 椎體旁或椎管內的 phlegmon 或膿瘍 | 敏感度最高（97.7%），區分感染和 Modic 1 的關鍵[^5][^10] |
| Psoas sign | T2 | 腰大肌水腫或積液 | 支持感染；腰椎研究中腰大肌水腫對硬膜外膿瘍特異度 96%[^11][^12] |
| DWI 擴散型態 | DWI | 以終板為中心瀰漫受限偏感染；claw sign 偏退化 | 輔助區分 Modic 1[^9][^11] |
| 小氣泡 | CT／X 光 | 椎間盤或軟組織內多顆小氣泡 | 革蘭氏陰性菌感染；不要和退化的線狀 vacuum 搞混[^2] |

- 一篇 44 例研究的各徵象敏感度：椎旁或硬膜外發炎 97.7%、椎間盤增強 95.4%、椎間盤 T2 高訊號 93.2%、終板侵蝕 84.1%、椎間隙變窄 52.3%、椎間盤 T1 低訊號 29.5%[^10]。
- 早期可能只有某一個序列異常，平掃和增強都要做[^6]。

> [!warning] 椎間盤 T2 亮≠一定是感染
> Modic type 1 也會增強。嚴重 Modic 1 和早期感染可能分不出來，關鍵看椎旁／硬膜外有沒有軟組織，必要時切片[^3][^4][^5]。

### 硬膜外膿瘍

- 增強分三型：整塊均勻亮（phlegmon）、邊緣亮（膿瘍）、兩者混合[^4]。
- 不打藥的 MRI 也能找：腰椎研究中椎旁水腫敏感度 97%[^12]。
- 有神經學缺損要立即手術並開始經驗性抗生素，不能等切片結果[^7]。

### 其他檢查

- X 光：早期不敏感，骨破壞要 3–6 週才看得到[^7]。
- CT：適合導引切片[^7]。
- MRI 不能做時：可改骨掃描合併 gallium、CT 或 PET[^7]。

## 鑑別與報告要點

| 鑑別 | 怎麼和化膿性感染分 |
| --- | --- |
| Modic type 1 | 沒有椎旁／硬膜外軟組織；DWI claw sign[^3][^9] |
| 結核性脊椎炎 | 胸椎多、韌帶下擴散 ≥3 節、薄壁大膿瘍、椎間盤相對保留，見 [[tb-spondylitis]][^13] |
| Charcot（神經病變性）脊椎 | 骨密度保留、碎骨片、排列紊亂、小面關節破壞、椎間盤內氣體；也可有椎旁軟組織，不能靠軟組織區分[^14][^18][^19] |
| 透析相關病變 | 終板侵蝕邊界清楚、椎間盤 T2 通常偏低、沒有椎旁發炎[^15] |
| CPPD | CT 見線狀鈣化、軟組織增強少；臨床也會發燒，容易誤認[^16] |
| 轉移 | 椎間盤保留、後方結構受侵、跳躍多發、沒有周邊發炎[^1][^4] |

報告時：
- 寫出受侵節段、終板與椎間盤變化、椎旁或硬膜外膿瘍與大小、硬膜囊或脊髓受壓程度。
- 有硬膜外膿瘍或脊髓受壓要立即通知。

## 解題

> [!note] 考點（2016 交換：[[2016-218]]）
> 問 discitis 和 Modic type 1 的 MRI 區分特徵，官方答 (C) 椎間盤內 T2 高訊號[^17]。
> 補充：這是傳統考點。教科書提醒椎間盤 T2 高訊號單獨不足以診斷感染，要合併椎旁／硬膜外發炎等表現[^4]；研究中它的敏感度 93.2%，低於椎旁／硬膜外發炎的 97.7%[^10]。

## 題目

> [!question]- 看到兩節相鄰椎體加中間椎間盤 T2 都亮，怎麼分感染還是 Modic type 1？
> 看椎旁或硬膜外有沒有發炎軟組織；Modic 1 也會增強，椎間盤 T2 亮單獨不夠。DWI claw sign 偏退化[^3][^4][^9]。

> [!question]- 病人疑似脊椎感染又有下肢無力，要先切片確定菌種嗎？
> 不要等。有神經學缺損應立即手術並開始經驗性抗生素[^7]。

> [!question]- 治療 6 週後 MRI 的骨頭破壞更明顯，但病人退燒、CRP 下降，代表治療失敗嗎？
> 不一定。骨頭變化常落後於臨床，要看椎旁與硬膜外軟組織；臨床改善時不需常規追蹤 MRI[^7][^8]。
