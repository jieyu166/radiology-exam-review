# pediatric-hindfoot-alignment

**記住「varus 屬 clubfoot、valgus 屬其他」這條分水嶺：後足內翻（hindfoot varus）是 clubfoot（congenital talipes equinovarus, CTEV）的核心構成（CAVE 中的 V）；反之後足外翻（hindfoot valgus）出現在 congenital vertical talus、skewfoot、cerebral palsy（痙攣性平足外翻）等——唯獨 clubfoot 不會有後足外翻。**

## Summary
- **Clubfoot（CTEV）＝後足內翻（varus）**：由四元素構成——**hindfoot varus（後足內翻）**＋hindfoot equinus（後足馬蹄／蹠屈）＋forefoot adductus/varus（前足內收）＋talonavicular subluxation（舟骨內側半脫位）；助記 **CAVE**（Cavus、forefoot Adductus、hindfoot Varus、Equinus）。[^1][^2]
- **後足內翻是 clubfoot 的診斷成分（2022-463 考點）**：故問「hindfoot varus 屬哪種先天畸形」答 **clubfoot**。[^1][^2]
- **後足外翻（valgus）的疾病譜（2022-467 考點）**：見於 **congenital vertical talus（rocker-bottom，equinovalgus）、skewfoot（serpentine foot，後足外翻＋前足內收）、cerebral palsy（痙攣性平足外翻）**；**唯 clubfoot（CTEV）為後足內翻，不屬後足外翻** → 故「hindfoot valgus 例外者＝CTEV」。[^1][^3]

## 放射科醫師影像判讀重點
- **量測需負重（或模擬負重）之 DP／側位片**，以 talus 為後足參考點。[^1][^2]
- **Clubfoot 影像**：**AP 與側位 talocalcaneal angle 皆變小（平行化）**——正常兩線發散、clubfoot 兩線趨於平行；側位 lateral talocalcaneal angle < 35°（馬蹄）、AP talocalcaneal angle < 20°（內翻）；talus 長軸明顯偏 1st MT 外側、跟骨長軸偏 5th MT 外側；navicular 於 talus 內側半脫位。[^1][^2]
- **Congenital vertical talus（後足外翻）**：talus 固定蹠屈（垂直）、talocalcaneal angle 增大、navicular 背側不可復位脫位、forefoot valgus、外形呈搖椅底（rocker-bottom）；常合併 trisomy 13/18、脊柱裂、arthrogryposis。[^3]
- **Skewfoot / Metatarsus adductus 區別**：metatarsus adductus 為單純前足內收、後足正常；skewfoot（Z/serpentine foot）＝前足內收＋後足外翻並存。[^1]
- **陷阱**：clubfoot 與 CVT 都可有 equinus，但 clubfoot 後足**內翻**、CVT 後足**外翻**——後足對位方向是分辨關鍵。[^1][^2][^3]

## 題目
> [!question]- Hindfoot varus is a component of which congenital deformity? (2022-466)
> **C（關鍵）Clubfoot**。後足內翻（hindfoot varus）是 clubfoot（CTEV）的核心成分之一（CAVE 中的 V）。A vertical talus 與 B oblique talus 為後足外翻/中間型、D pes planus 為扁平（外翻）足，皆非內翻。→ [[pediatric-hindfoot-alignment]]。[^1][^2]

> [!question]- Hindfoot valgus can be present in all the following conditions EXCEPT which of the following? (2022-467)
> **D（關鍵）Congenital talipes equinovarus（clubfoot）為例外**。CTEV 是後足**內翻（varus）**，不會有後足外翻。A cerebral palsy（痙攣性平足外翻）、B skewfoot（後足外翻＋前足內收）、C congenital vertical talus（equinovalgus）皆屬後足外翻。→ [[pediatric-hindfoot-alignment]]。[^1][^3]

> [!question]- Which choice likely represents the cause of hindfoot valgus? (2022-499)
> **C（關鍵）Cerebral palsy（腦性麻痺）**。痙攣型腦性麻痺屬神經肌肉疾病，是兒童後足外翻／痙攣性平足外翻（pes planovalgus）的公認成因。A amniotic band syndrome（束帶症，多致 equinovarus/截肢）、B osteogenesis imperfecta（骨脆弱/骨折/彎曲）、D nonaccidental trauma（骨折）、E muscular dystrophy（多為 equinovarus/cavovarus 攣縮）皆非後足外翻的典型成因。→ [[pediatric-hindfoot-alignment]]。[^4][^5]
