# kawasaki-disease-imaging

**川崎病(Kawasaki disease)是好發於5歲以下兒童的中血管血管炎(medium-vessel vasculitis)，最重要的併發症是「冠狀動脈擴張伴動脈瘤形成(coronary dilatation with aneurysm)」——不同於巨細胞動脈炎(giant cell arteritis)好發顳淺動脈，川崎病並不特別侵犯顳淺動脈。** 判讀分水嶺：**川崎病屬中血管血管炎（非大血管）;好發冠狀動脈病變（擴張/動脈瘤）為最重要的長期併發症與死亡原因;中樞神經系統侵犯相對少見（並非高達30%這麼高的比例，此為常見誤答陷阱）。**

## Summary
- **血管口徑分類**：川崎病屬**中血管血管炎(medium-vessel vasculitis)**，與結節性多動脈炎(polyarteritis nodosa)同類。[^1]
- **顳淺動脈**：川崎病**並非**以侵犯顳淺動脈(superficial temporal artery)為主要特徵——此為巨細胞動脈炎(giant cell arteritis，大血管炎)的典型侵犯部位，兩者不應混淆。[^1]
- **心臟併發症**：可造成**冠狀動脈擴張伴動脈瘤形成(coronary dilatation with aneurysm)**，為川崎病最重要且可能致命的長期併發症，需長期心臟超音波追蹤。[^1]
- **中樞神經系統侵犯**：相對**少見**，並非高比例（如30%）常規侵犯——此為常見誤答選項，需注意數字誇大陷阱。[^1]
- **疾病本質補充**：川崎病為**急性(acute)**、自限性多系統性全血管炎（並非「慢性chronic」）；**最常侵犯左主冠狀動脈(left main coronary artery)**；1967年於日本首次描述。[^2]

## 放射科醫師影像判讀重點

- **首選影像＝經胸心臟超音波(transthoracic echocardiography)**：用於偵測與追蹤冠狀動脈擴張/動脈瘤，是急性期與長期追蹤的第一線工具，重點在測量冠狀動脈內徑並以 Z-score 校正體表面積。[^1]
- **好發部位為冠狀動脈近端**：動脈瘤最常見於左主冠狀動脈與近端節段；影像上呈囊狀(saccular)或紡錘狀(fusiform)擴張，須與正常管徑逐節比對。[^2]
- **中血管血管炎的分布邏輯**：川崎病屬中血管炎，病灶集中於冠狀動脈等中口徑動脈，**不**以顳淺動脈(superficial temporal artery)為侵犯部位——顳淺動脈受侵是巨細胞動脈炎(大血管炎)特徵，為影像/臨床鑑別分水嶺。[^1]
- **慢性期併發症的判讀**：長期後遺症含冠狀動脈瘤內血栓、早發性動脈粥樣硬化與狹窄，可致心肌梗塞；CT 冠脈攝影或 MRI 用於評估瘤壁鈣化、血栓與心肌灌注。[^2]
- **中樞神經侵犯屬少見**：勿被「高比例(如30%)中樞神經侵犯」的誇大選項誤導，此非川崎病典型影像表現。[^1]

## 臨床重點（5 句）

- 川崎病好發於**5 歲以下**兒童，是已開發國家兒童後天性心臟病的主要原因之一。[^1]
- 診斷為臨床診斷：持續發燒 ≥5 天併結膜炎、口唇/口腔黏膜變化、肢端變化、皮疹與頸部淋巴結腫大等特徵。[^2]
- 標準治療為**靜脈免疫球蛋白(IVIG)加 aspirin**，於發病 10 天內給予可顯著降低冠狀動脈瘤發生率。[^2]
- 冠狀動脈瘤是最重要且可能致命的長期併發症，也是本病主要死亡原因。[^1]
- 1967 年由川崎富作於日本首次描述，又稱皮膚黏膜淋巴結症候群(mucocutaneous lymph node syndrome)。[^2]

> [!note] 考點：關於川崎病，何者「為偽」?
> **A為偽**——川崎病**並非**主要侵犯顳淺動脈(superficial temporal artery，此為giant cell arteritis的特徵)。川崎病屬中血管血管炎(B)、可致冠狀動脈擴張伴動脈瘤(C)皆為真;中樞神經系統侵犯比例並非高達30%(D，此選項本身描述比例過高而為另一常見誤答陷阱)。[^1]

> [!question]- About KAWASAKI disease, which following is not true (2017-320)

> [!question]- About Kawasaki disease, which statement is wrong? (2018-233)
> **Is an "chronic" self-limited multisystemic panarteritis（B）**——實際為「急性(acute)」，非慢性，此敘述錯誤。1967年日本首次描述(A)、心臟後遺症(C)、最常侵犯左主冠狀動脈(D)皆為正確描述。[^2]
