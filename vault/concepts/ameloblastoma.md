# ameloblastoma

**Ameloblastoma 是最常見的 odontogenic tumor，組織學上為良性但具有 locally aggressive 特性。最常發生於 mandible（下顎骨，約80%），而非 maxilla。典型影像為 multilocular radiolucent lesion（soap bubble appearance）。**

## Summary
- **最常見位置**：mandible 後段（posterior body / ramus），約 80% [^1]
- **非 maxilla**（上顎骨最常見的 odontogenic tumor 是 odontoma）[^1]
- 組織學良性但 locally aggressive，復發率高 [^1]
- 影像：multilocular radiolucent lesion = **soap bubble** / honeycomb pattern on panoramic radiograph [^1]
- 臨床：口腔/顏面腫脹、牙齒鬆動 [^1]

## 放射科醫師影像判讀重點
- **好發部位與定位**：絕大多數為骨內(intraosseous)病灶，對下顎骨(mandible)有明顯偏好（文獻報告可達 97%），以體部-角部-升支(body-angle-ramus/後段臼齒區)最常見；此下顎後段之定位是重要判讀線索。[^2]
- **X 光/全景片型態**：可表現為單囊(unilocular)或多囊(multilocular)透亮病灶；經典「肥皂泡(soap bubble)／蜂窩(honeycomb)」為多囊型，惟並非全部——文獻顯示相當比例之實質型(solid)呈單囊透亮、部分單囊型(unicystic)反呈多囊，故單/多囊外觀與組織型不能一一對應，判讀勿以外觀直接推論亞型。[^2]
- **侵犯與 DDx**：常伴皮質骨膨脹(cortical expansion)、皮質穿破(perforation)及鄰牙牙根吸收；判讀時須與含牙囊腫(dentigerous cyst)、齒源性角化囊腫(OKC)、齒源性黏液瘤、中央性巨細胞病灶等多囊透亮病灶鑑別，膨脹性生長與牙根吸收較支持 ameloblastoma。[^2]
- **進階影像角色**：CT/CBCT 可精確評估皮質穿破、頰舌向膨脹範圍與病灶邊界；MRI 有助評估軟組織成分並協助與囊腫區分（實質/囊實混合成分），對術前範圍界定與復發監測有價值。[^2]

## 臨床重點（5 句）
- Ameloblastoma 是最常見之齒源性腫瘤，於單一系列可佔全部齒源性腫瘤約 60%。[^2]
- 組織學為良性但具局部侵襲性(locally aggressive)，若切除不足復發率高（系列報告約 13%）。[^2]
- 兒童/青少年病例相對少見（約佔 10–15%），且此年齡層仍以下顎為主。[^2]
- 組織型以實質/多囊型與單囊型(unicystic)為主，單囊型（尤其伴囊壁侵犯或壁內增生者）復發風險不低，可能需較積極處置而非單純刮除。[^2]
- 臨床多以無痛性顎骨/顏面漸進性腫脹、牙齒鬆動或移位表現，晚期可致顏面變形。[^2]

## 陷阱
- 最常見在 **mandible**，不是 maxilla — 這是常見考題陷阱
