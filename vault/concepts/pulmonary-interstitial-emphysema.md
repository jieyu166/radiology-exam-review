# pulmonary-interstitial-emphysema

**PIE＝氣體由破裂肺泡進入肺間質與淋巴管，好發『新生兒』（早產、機械通氣/CPAP 的 air-block 現象，barotrauma）。** 判讀分水嶺：**新生兒/早產接受正壓通氣者；氣體沿支氣管血管周圍間質積聚（線狀/囊狀透亮）；NICU 發生率 2–3%、早產兒升至 20–30%、低體重最高；可進展為 pseudocyst、氣胸、縱膈氣腫；偶見於成人。**

## Summary
- **機轉**：肺泡過度膨脹破裂 → 氣體進入**肺間質與淋巴管**沿支氣管血管鞘；**air-block／barotrauma，好發新生兒（早產、機械通氣/CPAP）**，非老年。[^1][^2]
- **流行病學**：NICU 新生兒 **2–3%**、**早產兒升至 20–30%**、**低出生體重最高**。[^2]
- **危險因子**：機械通氣/CPAP、肺順應性下降、早產、低體重、胎便吸入、肺炎。[^2]
- **臨床**：通氣中病人**突然惡化**（亦可為偶見發現）。[^1][^2]
- **併發**：可形成 **pseudocyst、氣胸、縱膈氣腫**；典型**雙側對稱**。[^1]

## 放射科醫師影像判讀重點
- **型態**：沿支氣管血管束之線狀/點狀/小囊狀透亮，不隨呼吸消長，異於正常含氣支氣管。[^1][^2]
- **背景**：早產 + 正壓通氣 + 突然惡化 → 高度懷疑 PIE。[^2]
- **併發警覺**：追蹤是否進展為 pseudocyst/氣胸/縱膈氣腫。[^1]
- **成人偶見**：正壓通氣成人亦可偶發，非僅新生兒獨有。[^2]
- **陷阱**：air-block 好發新生兒而非老年。[^1]

## 臨床重點（5 句）
1. **氣體入間質/淋巴管**、barotrauma。[^1][^2]
2. **好發新生兒**（早產、機械通氣）。[^1][^2]
3. **早產兒 20–30%**、低體重最高。[^2]
4. **通氣中突然惡化**。[^1]
5. **併 pseudocyst/氣胸/縱膈氣腫**、雙側對稱。[^1]

> [!note] 考點：關於 PIE，何者「錯誤」?
> 「**air-block 現象好發老年**」錯誤——好發**新生兒（早產/機械通氣）**。通氣中突然惡化、可併 pseudocyst/氣胸、雙側對稱皆正確。[^1][^2]
