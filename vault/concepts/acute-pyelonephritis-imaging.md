# acute-pyelonephritis-imaging

**單純性急性腎盂腎炎是臨床診斷、不需常規影像；CT 只保留給糖尿病/免疫低下/複雜性或治療無反應者，用來找併發症（膿瘍、氣腫、阻塞），而非「評估感染範圍」。**

## Summary
- **單純性 APN**：以臨床及尿液檢查即可診斷，**不需常規 CT**；影像目的在於偵測併發症而非確認感染範圍。[^1]
- **成人 CT 適應症**：糖尿病、免疫低下、複雜性感染，或抗生素治療 48–72 小時無反應時。[^1][^2]
- **兒童**：疑似泌尿系統功能異常者應做逆流研究（VCUG/reflux study）；反覆腎盂腎炎而逆流研究無明確異常時再考慮 CT 或 MRI。[^1]
- **氣腫性腎盂腎炎（EPN）**：CT 是診斷與分級（Huang–Tseng class 1–4）的依據；糖尿病、阻塞性尿路病變、高血壓為常見危險因子。[^2]

## 放射科醫師影像判讀重點
- **對比後 CT 典型表現**：楔形低強化區、條紋狀腎圖（striated nephrogram）、腎腫大與腎周脂肪條紋；平掃常無明顯異常，須做對比。[^1]
- **併發症判讀**：局灶低密度不強化區＝腎/腎周膿瘍；腎實質內或集尿系統氣體＝氣腫性感染，須立即分級並評估引流。[^2]
- **黃色肉芽腫性腎盂腎炎（XGP）/真菌性腎盂腎炎**：在 T2 加權像上呈明顯低訊號，可與腫瘤區分，屬影像上的「腎假性腫瘤」之一。[^3]
- **陷阱**：把「CT 對單純性 APN 很重要、用來評估感染範圍」當正確敘述是錯的——單純性 APN 不需 CT。[^1]

## 臨床重點（5 句）
1. 女性、性活躍、糖尿病、尿路阻塞或器械操作為 APN 高風險族群。[^2]
2. 大腸桿菌（E. coli）為最常見致病菌。[^2]
3. 多數單純性 APN 對適當抗生素反應良好；未改善須警覺膿瘍或阻塞。[^1]
4. EPN 死亡率高，糖尿病為最主要基礎疾病，治療已由早期主張的緊急腎切除轉向較保守的引流合併抗生素。[^2]
5. 兒童反覆 UTI 合併 APN 須評估膀胱輸尿管逆流以預防腎瘢痕。[^1]

> [!note] 考點：以下哪一項急性腎盂腎炎的影像策略「最不恰當」？
> **單純性 APN 不需常規 CT 去評估感染範圍**（該選項最不恰當）。CT 應保留給糖尿病/免疫低下/複雜性成人、以及兒童反覆腎盂腎炎而逆流研究陰性者。[^1]
