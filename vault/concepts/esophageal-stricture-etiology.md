# esophageal-stricture-etiology

**食道狹窄常見病因中，嗜酸性球性食道炎（eosinophilic esophagitis, EoE）相對「最少」造成狹窄——EoE 的食道攝影常「正常」，雖長期病程（>20 年）約 71% 仍會出現狹窄，但相較 Barrett esophagus、藥物性食道炎、逆流性食道炎（peptic），仍是四者中最少見的狹窄病因。** 判讀分水嶺：**用「部位」鎖定病因——peptic/reflux 在遠端、藥物性在主動脈弓/左心房壓迫處、caustic 在近端+中段且長、EoE 呈瀰漫小口徑或同心環（ringed/feline esophagus）。**

## Summary
- **常見狹窄病因（相對多→少）**：**peptic/reflux（遠端，慢性 GER，最常見良性狹窄）、Barrett esophagus（遠端/中段）、drug-induced esophagitis** 皆較常見；**EoE 相對最少見**——食道攝影**最常正常**，長期病程（>20 年）約 71% 才出現狹窄。[^1][^2][^3]
- **部位定位**：peptic **遠端**；caustic **近端 + 中段**（常長、嚴重）；drug-induced 多在**主動脈弓/左心房壓迫處**；EoE 可**瀰漫變窄或同心環狀**。[^1]
- **EoE 特徵**：**ringed esophagus（同心、薄、web-like 狹窄，即 feline/ringed esophagus）**為最特徵表現，可合併較長狹窄；狹窄/webs/痙攣造成**食物或藥丸阻塞**。[^2]

## 放射科醫師影像判讀重點
- **peptic（reflux）**：遠端食道平滑漸細狹窄 + 近端擴張，常伴 hiatal hernia/reflux；為最常見良性狹窄。[^1]
- **Barrett**：中-遠段狹窄 ± reticular mucosa，源於長段柱狀化生，惡性風險需留意。[^1]
- **drug-induced**：於解剖壓迫點（主動脈弓/左心房/LES 上）之局部潰瘍/狹窄，有服藥（doxycycline、KCl、NSAID 等）病史。[^1]
- **caustic**：近端+中段之長段、嚴重狹窄，有腐蝕劑吞食史，長期惡性風險。[^1]
- **EoE**：食道攝影常「正常」為陷阱；找 **ringed/feline esophagus、small-caliber esophagus**；年輕、過敏體質、食物阻塞病史 → 切片 ≥15 eos/HPF 確診。[^2]

## 臨床重點（5 句）
1. **EoE 最少造成狹窄**：四者中相對最少見之狹窄病因，攝影常正常。[^1][^2][^3]
2. **部位鎖病因**：遠端 peptic、近中段 caustic、壓迫點 drug、瀰漫環狀 EoE。[^1]
3. **EoE 診斷**：年輕 + 過敏 + 食物阻塞 + ringed esophagus + 切片 ≥15 eos/HPF。[^2]
4. **EoE 治療**：高劑量局部類固醇、雙倍 PPI、elimination diet。[^2]
5. **惡性警覺**：Barrett/caustic 狹窄有惡性風險，需追蹤與適時切片。[^1]

> [!note] 考點：下列何者為食道狹窄最少見之病因?
> **Eosinophilic esophagitis（B）**——EoE 食道攝影最常正常，雖長期病程（>20 年）約 71% 仍會狹窄，相較 Barrett/藥物性/逆流性食道炎仍為四者中相對最少見之狹窄病因。[^1][^2][^3]
