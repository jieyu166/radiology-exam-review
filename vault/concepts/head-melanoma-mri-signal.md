# head-melanoma-mri-signal

**惡性黑色素瘤依黑色素含量分兩種 MRI 訊號：「Melanotic pattern（>10% 黑色素細胞）」呈 T1 高訊號、T2 低訊號（黑色素順磁效應，唯一提供一致可靠 MR 表現者）；「Amelanotic pattern（<10%）」則 T1 低-等、T2 高-等（非特異）——兩者恰好相反。** 判讀分水嶺：**melanotic：T1 高、T2 低（黑色素順磁、對 T1/T2 皆縮短）；amelanotic：T1 低-等、T2 高-等（似一般軟組織腫瘤）；陷阱＝誤將 amelanotic 之 T2 寫成「低訊號」（應為高-等訊號）；melanoma 為典型出血性轉移，血產物亦致 T1 高/T2 低。**

## Summary
- **兩型（依黑色素含量）**：**melanotic（組織學 >10% 黑色素細胞）** vs **amelanotic（<10%）**。[^1][^2]
- **Melanotic pattern**：**T1 高訊號、T2 低訊號**——黑色素為**順磁性**（穩定自由基），縮短 T1 與 T2；**唯一提供一致可靠 MR 表現者**。[^1][^2]
- **Amelanotic pattern**：**T1 低-等訊號、T2 高-等訊號**——**非特異**，似一般軟組織腫瘤。[^1][^2]
- **出血因素**：melanoma 為典型**出血性轉移**；血產物亦致 T1 高/T2 低，故訊號可源自黑色素**或**出血（黑色素對 T1/T2 有平行效應）。[^2]
- **比例**：腦轉移中僅約 **25%** 為 melanotic 型。[^2]

## 放射科醫師影像判讀重點
- **melanotic 指紋**：T1 高 + T2 低之腦/頭頸病灶 + 已知黑色素瘤 → 想 melanotic 轉移。[^1][^2]
- **amelanotic 非特異**：T1 低-等/T2 高-等，需靠病史 + 強化 + 出血傾向判斷。[^1][^2]
- **出血 vs 黑色素**：兩者皆 T1 高/T2 低，難單靠訊號分；SWI/GRE 找含鐵血黃素輔助。[^2]
- **多發出血性轉移**：多發 T1 高訊號結節 + 出血 → melanoma（與絨毛膜癌、腎癌、甲狀腺癌等出血性轉移鑑別）。[^2]
- **陷阱**：amelanotic 之 T2 為高-等（非低）——常考錯誤選項。[^1]

## 臨床重點（5 句）
1. **melanotic**：T1 高、T2 低（順磁、唯一可靠）。[^1][^2]
2. **amelanotic**：T1 低-等、T2 高-等（非特異）。[^1][^2]
3. **出血**：melanoma 典型出血性轉移，血產物亦 T1 高/T2 低。[^2]
4. **比例**：腦轉移僅 ~25% melanotic。[^2]
5. **陷阱**：amelanotic T2 為高-等，非低。[^1]

> [!note] 考點：關於頭部惡性黑色素瘤，何者敘述「為偽」?
> ⚠️ 官方原答案 B、後更正為 **C 為偽**——Amelanotic pattern 於 T2WI 應呈**高-等訊號**，而非「低訊號（low signal intensity）」。含 melanotic 與 amelanotic 兩型態（A，真）、melanotic pattern 於 T1WI 呈高訊號（B，真，黑色素順磁效應）皆為正確敘述。[^1][^2]
