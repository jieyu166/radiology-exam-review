# subtle-fracture-radiographic-signs

**當骨折線本身在 X 光上不明顯（隱匿/subtle fracture）時，常須靠「間接/次級徵象」推斷骨折存在：軟組織徵象（關節積液、脂肪墊移位、關節內脂肪-液平＝lipohemarthrosis/FBI sign）、骨膜反應（癒合期）、以及皮質壓陷徵象（雙皮質線/局部緻密帶）。** 判讀分水嶺：**關節內脂肪-液平（fat-fluid level）只要看到就代表關節內骨折**（骨髓脂肪＋血滲入關節，脂肪浮於血上）；而**「不規則骨骺角（irregular epiphyseal corners）」並非隱匿性骨折徵象**——它指向骨壞死/骨梗塞、感染或代謝性病變（本題答案 D）。記憶鉤：**看不到骨折線就找「間接證據」**——積液、脂肪浮血（FBI）、骨膜反應、皮質壓陷成雙線；骨骺角「毛毛的」是另一國的事（AVN/感染/代謝）。

## Summary

### 為何需要間接徵象
- Subtle/隱匿性骨折的**骨折線可能完全看不到**，須靠**間接（secondary）徵象**提示骨折存在並促成進一步影像（CT/MRI）。[^1][^2]

### 常見的間接/次級徵象（考點 A、B、C）
- **關節內脂肪-液平（lipohemarthrosis／FBI sign）＝關節內骨折的可靠指標**（選項 B）：骨折使**骨髓脂肪與血**滲入關節，脂肪較輕浮於血/滑液上，於**水平射束（horizontal-beam）**X 光呈脂肪-液平面。**只要見到脂肪-液平即代表骨折**（但看不到不能排除骨折）。最常見於**脛骨平台、遠端股骨、髕骨骨折**，亦見於髖、肩、肘、腕。[^1][^2]
- **骨膜反應（periosteal reaction）**（選項 A）：為一般性徵象，**成因廣泛**——**創傷（含癒合中的隱匿骨折/壓力性骨折）**、感染、關節病、腫瘤、藥物、血管性等；在亞急性期可提示先前未察覺的骨折。[^3]
- **雙皮質線（double cortical line）**（選項 C）：提示**壓陷性（impacted/depressed）骨折**——實際骨折線可能不明顯，但皮質壓陷/重疊造成**雙重皮質輪廓或局部緻密（impaction）帶**，反映嵌插。[^4]
- 其他常見間接徵象（延伸）：**關節積液/脂肪墊徵象**（如肘 sail sign／後脂肪墊、膝 suprapatellar effusion）、**皮質中斷/階差（step-off）、皮質皺曲（buckle/torus）**、骨小樑扭曲或**嵌插緻密線**。[^1]

### 關鍵鑑別——什麼「不是」隱匿性骨折徵象（答案 D）
- **不規則骨骺角（irregular epiphyseal corners）並非隱匿性骨折的間接徵象**；此類骨骺/干骺端角落不規則多見於**骨壞死/骨梗塞、感染或代謝性/發育性病變**（如壞血病 corner/Pelkan 徵、佝僂病干骺端毛邊杯狀、缺血性壞死、骨骺發育不良）。故本題答案為 D。[^4]

## 影像診斷

### X 光（尋找間接徵象）
- **水平射束攝影**找**脂肪-液平（FBI sign）**——見到＝關節內骨折；膝可有「double fat-fluid level」（suprapatellar plica 造成）。[^1][^2]
- 找**關節積液/脂肪墊移位**（肘後脂肪墊、sail sign）、**皮質階差/皺曲/雙皮質線（壓陷）**、骨小樑錯位或嵌插緻密帶。[^1]
- **骨膜反應**（亞急性/癒合期）提示先前骨折或壓力性骨折。[^3]

### CT / MRI（次級徵象陽性時進一步確認）
- CT/MRI 對密度/訊號差異敏感度更高：CT 明確顯示脂肪-液平（甚至三層 fat-serum-cells）與骨折線；**MRI 對骨髓水腫/隱匿骨折最敏感**，脂肪層在 fat-sat 序列被壓制。[^1]

## 鑑別與報告要點

| 徵象 | 意義 |
|---|---|
| **脂肪-液平（lipohemarthrosis/FBI）** | 見到＝關節內骨折（可靠）；未見不能排除 |
| **骨膜反應** | 非特異，成因廣（創傷/感染/腫瘤/藥物/血管）；癒合期提示先前骨折 |
| **雙皮質線/緻密帶** | 壓陷/嵌插性骨折 |
| **關節積液/脂肪墊徵象** | 間接提示關節內骨折（如肘 sail sign） |
| **不規則骨骺角（答案 D）** | 非骨折徵象；提示 AVN/骨梗塞、感染、代謝性/發育性病變 |

**報告要點**：X 光未見骨折線時，主動尋找**脂肪-液平、關節積液/脂肪墊、皮質壓陷（雙皮質線）、骨膜反應**等間接徵象；任一陽性應建議 CT/MRI。**勿把「不規則骨骺角」當成骨折徵象**——它屬 AVN/感染/代謝性範疇。[^1][^2][^4]

## 題目
> [!question]- Which radiographic feature on radiography is NOT usually seen in patients with a subtle fracture? (2021-260)
> **D（Irregular epiphyseal corners，不規則骨骺角）為正解（＝非隱匿性骨折徵象）**——不規則骨骺角提示骨壞死/骨梗塞、感染或代謝性/發育性病變，並非隱匿性骨折的間接徵象。其餘皆為隱匿性骨折的間接徵象：A（骨膜反應，成因廣含創傷/癒合期）、B（關節內脂肪-液平＝lipohemarthrosis，見到即代表關節內骨折）、C（雙皮質線，反映壓陷/嵌插性骨折）。[^1][^2][^4]
