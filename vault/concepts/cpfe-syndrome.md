# cpfe-syndrome

**CPFE＝『上肺氣腫＋下肺纖維化』常共存於吸菸者，被視為一個獨立疾病實體，凸顯單純把肺氣腫與纖維化二分的侷限;常合併肺高壓、預後差。** 判讀分水嶺：**上肺中央小葉/間隔旁肺氣腫＋下肺 UIP 或 NSIP 型纖維化;肺量測『假性正常』（氣腫使肺容積維持但 DLCO 顯著下降）;常合併嚴重肺高壓、肺癌風險高;非「只是兩種常見病剛好同時出現」,而是有共同（吸菸）易感性的獨立症候群。**

## Summary
- **本質**：肺氣腫與間質纖維化**常共存（尤吸菸者）,應視為一個獨立疾病實體（CPFE syndrome）**——凸顯單純二分肺氣腫/纖維化的侷限。[^1]
- **分布**：**上肺為主的中央小葉/間隔旁肺氣腫**＋**下肺為主的纖維化（UIP 或 NSIP 型）**。[^1]
- **生理**：肺容積/肺量測可『假性正常』（氣腫與纖維化限制互相抵消），但 **DLCO/一氧化碳轉移量顯著下降**、運動性低血氧;佔瀰漫性間質肺病約 5–10%、好發男性吸菸者。[^1][^2]
- **併發/預後**：常合併**嚴重肺高壓**、肺癌風險高、預後差。[^1]
- **病因**：推測為部分病人對香菸的內在易感性（吸菸誘發纖維化）。[^1]

## 放射科醫師影像判讀重點
- **HRCT 分區（Jankowich）**：**上肺為主 centrilobular/paraseptal 氣腫 + 下肺為主纖維化（UIP 或 NSIP 型：網狀/牽引性支氣管擴張 ± honeycombing）**同時並存於同一病人。[^1]
- **肺量測假性正常（Jankowich，考點）**：**氣腫（增容積）與纖維化（限制）互相抵消 → spirometry/肺容積可相對保留**，但**DLCO（氣體交換）顯著下降、運動性低血氧**——臨床-影像不成比例是線索。[^1][^2]
- **肺高壓警覺（Jankowich）**：**CPFE 常併嚴重肺高壓**（PA/主動脈徑比增大、右心室擴大）→ 尋找並報告；有肺高壓者死亡率顯著。[^1]
- **併發搜尋**：**acute lung injury/急性惡化、肺癌（風險高）**；追蹤新結節/實質化。[^1]
- **DDx**：單純肺氣腫（無下肺纖維化）、單純 IPF/UIP（無明顯上肺氣腫）——CPFE 為兩者並存之獨立症候群。[^1]

## 臨床重點（5 句）
1. **本質（Jankowich）**：**臨床/影像/病理日益認識氣腫與肺纖維化並存 → CPFE 症候群**（呼吸困難 + 上肺氣腫 + 下肺纖維化 + 氣體交換異常）。[^1]
2. **族群（Jankowich）**：**典型為男性吸菸者**；佔瀰漫性間質肺病約 5-10%。[^1][^2]
3. **併發（Jankowich）**：**常併肺高壓、acute lung injury、肺癌**。[^1]
4. **預後（Jankowich）**：**死亡率顯著、尤其有肺高壓者**。[^1]
5. **病因**：對香菸之內在易感性（吸菸誘發氣腫 + 纖維化）。[^1]

> [!note] 考點：關於肺間質纖維化與肺氣腫，何者「正確」?
> 「**兩者常共存且應視為一個獨立疾病實體（CPFE）**」正確。肺氣腫非較少見、非總在上肺、非「只是兩病剛好同時出現」。[^1]
