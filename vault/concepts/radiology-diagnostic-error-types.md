# radiology-diagnostic-error-types

**放射診斷錯誤可大分為知覺型（perceptual）與認知型（cognitive/interpretive）兩類。判讀分水嶺：問『病灶到底有沒有被看到（detected）』——沒被看到、只在回溯時才發現＝perceptual error（最常見，占 60–80%）；病灶有被看到、但其意義被判讀錯誤＝cognitive error。兩者成因不同，區分成因是常見考點。**

## Summary
- **兩大類**：診斷放射學之錯誤大分為 **perceptual errors** 與 **cognitive（interpretive）errors**。[^2]
- **Perceptual error 最常見**：占放射科醫師錯誤的 **60%–80%**。[^2]（Radiopaedia 之 Renfrew/Kim–Mansfield 分類亦以 **type 4 under-reading（回溯可見的漏看）為最常見錯誤**，與此一致。[^1]）
- **Perceptual error 定義**：異常**僅於回溯時才被辨識、前瞻性判讀時未偵測到**——病灶「就是沒被看到」。[^2]
- **Cognitive error 定義**：異常**已被前瞻性偵測到，但其意義被錯誤判讀/誤認為良性**，導致錯誤診斷。[^2]
- **Perceptual error 成因**：(a) subtle findings、(b) satisfaction of search、(c) workplace distractions、(d) radiologist fatigue、(e) poor lesion conspicuity。[^2]
- **Cognitive error 成因**：lack of medical knowledge、radiologist bias、incorrect or incomplete clinical information。[^2]
- **考點關鍵（易混）**：subtle findings / satisfaction of search / distraction / fatigue / poor conspicuity 屬 **perceptual** error 成因，**不是** cognitive error 成因；把這組成因歸給 cognitive error 即為錯誤敘述。[^2]

## 影像診斷
（本主題為判讀過程/品質與安全概念，非單一影像所見；以下為對應之判讀策略。）
### 降低 perceptual error
- 建立**完整而有系統的搜尋型態（search pattern）**，避免因找到一個病灶即停止搜尋（satisfaction of search）；控制工作量與疲勞、減少干擾。[^2]

### 降低 cognitive error
- 善用**所有可對照之舊檢查**、於**各切面（all planes）**評估邊緣與形態、整合對比後/T2/T1 影像與臨床病史後再下判讀。[^2]

## 鑑別與報告要點
| 面向 | Perceptual error | Cognitive (interpretive) error |
|---|---|---|
| 本質 | 病灶未被偵測（回溯才可見） | 病灶已偵測、但意義判讀錯誤 |
| 佔比 | 最常見，60–80% | 較少 |
| 典型成因 | subtle findings、satisfaction of search、distraction、fatigue、poor conspicuity | lack of knowledge、bias、incorrect/incomplete clinical information |
| 對策 | 系統化搜尋型態、控管疲勞/干擾 | 對照舊片、多切面、整合臨床資訊 |
- **報告啟示**：辨識自身錯誤型態有助於針對性改善——知覺型靠流程與搜尋紀律，認知型靠知識、去偏誤與資訊整合。[^1][^2]

## 題目
> [!question]- Regarding the type of errors in false negative breast MRI, which of the following statements is incorrect? (2021-009)
> **D（Common causes of cognitive errors include subtle findings, satisfaction of search, workplace distraction, radiologist fatigue, poor lesion conspicuity）**——錯誤；這五項是 **perceptual（知覺）error** 的常見成因，而非 cognitive error。cognitive error 的成因為 lack of medical knowledge、radiologist bias、incorrect clinical information（即選項 E，正確）。A（perceptual error 最常見，占 60–80%）、B（perceptual error＝僅回溯可見、前瞻未偵測）、C（cognitive error＝已偵測到但意義誤判）皆正確。
