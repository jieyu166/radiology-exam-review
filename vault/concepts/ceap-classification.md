# ceap-classification

**CEAP 是慢性靜脈疾病（chronic venous disorders, CVD）的國際標準描述語言，四軸 C-E-A-P 各自獨立編碼：C（臨床外觀 C0–C6）、E（病因 congenital/primary/secondary/none）、A（解剖 superficial/perforator/deep/none）、P（病生理 reflux/obstruction/both/none）。** 判讀分水嶺：**CEAP 是「描述性分類」而非嚴重度評分**——它不衡量預後或治療反應（那是 VCSS 靜脈嚴重度評分與生活品質量表的工作）；四軸互相獨立，同一病人可以是「靜脈曲張（C2）但無逆流（Pn）」。放射科的角色集中在 **E、A、P 三軸**：都卜勒超音波是逆流/阻塞的黃金標準，**逆流時間閾值——深部靜脈 >1 秒、淺部/穿通/其他 >0.5 秒**是最常被考的數字；髂腔靜脈段（May-Thurner）超音波受限時才上 CT/MR venography。**2020 更新最需記三件事：C4c corona phlebectatica 新增、recurrent 用 "r" modifier（C2r/C6r）、numbered venous segments 改用縮寫。**

## Summary
- **四軸定義**：C = Clinical（臨床表現）、E = Etiology（病因）、A = Anatomy（解剖位置）、P = Pathophysiology（病生理）。[^1][^3]
- **沿革**：1994 年於夏威夷 Maui 美國靜脈論壇（American Venous Forum）共識會議首度發表 → 1996 更新 → 2004 大改版 → **2020 最新更新**。[^1][^2][^3]
- **Basic vs Advanced（2004 引入）**：Basic CEAP 為簡化版供臨床快速使用；Advanced（full）CEAP 加入 18 個具名靜脈節段以精確定位病灶。[^2][^3]
- **CEAP ≠ 嚴重度評分**：CEAP 是「描述性分類」；縱貫追蹤療效請用靜脈嚴重度評分（venous severity scoring）與生活品質評分。[^2]
- **影像對應**：都卜勒超音波為逆流/阻塞的首選（gold standard）；**逆流時間閾值——common femoral/femoral/popliteal vein >1 秒、其他任何層級 >0.5 秒**視為臨床顯著。[^4][^5]

> [!warning] 2004 → 2020 主要變更（併列對照）
> **C 軸**：新增 **C4c = corona phlebectatica（踝周扇形擴張細靜脈叢）**；新增 modifier **"r" 表復發**（recurrent varicose veins、recurrent venous ulcer）。[^1]
> **A 軸**：以**靜脈節段的通用縮寫**取代 2004 版的數字編號（1–18）。[^1]
> 2004 版本身相對 1994 的變更：refine C 分類定義、新增描述符 **n（no venous abnormality identified，無可辨識靜脈異常）**、加入分類日期與檢查等級（level of investigation）、並引入 **basic CEAP** 作為 advanced 版的簡化替代。[^2]

## CEAP 是什麼與沿革

- CEAP（Clinical–Etiology–Anatomy–Pathophysiology）是描述慢性靜脈疾病病人、並用於科學期刊臨床研究報告的國際公認標準。[^1]
- **時間線**：1993/1994 發展 → 1996 更新 → 2004 修訂 → 2020 更新。（2020 共識文件明列 "Developed in 1993, updated in 1996, and revised in 2004"；Radiopaedia 記共識會議於 1994 年 2 月夏威夷 Maui 美國靜脈論壇第六屆年會舉行，其後 1996 更新、2004 修訂。）[^1][^3]
- **2020 更新的產生流程**：2017 年 5 月美國靜脈論壇成立 CEAP Task Force，採用修訂式 Delphi 流程，遵循四項基本原則——**保留 CEAP 的再現性、與舊版相容、實證為本、臨床實用**——做出數項變更。[^1]

## C — Clinical（臨床）

七個臨床分級（C0–C6，數字越大病況越重）：[^3]

| 分級 | 定義 |
|---|---|
| **C0** | 無可見或可觸及的靜脈疾病徵象 |
| **C1** | 微血管擴張（telangiectasia）或網狀靜脈（reticular veins） |
| **C2** | 靜脈曲張（varicose veins）；與網狀靜脈以**直徑 ≥ 3 mm** 區別 |
| **C3** | 水腫（edema） |
| **C4** | 皮膚與皮下組織的續發性變化 |
| **C4a** | 色素沉著（pigmentation）±濕疹（eczema） |
| **C4b** | 脂肪皮膚硬化症（lipodermatosclerosis）或白色萎縮（atrophie blanche） |
| **C5** | 已癒合的靜脈潰瘍 |
| **C6** | 活動性靜脈潰瘍 |

- **2020 新增（C 軸）**：
  - **C4c = corona phlebectatica**（踝周/足內側的扇形擴張細小靜脈叢，被視為晚期慢性靜脈疾病早期徵象）——由 2004 的 C4a/C4b 二分擴為 **C4a / C4b / C4c** 三分。[^1]
  - **"r" modifier**：用於 **recurrent varicose veins（C2r）** 與 **recurrent venous ulcer（C6r）**，標記復發性病灶。[^1]
- **a/s 後綴（asymptomatic / symptomatic）**：可在 C 分級後加上修飾符標記有無症狀——**S = symptomatic（有症狀）、A = asymptomatic（無症狀）**。症狀包含痠脹、沉重感、疼痛、腫脹感、皮膚刺激、痙攣等歸因於靜脈疾病者。[^3]

> [!note] C2r / C6r 記法
> 復發性靜脈曲張寫作 **C2r**、復發性活動潰瘍寫作 **C6r**（2020 新增）。這是 2020 版辨識度最高的考點之一。[^1]

## E — Etiology（病因）

四類：[^3]

- **Ec = congenital（先天性）**
- **Ep = primary（原發性，原因不明的原發瓣膜/管壁病變）**
- **Es = secondary（續發性，有明確後天病因，如深部靜脈血栓後 post-thrombotic）**
- **En = no venous cause identified（未辨識出靜脈病因）**

> [!note] 2020 對 Es 的細分
> 交辦要點指出 2020 將 **Es 再分為 Es-i（intravenous，血管內成因，如 post-thrombotic）與 Es-e（extravenous，血管外成因，如外在壓迫）**。此細分屬 2020 版精修方向；本次可實際查證的 2020 共識**摘要層級**未逐字列出 Es-i/Es-e（摘要僅明列 C4c、r modifier、節段縮寫三項主要變更）。此二細分我**無法以已讀來源逐字證實**，故在此標記存疑，待全文查證後補正。[^1]

## A — Anatomy（解剖）

四類：[^3]

- **As = superficial veins（淺部靜脈）**
- **Ap = perforating veins（穿通靜脈）**
- **Ad = deep veins（深部靜脈）**
- **An = no venous location identified（無可辨識靜脈位置）**

- **Advanced CEAP 的具名節段**：進階版加入 **18 個具名靜脈節段**以定位靜脈病灶。[^3]
- **2020 變更**：以各節段的**通用縮寫**取代 2004 版的數字編號（原 1–18 numbered segments）。[^1]

## P — Pathophysiology（病生理）

四類：[^3]

- **Pr = reflux（逆流）**
- **Po = obstruction（阻塞）**
- **Pr,o = reflux and obstruction（逆流併阻塞）**
- **Pn = no venous pathophysiology identified（無可辨識靜脈病生理）**

## Basic vs Advanced CEAP

- **Basic CEAP**（2004 引入）：以最高等級的 C（單一 C 分級）＋ E、A、P 各記其主要類別，作為臨床快速溝通版本。[^2]
- **Advanced（full）CEAP**：C 軸可列出所有存在的臨床分級，A 軸以 18 具名節段精確定位，並附上**分類日期**與**檢查等級（level of investigation）**。[^2][^3]
- **檢查等級（Level of investigation）**：
  - **L I**：理學檢查 ±手持式都卜勒。
  - **L II**：非侵入性檢查（主要為 duplex 超音波，±體積描記 plethysmography）。
  - **L III**：侵入性檢查或複雜影像（venography、venous pressure、IVUS、CT/MR venography）。
  （注：level of investigation 為 2004 版正式納入的概念；上述 L I/II/III 的具體內容對應為本領域通行定義，2004 共識摘要僅點出「加入檢查等級」而未逐字列出各級細目，此處分級內容標記為通行慣例、非逐字引自摘要。[^2]）

## 完整編碼範例（如何寫出一個 CEAP code）

- **格式**：依序寫 C（可含 a/s 與 r modifier）、E、A、P，並附**分類日期**與**檢查等級**。
- **Basic 範例**：一位有症狀的原發性淺部靜脈逆流曲張病人 →
  **C2s, Ep, As, Pr**（2026-07-06, L II）。
- **Advanced 範例**：同一病人若 duplex 顯示逆流位於大隱靜脈（great saphenous vein）節段 →
  **C2s, Ep, As, Pr（GSV 節段）**，並註明分類日期 2026-07-06、檢查等級 L II。
- **復發範例（2020）**：先前手術後復發的活動潰瘍、post-thrombotic 病因、深部逆流併阻塞 →
  **C6r, Es, Ad, Pr,o**。
（上述範例依 C/E/A/P 四軸與 2020 modifier 規則自行組合示範，用以說明編碼方式；各軸分類定義出處見 [^1][^2][^3]。）

## 影像對應（Imaging role mapped to CEAP）

**放射科主要負責 E/A/P 三軸的客觀化，尤其 Pr（逆流）、Po（阻塞）與 A（定位）。**

### 都卜勒超音波（首選、gold standard）
- **最佳工具**：合併 grayscale＋pulsed Doppler＋color Doppler 超音波；高解析度系統、3–10 MHz 探頭。[^5]
- **逆流時間閾值（clinically significant reflux）**：
  - **深部靜脈（common femoral / femoral / popliteal vein）：> 1 秒**。[^4][^5]
  - **其他任何層級（淺部、穿通等）：> 0.5 秒**。[^4][^5]
  - 逆流時間（reflux time，取代舊稱 valve closure time）**越長代表病況越嚴重**。[^4]
- **誘發逆流**：由上方用 dependency test 或 Valsalva；由下方用氣壓袖帶或徒手加壓；釋放遠端加壓後不應出現逆行血流（正常）。[^5]
- **姿勢**：躺姿超音波懷疑靜脈功能不全時，**須改站姿確認**（尤其淺部靜脈與小腿深部靜脈）。[^5]
- **穿通靜脈**：**> 3.5 mm 通常為不全（incompetent）**，< 3.5 mm 通常正常；不全穿通靜脈較粗。[^5]
- **靜脈曲張定義**：皮下、多迂曲、管徑 **≥ 3–4 mm**。[^5]
- **阻塞徵象**：血栓或外在壓迫時 Doppler 頻譜由 phasic 變為連續、非 phasic；遠端加壓的 augmentation 減弱。[^5]

### CT / MR venography（何時用）
- 平片非特異：小腿可見實心波狀骨膜反應、營養不良性軟組織鈣化、靜脈石（phlebolith）、皮下水腫。[^4]
- 都卜勒對**髂腔靜脈段**評估能力有限（腸氣/體型遮蔽），懷疑**近端阻塞（May-Thurner／髂靜脈壓迫、post-thrombotic 髂段狹窄）**時進階至 **CT venography / MR venography**。CTV/MRV 可顯示狹窄、側枝、DVT 並排除外在壓迫成因（詳見 [[may-thurner]]）。[^4]

> [!note] CEAP 軸 ↔ 影像對照
> - **P（Pr/Po）**：duplex 逆流時間（深 >1s、淺 >0.5s）判 reflux；頻譜非 phasic、augmentation 減弱判 obstruction。[^4][^5]
> - **A（As/Ap/Ad）**：duplex 分辨淺部（saphenofemoral / saphenopopliteal junction）vs 深部逆流、標定不全穿通靜脈；髂腔段改 CTV/MRV。[^5]
> - **E**：post-thrombotic 再通/側枝形態 → Es；找不到者 → En。[^5]

## 報告與陷阱（Reporting pearls & pitfalls）

- **CEAP 是描述性、非嚴重度**：報告勿把 CEAP 當成嚴重度或療效指標；追蹤療效請另用 VCSS/QoL。[^2]
- **四軸獨立**：C2（外觀曲張）不必然伴 Pr；務必分別記錄 P 軸實際的逆流/阻塞證據。[^1][^3]
- **逆流時間分閾值**：深部 >1 秒 vs 淺部/其他 >0.5 秒——**別用單一 0.5 秒套所有靜脈**。[^4][^5]
- **姿勢陷阱**：躺姿易低估逆流，站姿確認；室溫保暖避免血管收縮致假陰性。[^5]
- **2020 記憶點**：C4c corona phlebectatica、"r" modifier（C2r/C6r）、節段改縮寫——三者最易入題。[^1]
- **a/s 後綴**：報告/編碼時標記有無症狀（S/A），影響臨床決策。[^3]
