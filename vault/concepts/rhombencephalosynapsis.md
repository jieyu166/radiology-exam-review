# rhombencephalosynapsis

**Rhombencephalosynapsis（菱腦融合症）＝小腦蚓部缺失 + 兩側小腦半球、齒狀核、上小腦腳融合成橫向連續的單一構造。可孤立（罕見）或為更廣泛畸形之一部分，且『常合併其他中樞神經異常』（並非孤立不合併）、部分為症候群性。** 判讀分水嶺：**軸位見小腦葉片橫跨中線連續、無蚓部、第四腦室呈鑰匙孔/菱形；常合併視丘融合、下丘融合、透明隔缺失、腦室擴大（導水管狹窄）、顱縫早閉；可為 Gómez-López-Hernández 症候群或 VACTERL 一部分。**

## Summary
- **核心病理**：**小腦蚓部缺失（前蚓部缺、後蚓部發育不全，nodulus 常仍形成）+ 兩側小腦半球、齒狀核、上小腦腳（SCP）融合**成橫向連續之單一構造。[^1][^2]
- **胚胎**：蚓部分化失敗所致，損傷約在孕 **28-44 天**；典型呈橫向連續之單一小腦（馬蹄/keyhole 第四腦室）。[^2]
- **是否孤立/症候群**：可**孤立（罕見）或為更廣泛腦畸形之一部分**；**多數非症候群性**但確有症候群型——**Gómez-López-Hernández 症候群**（菱腦融合 + 發展遲緩 + 頭皮脫髮 + 三叉神經感覺缺失 + 顏面/短頭）或 **VACTERL** 之一部分。[^1][^2]
- **常合併之其他 CNS 異常（非孤立）**：**視丘融合、下丘融合、透明隔缺失、腦室擴大（常因導水管狹窄）、顱縫早閉、椎體融合異常**。[^1][^2]
- **臨床**：軀幹/肢體共濟失調、異常眼動、頭部搖擺（head stereotypies）、動作發展遲緩；程度不一。[^2]

## 放射科醫師影像判讀重點
- **軸位標誌**：小腦葉片**橫向連續跨中線、無蚓部裂**；齒狀核/SCP 呈 V 形融合；第四腦室鑰匙孔/菱形。[^1][^2]
- **矢狀面**：正中矢狀無正常蚓部葉片，後顱窩結構異常。[^2]
- **合併異常搜尋**：視丘融合、透明隔缺失、導水管狹窄致水腦、顱縫早閉——見菱腦融合要主動找這些。[^1][^2]
- **症候群連結**：合併頭皮脫髮/三叉神經感覺缺失→想 Gómez-López-Hernández；合併脊椎/肛門/心/氣管食道/腎/肢體→VACTERL。[^1]
- **陷阱**：勿當孤立小腦異常，需系統性評估全腦與症候群特徵。[^1][^2]

## 臨床重點（5 句）
1. **定義**：蚓部缺 + 半球/齒狀核/SCP 橫向融合。[^1][^2]
2. **非孤立**：常合併視丘融合、透明隔缺失、水腦、顱縫早閉。[^1][^2]
3. **症候群**：可為 Gómez-López-Hernández 或 VACTERL 一部分。[^1][^2]
4. **臨床**：共濟失調、異常眼動、頭部搖擺、動作遲緩。[^2]
5. **判讀**：見菱腦融合要系統找合併異常與症候群特徵。[^1]

> [!note] 考點：關於 Rhombencephalosynapsis，何者「不正確」?
> 「**不合併其他中樞神經系統異常（It is not associated with other CNS anomalies）**」不正確——**常合併**視丘融合、下丘融合、透明隔缺失、腦室擴大、顱縫早閉，亦可為 Gómez-López-Hernández 症候群或 VACTERL 一部分。小腦蚓部缺失 + 半球/齒狀核/上小腦腳融合、共濟失調等臨床表現、多數非症候群性皆正確。[^1][^2]
