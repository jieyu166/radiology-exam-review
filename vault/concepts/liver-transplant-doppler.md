# liver-transplant-doppler

**移植肝的都卜勒評估要分三條血管各看一件事：肝動脈看「有無狹窄／血栓」、門靜脈看「吻合處有無局部加速」、肝靜脈看「波形有沒有 phasicity」。判讀分水嶺：正常肝動脈上升快（acceleration time <80 msec）、RI 0.5–0.7；狹窄／血栓時吻合處 PSV 升高、下游肝內動脈呈 tardus-parvus（RI <0.5、加速時間 >80 msec）。門靜脈狹窄＝局部 color aliasing 且狹窄處流速較狹窄前段增加 3–4 倍以上。肝靜脈維持 biphasic/triphasic 代表 outflow 通暢；轉為 monophasic 才提示 outflow/肝靜脈狹窄。** 超音波是移植後偵測早晚期併發症的首選初始影像。

## Summary
- **正常肝動脈**：快速收縮上升、acceleration time **<80 msec（0.08 秒）**、持續舒張血流、**RI 0.5–0.7**。[^2]（Radiopaedia 另載正常與移植後肝動脈 RI 常在 0.55–0.8）[^1]
- **正常門靜脈**：持續向肝（hepatopetal）血流，隨呼吸有輕度速度變化。[^2]
- **正常肝靜脈／IVC**：phasic（biphasic/triphasic）波形，反映心動週期——代表 outflow 通暢。[^2]
- **肝動脈狹窄／血栓（選項 A）**：吻合處 **PSV 升高（>2 m/sec）**、下游肝內動脈 **tardus-parvus**（acceleration time >0.08 秒、**RI <0.5**）；狹窄最常見於吻合處，肝動脈血栓（HAT）為最常見血管併發症（約 2–12%）。[^1][^2]
- **門靜脈狹窄（選項 B）**：吻合處**局部 color aliasing**，狹窄處流速較 prestenotic 段增加 **3–4 倍以上**。[^2]
- **肝靜脈 outflow（選項 C、D）**：biphasic/triphasic＝outflow 通暢（C 正確）；轉為 **monophasic** 提示肝靜脈／outflow 狹窄。官方以「**venous pulsatility index <0.45＋monophasic**」代表肝靜脈狹窄。[^2]

## 影像診斷
### 肝動脈（hepatic artery）
- **正常**：acceleration time <80 msec、RI 0.5–0.7、持續舒張血流。[^2]
- **狹窄／血栓**：吻合處 PSV >2 m/sec、亂流/aliasing；肝內動脈 tardus-parvus（加速時間延長、RI <0.5、no flow 或收縮上升鈍化）。單用這些指標可能偽陽性，需綜合判讀。[^2]
- **假性動脈瘤**：內部亂流、可呈 monophasic，勿誤為靜脈 varix。[^2]

### 門靜脈（portal vein）
- **狹窄**：吻合處局部 color aliasing，狹窄處相對狹窄前段流速增加 >3–4 倍。需沿門靜脈全長以灰階＋頻譜仔細評估。[^2]

### 肝靜脈 / IVC
- **正常**：phasic（biphasic/triphasic）波形。**通暢的 outflow** 保留此 phasicity。[^2]
- **肝靜脈／流出道狹窄**：波形失去 phasicity 轉為 **monophasic**；官方引用 **venous pulsatility index <0.45＋monophasic** 為肝靜脈狹窄指標。[^2]

## 鑑別與報告要點

| 血管 | 正常 | 異常（狹窄）關鍵 |
|---|---|---|
| 肝動脈 | AT <80 msec、RI 0.5–0.7 | 吻合處 PSV >2 m/sec；下游 tardus-parvus、RI <0.5 |
| 門靜脈 | 連續向肝、呼吸變化 | 局部 aliasing、流速增 >3–4 倍 |
| 肝靜脈/IVC | biphasic/triphasic phasic | monophasic（失 phasicity）、venous pulsatility index <0.45 |

- 報告要點：移植肝都卜勒須逐一評估肝動脈（吻合＋肝內）、門靜脈（全長）、肝靜脈/IVC 波形。肝內動脈 tardus-parvus＋RI<0.5 提示近端肝動脈狹窄/血栓；門靜脈局部加速＞3–4 倍提示狹窄；肝靜脈由 phasic 轉 monophasic 提示 outflow 阻塞。[^2]

## 題目
> [!question]- Which of the description about the graft liver vessels is wrong? (2021-186)
> **D（A resistance index of less than 0.45 and monophasic pattern of hepatic vein indicative of hepatic vein stenosis——此敘述有誤）**——概念本身（monophasic 肝靜脈波形＋<0.45 提示肝靜脈狹窄）正確，但正確參數應為 **venous pulsatility index <0.45**，選項卻誤植為 **resistance index**（RI 用於動脈評估，非肝靜脈），故 D 為「錯誤」描述。A（吻合處 PSV 升高＋肝內動脈 tardus-parvus＝肝動脈狹窄）正確；B（吻合處 color aliasing＋流速增 >3 倍＝門靜脈狹窄）正確；C（肝靜脈 biphasic/triphasic＝outflow 通暢）正確。[^2] → [[liver-transplant-doppler]]
