# malrotation-volvulus

**腸旋轉不良（胚胎期 ~270° 逆時針旋轉失敗）使腸繫膜附著縮短 → 易發生中腸扭轉（midgut volvulus，可致命外科急症）；Ladd bands 致十二指腸阻塞/內疝。但並非每個疑似旋轉不良都需緊急介入——僅合併 volvulus/症狀者需緊急。** 判讀分水嶺：**midgut volvulus（膽汁性嘔吐新生兒）→ 緊急 UGI（gold standard）：DJ flexure 位置異常（正常應在中線左、L1 高度）、corkscrew/whirlpool、duodenum 不過中線；US 見 SMA/SMV 反位（whirlpool）；無症狀旋轉不良不需緊急手術。**

## Summary
- **本質**：胚胎期 ~270° 逆時針旋轉失敗 → **腸繫膜附著縮短 → 易 midgut volvulus（可致命）**、**Ladd bands** 致十二指腸阻塞/內疝。[^1][^2]
- **Midgut volvulus（急症）**：膽汁性嘔吐新生兒 → **緊急 UGI**；徵象 **whirlpool/corkscrew、duodenum 不過中線、DJ flexure 位置異常（正常在中線左、L1）、SMA/SMV 反位**。[^1][^2]
- **非每例都緊急介入**：**僅 volvulus/症狀者需緊急**；無症狀旋轉不良不需緊急手術（故「每個疑似都需緊急影像＋介入」最不恰當）。[^1]
- **合併阻塞**：**<5%** 先天十二指腸阻塞合併第二處遠端阻塞；duodenal atresia 與部分阻塞臨床/影像常難分。[^1]

## 放射科醫師影像判讀重點
- **UGI 為 gold standard**：看 DJ flexure 位置（正常中線左、L1 高度、與十二指腸球同高）；異常（右移/低於 L1）+ corkscrew → volvulus。[^2]
- **US 徵象**：SMA/SMV 反位（SMV 在 SMA 左側）、whirlpool sign（腸繫膜血管漩渦）。[^1][^2]
- **Ladd bands**：橫跨十二指腸致部分阻塞（double bubble 樣但遠端仍有氣）。[^2]
- **緊急分流（Brinkley）**：**膽汁性嘔吐（bilious emesis）為兒科放射常見評估原因**——多數先天十二指腸阻塞可擇期手術，但 **malrotation 併 midgut volvulus 需立即影像評估** → volvulus until proven otherwise → 外科 Ladd procedure。[^1]
- **先天十二指腸阻塞 DDx（Brinkley）**：**duodenal atresia/stenosis（double bubble、遠端無氣）、annular pancreas、preduodenal portal vein、duodenal web/windsock、Ladd bands（部分阻塞、遠端仍有氣）**——與 malrotation/volvulus 一併鑑別。[^1]
- **陷阱**：無症狀旋轉不良偶然發現，不需緊急介入；勿一律當急症。[^1]

## 臨床重點（5 句）
1. **機轉**：旋轉失敗 → 腸繫膜短 → volvulus/Ladd bands。[^1][^2]
2. **volvulus 急症**：膽汁性嘔吐 → 緊急 UGI（whirlpool/corkscrew）。[^1][^2]
3. **非每例緊急**：僅 volvulus/症狀者。[^1]
4. **<5%** 合併遠端阻塞。[^1]
5. **處置**：Ladd procedure（症狀性）。[^1]

> [!note] 考點：何者「最不恰當」?
> 「**每個疑似旋轉不良都需緊急影像評估與介入**」最不恰當——僅 volvulus/症狀者需緊急。volvulus 需緊急影像、<5% 合併遠端阻塞、duodenal atresia 與部分阻塞難分皆正確。[^1]
