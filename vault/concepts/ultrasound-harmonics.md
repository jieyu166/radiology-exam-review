# ultrasound-harmonics

**組織諧波影像（THI）利用聲波在組織中『非線性傳播』產生的諧波——第二諧波頻率為基頻的兩倍，因頻率與波長成反比，故波長變為基頻的『一半』。** 判讀分水嶺：**諧波＝基頻的倍數；frequency=2a→wavelength=x/2、frequency=3a→x/3……頻率 n 倍對應波長 1/n。第二諧波（振幅最大之可用諧波）成像因較窄波束、較少旁瓣/混響偽影、較佳對比解析度而廣泛臨床使用（尤其肥胖/難掃描病人）。**

## Summary
- **諧波產生機轉**：聲波非線性傳播——高壓部分傳播較快使波形扭曲 → 產生**諧波（基頻的倍數）**；**第二諧波＝基頻兩倍**（後續諧波振幅遞減、不足以成像故用第二諧波）。[^1][^2]
- **頻率-波長反比**：基頻 f=a、λ=x → **第二諧波 f=2a、λ=x/2（減半）**；第三諧波 f=3a、λ=x/3，以此類推。[^1][^2]
- **臨床應用（THI）**：改善**對比解析度、減少旁瓣與混響（clutter）偽影**，尤其對肥胖/困難掃描病人有幫助。[^1][^2]
- **深度分佈**：組織內諧波隨深度增加至最大強度後再遞減。[^2]

## 放射科醫師影像判讀重點
- **為何選第二諧波**：振幅最大之諧波，訊噪比足以成像；更高階諧波太弱。[^2]
- **影像優勢**：窄波束 + 少旁瓣/混響 → 邊界更清、囊腫內更乾淨（減少假回音）。[^2]
- **困難病人**：肥胖、腹壁厚者 THI 改善穿透與對比。[^2]
- **物理提醒**：頻率↑則波長↓、且衰減↑（穿透↓）——THI 以組織產生之諧波兼顧解析與偽影抑制。[^1]
- **考點**：諧波成像波長「減半」（非兩倍/四倍/1/4）。[^1]

## 臨床重點（5 句）
1. **第二諧波**：頻率 2×、波長減半。[^1][^2]
2. **機轉**：非線性傳播致波形扭曲產生諧波。[^2]
3. **優勢**：對比解析度佳、旁瓣/混響少。[^2]
4. **適用**：肥胖/困難掃描病人。[^2]
5. **反比**：頻率 n 倍 → 波長 1/n。[^1]

> [!note] 考點：使用超音波諧波(harmonics)，波長會如何變化?
> **減半（It is halved，B）**——第二諧波頻率為基頻兩倍，波長依反比關係變為基頻的一半（非四倍、非四分之一、非兩倍）。[^1][^2]
