# thyroid-cancer-tnm-staging

**判讀分水嶺：分化型甲狀腺癌（PTC/FTC）的 T 分期以「腫瘤大小 + 甲狀腺外侵犯（ETE）程度」界定——只侵犯 strap 帶狀肌（sternohyoid、sternothyroid、thyrohyoid、omohyoid 任一）＝T3b；一旦超過帶狀肌侵入皮下、喉、氣管、食道或喉返神經才升到 T4a。故侵犯 sternothyroid（胸骨甲狀肌，屬帶狀肌）＝T3b＝T3。**

## Summary
- **T3b＝gross ETE 只侵犯帶狀肌**（sternohyoid / sternothyroid / thyrohyoid / omohyoid），仍屬 **T3**。[^1][^2]
- **T3a**＝腫瘤 >4 cm 但仍限於甲狀腺內；**T2**＝2–4 cm；**T1**＝≤2 cm（T1a ≤1 cm、T1b 1–2 cm）。[^1][^2]
- **T4a**＝超過帶狀肌侵犯皮下軟組織、喉、氣管、食道或喉返神經；**T4b**＝侵犯椎前筋膜或包繞頸動脈／縱膈血管。[^1][^2]
- **年齡是分期關鍵**：AJCC 第 8 版以 **55 歲**為分界（第 7 版為 45 歲）；<55 歲僅分 stage I（M0）與 II（M1）；≥55 歲時 T3（含 T3a/T3b）any N M0＝stage II。[^1][^2]
- 本題「侵入 sternothyroid muscle」即 gross ETE 侵犯帶狀肌 → **T3（T3b）**。[^1][^2]

## 放射科醫師影像判讀重點
- **US 為第一線**：評估原發灶大小、被膜外侵犯（甲狀腺輪廓中斷、與帶狀肌介面消失）、頸部淋巴結（微鈣化、囊變、周邊血流、圓形）。[^2]
- **CECT/MRI** 用於評估大體 ETE 與侵犯範圍：氣管、食道、喉返神經溝、椎前筋膜、頸動脈包繞（>180° 提示不可切除傾向）——用以區分 T3b（僅帶狀肌）vs T4a/T4b。[^1][^2]
- **淋巴結分期**：N1a＝central compartment（level VI/VII，pretracheal/paratracheal/Delphian）；N1b＝lateral（level I–V）或咽後淋巴結。[^1]
- **核醫**：I-123（優先）或 I-131 全身掃描偵測殘餘甲狀腺、淋巴結與遠端／復發轉移；約 25% 復發/轉移為非碘親和 → 需 **F-18 FDG PET/CT**（Tg >10 ng/mL 且 RAI 掃描陰性時），FDG 陽性者預後較差。[^2]
- **陷阱**：strap 帶狀肌侵犯只到 T3b，勿誤升級為 T4a；T4a 的門檻是超過帶狀肌（喉/氣管/食道/皮下/RLN）。[^1][^2]
