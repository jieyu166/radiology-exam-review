# transcatheter-mitral-valve-replacement

**經導管二尖瓣介入分兩大類：修補（TMVr，含 MitraClip edge-to-edge/TEER）與置換（TMVR）；CT 是術前規劃的關鍵，用來量測二尖瓣環、模擬 neo-LVOT 以預測置換後 LVOT 阻塞。** 記憶鉤：這題四選項其實混用了 **MitraClip 修補的 Table 1「有利解剖 vs 禁忌」**——有利＝二尖瓣口面積 **>4 cm²**、可動瓣葉長 **>1 cm**；禁忌＝**風濕性二尖瓣疾病**、瓣葉鈣化。判讀分水嶺一：**風濕性二尖瓣病是禁忌（正解 B）**；判讀分水嶺二：**LVOT 阻塞是重大（非次要）併發症，以術後 LVOT 壓差上升 ≥10 mmHg 定義（非 50 mmHg）**。

## Summary
- **TMVI 分修補（TMVr）與置換（TMVR）**：修補含 transcatheter edge-to-edge repair（TEER，如 MitraClip）、環成形、腱索修補等；TMVR 為經導管植入人工瓣，用於不適合外科手術、且不適合修補的重度二尖瓣逆流，或用於鈣化性二尖瓣狹窄、瓣環／生物瓣失效（valve-in-ring / valve-in-valve）。[^1][^2]
- **MitraClip 修補的有利解剖（Table 1）**：病變位於 **A2–P2**、coaptation length >2 mm、flail gap <10 mm、flail width <15 mm、**mitral orifice area >4 cm²**、**mobile leaflet length >1 cm**——故「口面積 <1 cm² 有利」「可動瓣葉 >1 cm 為禁忌」皆錯。[^1]
- **MitraClip 修補的禁忌（Table 1）**：**rheumatic mitral disease（風濕性二尖瓣疾病）**、mitral leaflet calcifications——故「風濕性二尖瓣疾病為禁忌」正確。[^1]
- **CT 術前規劃核心**：量測二尖瓣環面積／周長／trigone-trigone、intercommissural、septolateral 距離；評估 landing zone、subvalvular apparatus，及與 coronary sinus、左迴旋支的關係。[^1]
- **neo-LVOT 與 LVOT 阻塞**：植入瓣使前葉（AML）前偏、拉長並窄化 LVOT＝**neo-LVOT**；於 CT 放置 virtual prosthesis 模擬、量測收縮末最窄橫切面積（理想候選 **>200 mm²**）。**小 neo-LVOT 導致的 LVOT 阻塞是 TMVR 後重要的死亡／併發症來源（重大併發症）**。[^1]
- **LVOT 阻塞定義**：以術後 LVOT 壓差上升 **≥10 mmHg**（MVARC 定義）判定，非 50 mmHg；且屬**重大**併發症而非次要。[^3]

## 影像診斷
### CT（術前規劃主力）
- **二尖瓣環量測**：D 形瓣環的面積、周長、trigone-trigone 距離、intercommissural 與 septolateral 徑，用於選瓣與定尺寸。[^1]
- **neo-LVOT 模擬**：放置 virtual prosthesis（各裝置形狀由簡單圓柱到複雜結構），於收縮末三腔長軸生成 neo-LVOT 中心線、量測最窄橫切面積；**≥200 mm² 通常低阻塞風險**。[^1]
- **增加 LVOT 阻塞風險的因子**：裝置面（flaring、protrusion、skirt 大）與病人面（**aortomitral angle 趨近或 >90°**、**基部間隔厚 >14 mm**、**AML 長 >30 mm**）。[^1]
- **周邊結構**：評估 coronary sinus、左迴旋支與 landing zone 關係，並模擬透視角度；經心尖入路者需評估胸壁。[^1]

### 超音波（TTE / TEE）
- **經胸超音波（TTE）為第一線**：定性與定量二尖瓣病變；CT 與之互補（高等向空間解析、大 FOV、多平面重組）。[^1]
- 影像可見瓣葉增厚、鈣化、活動受限（風濕性二尖瓣狹窄）或瓣葉脫垂／flail。[^1]

## 鑑別與報告要點
| 選項考點 | 正確事實 | 對錯 |
| --- | --- | --- |
| Mitral orifice area <1 cm² 為有利 | 有利為 **>4 cm²** | ✗（A 錯） |
| Rheumatic mitral disease 為禁忌 | 正確，Table 1 明列 | ✓（**B 正解**） |
| Mobile leaflet length >1 cm 為禁忌 | **>1 cm 是有利解剖** | ✗（C 錯） |
| LVOT 阻塞為次要併發症、壓差 ≥50 mmHg | 為**重大**併發症、壓差 **≥10 mmHg** | ✗（D 錯） |

> [!note] 題幹用詞陷阱
> 本題稱「TMVR」，但選項 A/B/C 的數據其實出自 RadioGraphics Table 1 的 **MitraClip 經導管二尖瓣「修補」**有利解剖／禁忌準則；答題仍以該表為準，正解 B。[^1]

## 題目
> [!question]- Which of the following is true about transcatheter mitral valve replacement? (2021-346)
> **B（Rheumatic mitral disease is a contraindication of the procedure）**——依 RadioGraphics Table 1，風濕性二尖瓣疾病與瓣葉鈣化為禁忌。A 錯：有利解剖為二尖瓣口面積 **>4 cm²**（非 <1 cm²）；C 錯：可動瓣葉長 **>1 cm 是有利解剖**（非禁忌）；D 錯：LVOT 阻塞為**重大**併發症，定義為術後 LVOT 壓差上升 **≥10 mmHg**（非次要、非 50 mmHg）。[^1][^3]
