# leukemia-skeletal-manifestations

**白血病的骨骼變化本質是「腫瘤細胞取代骨髓」的影像投影：在兒童身上因紅骨髓活躍、分布廣，故骨變化比成人更常見、更廣泛、更多樣。判讀分水嶺：X 光大多正常，最常見（也最早）的是 osteopenia；兒童的招牌是 metaphyseal radiolucent bands（快速生長的幹骺端）。別忘了 osteosclerosis（粗糙骨小樑）與 vertebra plana 也是公認表現。** 骨變化可先於（或不伴隨）周邊血象異常出現，因此在不明原因骨痛／拒走的孩子看到這組徵象要想到白血病。

## Summary
- **兒童 > 成人**：白血病的骨骼變化因兒童紅骨髓活躍而更常見、更廣泛、更多變；radiolucent metaphyseal bands 為「典型兒童」表現（ALL 病童可達約 40%）。[^1][^2]
- **最常見的 X 光發現＝osteopenia**：但多數 X 光即使回溯判讀仍為正常，故 X 光陰性不能排除。[^1][^2]
- **Metaphyseal radiolucent（leukemic）bands**：位於生長最快的長骨幹骺端，反映該處的骨質疏鬆；治療後可轉為 alternating radiolucent/radiodense（生長停滯線）。[^1][^2]
- **Periosteal reaction**：骨膜下白血病浸潤所致。[^1][^2]
- **Coarse trabeculation → osteosclerosis**：骨小樑增多可呈骨硬化外觀（與 secondary myelofibrosis 相關）——故「osteosclerosis 為公認表現」正確。[^1][^2]
- **Vertebral body collapse（vertebra plana）**：白血病骨髓浸潤為 vertebra plana 的鑑別之一。[^1][^2]
- **可先於周邊血象變化**：骨骼變化可在周邊血液抹片改變之前出現（classical teaching；本題採此觀點）。[^1]
- **亞型流行病學**：ALL 好發兒童（約占兒童白血病 80%）；AML 好發成人、亦為兒童第二常見；CML 好發成人；CLL 好發高齡（>75 歲）。[^3]

## 影像診斷
### X 光（radiograph）
- **osteopenia**（最常見，但常陰性）、**radiolucent metaphyseal bands**（幹骺端橫向透亮帶，兒童）、**periosteal reaction**、**coarse trabeculation / osteosclerotic 外觀**、**vertebra plana**。[^1][^2]
- 骨質破壞可為 permeative osteolytic（滲透性）或局部溶骨、病理性骨折。[^2]

### MRI
- 骨髓瀰漫浸潤：**T1 瀰漫低訊號、T2 增高訊號、T1 C+（Gd）瀰漫強化**。[^1]
- MRI 對骨髓取代最敏感，可在 X 光陰性時偵測。[^1][^2]

### 骨骼外肌肉侵犯
- **Intramuscular leukemic infiltrates**：罕見，肌肉內腫塊樣沉積，通常強化，T1 與肌肉等訊號、T2 高訊號。[^1]
- **Leukemia cutis**：皮膚白血病細胞沉積。[^1]

## 鑑別與報告要點

| 徵象 | 白血病骨髓浸潤 | 意義／陷阱 |
|---|---|---|
| Osteopenia | 最常見，X 光常仍陰性 | 陰性 X 光不能排除；MRI 較敏感 |
| Metaphyseal radiolucent bands | 兒童典型（ALL ~40%） | 非特異，鑑別含其他系統性疾病；治療後轉為生長停滯線 |
| Periosteal reaction | 可見 | 需與感染／外傷區分 |
| Coarse trabeculation / osteosclerosis | 公認表現 | 與 secondary myelofibrosis 相關 |
| Vertebra plana | 鑑別之一 | 與 LCH、轉移、感染鑑別 |

- 報告要點：兒童不明骨痛／拒走／關節痛合併瀰漫 osteopenia、幹骺端透亮帶或不明骨膜反應時，需將白血病列入鑑別並建議血液學檢查；X 光陰性可加做 MRI 評估骨髓。[^1][^2]
