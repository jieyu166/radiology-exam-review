# ivc-leiomyosarcoma

**IVC leiomyosarcoma依侵犯節段分三段，各自對應一個特徵性臨床症候群：上段（肝靜脈到右心房）→Budd-Chiari症候群；中段（肝靜脈到腎靜脈）→腎病症候群；下段（腎靜脈以下）→下肢水腫。記憶鉤：「愈往上愈靠近心臟愈危險（Budd-Chiari），愈往下愈單純（腿腫）」。**

## Summary
- **上段（upper segment）**：肝靜脈至右心房之間 → 阻塞肝靜脈回流 → **Budd-Chiari症候群**。[^1]
- **中段（middle segment）**：肝靜脈至腎靜脈之間 → 阻塞腎靜脈回流 → **腎病症候群（nephrotic syndrome）**。[^1]
- **下段（lower segment）**：腎靜脈以下（infrarenal） → 阻塞下肢靜脈回流 → **下肢水腫**。[^1]
- 上述三段-症候群對應關係為官方詳解確認之正確敘述（本題官方答案為「以上皆對」）。[^1]

> [!note] 考點：IVC leiomyosarcoma三段分類敘述何者「不正確」？
> **以上敘述皆正確（D）**——上段(肝靜脈-右心房)致Budd-Chiari症候群、中段(肝靜脈-腎靜脈)致腎病症候群、下段(腎靜脈以下)致下肢水腫，三者皆為正確描述。[^1]

## 放射科醫師影像判讀重點

### 節段定位與生長型態（CT/MRI）
- **判讀首務＝以肝靜脈與腎靜脈為界定位腫瘤節段**（上/中/下段），因節段直接對應臨床症候群與手術重建策略;矢狀/冠狀重組（MPR）最能顯示縱向侵犯範圍與上下界。[^1]
- **生長型態分完全腔外（extraluminal，最常見）、完全腔內（intraluminal）、腔內外併存**;IVC 平滑肌肉瘤常以**大的腔外軟組織腫塊**表現,增強呈不均質強化（含壞死/囊變）,勿僅以管腔內填充為唯一判準。[^1]
- **與腔內瘤栓/血栓鑑別**：腫瘤本身及瘤栓可見**強化**（血栓一般不強化）;IVC 因腫瘤擴張、管壁被破壞、周邊側枝靜脈形成為惡性徵象。[^1]

### DDx 與判讀陷阱
- **上段**侵犯肝靜脈匯流／右心房 → 影像上見肝臟鬱血、尾葉肥大等 **Budd-Chiari** 續發變化,勿把續發肝變化誤判為原發肝病。[^1]
- **DDx**：腎細胞癌/肝細胞癌之 IVC 瘤栓（有原發腫瘤可循）、後腹腔其他肉瘤（脂肪肉瘤等）、IVC 平滑肌瘤病（leiomyomatosis,女性、子宮靜脈延伸）、單純血栓——鑑別靠**原發灶、強化型態與 IVC 起源**。[^1]

## 臨床重點（5 句）
- IVC leiomyosarcoma 為**罕見後腹腔惡性腫瘤**,起源自血管平滑肌,是**IVC 最常見的原發惡性腫瘤**。[^1]
- **好發於中老年女性**,臨床表現常非特異（腹痛、腹部腫塊、下肢水腫）,常延遲診斷。[^1]
- **節段決定症候群**：上段→Budd-Chiari、中段→腎病症候群、下段→下肢水腫,為病史問診與定位的臨床連結。[^1]
- 治療以**完整手術切除併 IVC 重建**為主,預後與切除完整度相關。[^1]
- 因生長緩慢且症狀非特異,發現時常已較大,整體**預後不佳、易局部復發與遠端轉移**。[^1]
