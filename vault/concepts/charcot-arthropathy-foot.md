# charcot-arthropathy-foot

**足部 Charcot（神經病變）關節病最常繼發糖尿病；影像有兩型——atrophic（骨端『吸收 reabsorption』，多在前足/MTP）與 hypertrophic（6D：density/debris/dislocation/disorganization/destruction/distension，多在承重中足）。跗蹠關節（Lisfranc/TMT）侵犯典型造成蹠骨背外側脫位 → 縱弓完全塌陷（"rocker-bottom" foot）。** 判讀分水嶺：**病灶為受侵犯『骨端吸收（reabsorption）』而非蹠骨 metaphysis 破壞；好發糖尿病、足部常見潰瘍；痛感常小於破壞程度；抬高患肢腫脹減輕、發炎指數正常/輕升 → 偏 Charcot 而非感染。**

## Summary
- **好發族群**：**最常繼發糖尿病**（西方社會最常見病因）；一般糖尿病 ~0.1%、高風險族群達 15%。[^1][^2]
- **臨床**：單側（雙側 ~20%）腫脹、發熱、紅斑之足（易誤為 cellulitis/gout/DVT）；**痛感常小於關節破壞程度**；足部常見潰瘍（神經病變）。[^1][^2]
- **最初侵犯/型態**：**受侵犯骨端呈『reabsorption（骨端吸收）』**（atrophic 型，多前足/MTP），**非蹠骨 metaphysis 破壞**；hypertrophic 型呈 6D（承重中足）。[^1][^2]
- **Lisfranc/TMT 侵犯**：退化亦見跗蹠與跗骨間關節；**Lisfranc 侵犯致蹠骨背/外側脫位 → 縱弓完全塌陷（rocker-bottom foot）**。[^1]

## 放射科醫師影像判讀重點
- **兩型辨識**：atrophic＝骨端吸收（pencil-point/sucked candy，前足）；hypertrophic＝6D（distension/density/debris/dislocation/disorganization/destruction，中足承重）。[^2]
- **rocker-bottom**：中足（Lisfranc/TMT）塌陷 + 蹠骨背外側脫位 → 足底凸出，易潰瘍/骨突。[^1]
- **Charcot vs 骨髓炎**：難分——抬高減腫、發炎指數正常/輕升、無鄰接潰瘍/竇道偏 Charcot；MRI 看 ghost sign、subchondral cyst；ulcer + 鄰骨訊號 + 竇道偏 OM。[^2]
- **分佈**：糖尿病足以**中足（TMT/Lisfranc）**最常見，前足 MTP 呈 atrophic 吸收。[^1][^2]
- **臨床整合**：無痛性破壞 + 糖尿病神經病變 + 中足塌陷 → Charcot。[^1]

## 臨床重點（5 句）
1. **病因**：最常繼發糖尿病。[^1][^2]
2. **型態**：atrophic 骨端吸收 vs hypertrophic 6D。[^1][^2]
3. **rocker-bottom**：Lisfranc 侵犯致縱弓塌陷。[^1]
4. **痛<破壞**：無痛性破壞為線索。[^1][^2]
5. **vs 骨髓炎**：抬高減腫、發炎指數正常偏 Charcot。[^2]

> [!note] 考點：關於足部Charcot關節病變，何者「為偽」?
> **C 為偽**——病變表現為受侵犯骨端「**reabsorption（骨端吸收）**」（非蹠骨 metaphysis 破壞）。糖尿病最常見病因(A)、足部常見潰瘍(B)、關節初診即可見顯著破壞(D)皆為真。[^1][^2]
