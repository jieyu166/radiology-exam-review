# sciwora

**SCIWORA＝『無影像（平片 + CT）異常的脊髓損傷』，好發兒童（韌帶鬆弛/脊柱彈性大/頭身比大）；MRI 是評估必要工具（適應症）；兒童 SCI 整體相對少見。** 判讀分水嶺：**兒童 SCI 相對少見（SCIWORA 約占 SCI 10%）；SCIWORA＝MRI 適應症（X 光/CT 陰性但有持續脊髓病神經症狀）；<8 歲最易；運動傷害約 75%、兒虐近 100% 為 SCIWORA；生長陡增期前受傷者 ~97% 日後脊柱側彎（之後 ~52%）。**

## Summary
- **定義**：脊髓損傷但**平片 + CT 無異常**；**MRI 為適應症**（外傷後持續客觀脊髓病、影像陰性時）；約占 SCI **~10%**。[^1][^2]
- **好發兒童**：因**韌帶鬆弛 + 頭身比大 + 脊柱彈性**；**<8 歲最易**；兒童 SCI 整體相對少見。[^1][^2]
- **機轉族群**：運動傷害約 **75%**、**兒虐近 100%** 為 SCIWORA（故「兒虐少見 SCIWORA」錯）。[^1]
- **後遺脊柱側彎**：生長陡增期『前』受傷者 **~97% 發展脊柱側彎**（之後 ~52%）→ 側彎『常見』。[^1]

## 放射科醫師影像判讀重點
- **MRI 必要**：X 光/CT 陰性但有脊髓症狀 → MRI 評估脊髓水腫/出血/韌帶損傷（決定預後）。[^1][^2]
- **兒童易感解剖**：韌帶鬆弛、椎體楔形/關節面水平、頭大 → 頸椎（尤其上頸段）易受牽拉/缺血。[^2]
- **陰性影像不排除**：平片/CT 正常不能排除脊髓損傷，臨床有症狀即 MRI。[^1]
- **後遺追蹤**：生長陡增前受傷者高比例側彎，需長期骨骼追蹤。[^1]
- **兒虐警覺**：疑兒虐 + 脊髓症狀 → 幾乎皆 SCIWORA，須 MRI + 骨骼調查。[^1]

## 臨床重點（5 句）
1. **定義**：影像（平片+CT）陰性之脊髓損傷、~10% SCI。[^1][^2]
2. **好發兒童**：韌帶鬆弛、<8 歲最易。[^1][^2]
3. **MRI 必要**：陰性影像 + 症狀即 MRI。[^1][^2]
4. **族群**：運動 75%、兒虐近 100%。[^1]
5. **後遺**：生長陡增前受傷 ~97% 側彎。[^1]

> [!note] 考點：兒童脊髓損傷描述，何者「最恰當」?
> ⚠️ 官方答案鍵跨年不一致（見 warning）。依文獻：B（SCIWORA 不需 MRI）、C（兒虐少見 SCIWORA）、D（側彎少見）皆錯；唯 **A『兒童脊髓損傷相對少見』為正確**。[^1][^2]

> [!warning] 官方答案鍵跨年不一致
> 2017 原版標 A（附註「D A??」自我不確定）、2020 重印版標 D（側彎少見）。依 J Neurotrauma 2011 數據，生長陡增前受傷 ~97% 發展側彎，故 D「側彎少見」實為錯誤、A 應為正確。兩年官方 key 矛盾，建議醫師覆核；本筆記暫依 2017 原標之 A。

## 題目
> [!question]- 關於兒童脊髓損傷，何者描述「最恰當」? (2017-168／2020重印，官方答案鍵改標D，見 warning)
> **A（兒童脊髓損傷相對少見）**——唯一正確。SCIWORA 是 MRI 適應症（非不需 MRI）、兒虐近 100% 為 SCIWORA（非少見）、生長陡增前受傷 ~97% 發展側彎（非少見）。⚠️ 官方答案鍵跨年矛盾，建議醫師確認。[^1][^2]
