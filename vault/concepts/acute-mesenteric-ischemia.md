# acute-mesenteric-ischemia

**急性 SMA 阻塞合併敗血性休克但『腸壁強化仍保留（無不可逆壞死影像證據）』時，應優先『緊急血管內再灌流（PTA + 支架 + 溶栓/取栓）』而非立即開腹取栓——因腸道仍可挽救、血管內治療風險較剖腹低。** 判讀分水嶺：**preserved bowel enhancement＝腸道仍灌流可救 → 血管內再灌流首選；出現腸壁不強化/pneumatosis intestinalis/portal venous gas/穿孔/腹膜炎＝不可逆壞死 → 才緊急剖腹（±腸切除）；NOMI 用血管擴張劑；插鼻胃/肛管僅支持性，非優先。**

## Summary
- **類型**：**栓塞（EAMI，SMA 最常）、動脈血栓（動脈粥狀硬化基礎）、non-occlusive（NOMI，15-30%，低流量/休克/血管收縮）、靜脈性**。[^1][^2]
- **嚴重度序列**：輕（黏膜暫時性）→ 全層壞死 → **pneumatosis intestinalis** → **portal venous gas** → 穿孔。[^2]
- **關鍵影像＝腸壁強化**：**preserved enhancement＝腸道仍存活可救**；**不強化/pneumatosis/portal venous gas＝全層壞死（不可逆）**。[^1][^2]
- **依存活性處置**：[^1][^2]
  - **腸道仍可救（preserved enhancement、無壞死徵象）** → **血管內再灌流首選**（SMA 溶栓/取栓 + PTA ± 支架）。
  - **不可逆壞死（不強化、pneumatosis、portal gas、穿孔、腹膜炎）** → **緊急剖腹（±腸切除）**。
  - **NOMI** → 血管擴張劑（papaverine/PGE1）+ 治療低流量病因。
- **非優先/支持性**：插鼻胃管+肛管為減壓支持，非解決血管阻塞之根本；已敗血性休克不宜消極觀察等惡化。[^1]

## 放射科醫師影像判讀重點
- **CTA 為首選診斷（STATdx）**：**CECT/CTA 為 AMI 第一線診斷**，可區分病因並規劃治療；embolus＝SMA 內中央凸面充盈缺損（距 SMA 起始 3-8 cm）、thrombosis＝SMA 起始處不顯影、dissection＝真假腔、SMV thrombosis＝低密度充盈缺損 + 管壁強化。[^3]
- **NECT 分期**：早期＝腸擴張/壁增厚/腹水/腸繫膜水腫（可逆）；晚期＝**pneumatosis intestinalis/pneumoperitoneum/intravascular gas（腸梗塞徵象）**。[^3]
- **存活判定**：腸壁仍強化 → 可救 → 血管內再灌流；不強化 + pneumatosis + portal gas → 壞死 → 手術。[^1][^2]
- **DSA（傳統金標）**：**lateral view 看 celiac/SMA/IMA 起始（origin 狹窄最佳）、AP view 看分支與側枝**；embolus＝圓形界清充盈缺損 ± 凸面 meniscus（距起始遠、middle colic 遠側）、thrombus＝起始處 tapered occlusion ± 側枝、NOMI＝瀰漫血管收縮 string of sausages。[^3]
- **NOMI 線索**：SMA 通暢但瀰漫小血管收縮/低流量、SMV 延遲顯影 → 血管擴張劑，非取栓。[^2][^3]
- **CMI 都卜勒篩檢**：SMA 空腹高阻力波形、餐後 EDV 上升；顯著狹窄 PSV/EDV 上升、起始閉塞見逆流。[^3]
- **陷阱**：把插管/觀察當優先；preserved enhancement 應積極血管內再灌流；**median arcuate ligament syndrome 勿放支架（會惡化）、應手術減壓**。[^1][^3]

## 臨床重點（5 句）
1. **高致死急症**：AMI **死亡率 60-80%、與診斷/治療時間直接相關**（<12 h 再灌流死亡率 39%、>24 h 診斷則 70%）；臨床＝突發劇烈中腹痛與理學檢查不成比例 + 白血球增多/乳酸酸中毒/肝酵素上升。[^3]
2. **病因比例**：**動脈栓塞 ~50%（SMA 高流量急角度最易，常心源性 AF/MI/瓣膜；栓子多卡在起始遠 6-8 cm、middle colic 遠側）、動脈血栓 ~25%（既有狹窄基礎、預後較差因較近端）、NOMI 25%（低血壓/升壓劑）、腸繫膜靜脈栓塞 5-10%（高凝/術後/腫瘤/口服避孕/敗血）**。[^3]
3. **CMI（intestinal angina）**：餐後 1-2 h 鈍痛 + **80% 因懼食而體重減輕**；歷史定義 3 條主血管（celiac/SMA/IMA）≥2 條狹窄，惟單條亦可致病；進展為 AMI 死亡率 >50%；動脈硬化型好發老年女性。[^3]
4. **內科即刻處置**：懷疑即開始**輸液復甦、廣效抗生素、鼻胃管減壓、抗凝、避免升壓劑（惡化血管收縮）**；SMV 栓塞第一線為系統性抗凝 + 支持。[^3]
5. **介入/預後**：血管內再灌流臨床獲益 40-90%、技術成功 80-100%、溶栓臨床成功 70%、血管擴張劑效率 70-80%；**再灌流傷害可用 IV glucagon/allopurinol 減輕**；PTA/支架後 1 年再狹窄 15-25%；SMA 栓塞治療優於 SMA 血栓。[^3]

> [!note] 考點：75歲男性 SMA thrombosis 合併敗血性休克，CT 顯示 bowel ileus 但 preserved bowel enhancement，何種治療最優先?
> **Emergent PTA for SMA trunk with stenting and thrombolysis（D）**——腸壁仍有灌流，優先血管內再灌流搶救腸道，而非立即開腹取栓或消極觀察等惡化。[^1][^2]

## 題目
> [!question]- 75歲男性急性腹痛兩天、生命徵象不穩合併敗血性休克，CT 顯示 SMA thrombosis、bowel ileus、preserved bowel enhancement，接下來甚麼治療最為優先? (2017-246)
> **Emergent PTA for SMA trunk with stenting and thrombolysis（D）**——preserved enhancement 代表腸道仍可挽救，優先血管內再灌流。插鼻胃/肛管非根本處置、外科取栓非此情境首選、消極觀察等惡化再手術不適合已敗血性休克病人。[^1][^2]

> [!question]- Which is the LEAST typical of early arterial small bowel ischemia? (2022-263)
> **D**——早期動脈性缺血腸壁多薄而非增厚；腸壁增厚屬較晚期/靜脈性/再灌流表現，故最不典型。[^3]

> [!question]- Which of the followings is NOT true while talking about mesenteric venous thrombosis (MVT)? (2021-194)
> **C（Systemic anticoagulation 為 MVT 之第二線治療）為錯**——系統性抗凝是 MVT 的主要（第一線）治療，非第二線。特徵影像為腸繫膜靜脈內充盈缺損 ± 腸壁增厚/腸緣模糊/腹水/腸繫膜增厚 (A對)、非手術治療存活較佳且併發症較少 (B對)、導管導向溶栓僅用於抗凝無效之頑固症狀但不需開刀者 (D對)。
