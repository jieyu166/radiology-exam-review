# tarsal-coalition-signs

**跗骨聯合的間接 X 光徵象要對號入座——「食蟻獸徵象（anteater sign）＝跟骨前突延長」指向跟舟骨聯合（calcaneonavicular），「C sign＝側位反 C 形硬化」指向距跟骨聯合（talocalcaneal）；兩大聯合各約 45%。** 判讀分水嶺：**單一部位聯合常在 AP＋側位兩張片上看不到直接橋接，必須靠間接徵象警覺，再以 CT/MR 直接確認（尤其纖維／軟骨性聯合）。**

## Summary
- **定義**：跗骨間異常橋接，多為胚胎期**分節失敗（failure of segmentation）**；橋接可為**骨性、軟骨性或纖維性**。[^1]
- **兩大好發**：**calcaneonavicular（跟舟）約 45%、talocalcaneal（距跟／subtalar）約 45%**；distal 廣泛聯合罕見。[^1]
- **鑑別對應**：**anteater sign → calcaneonavicular**；**C sign → talocalcaneal**。[^1]

## 放射科醫師影像判讀重點
- **直接顯示（投影選擇）**：**calcaneonavicular coalition 於 45° 內斜位（internal oblique）最佳**；**talocalcaneal（中 facet）於跟骨軸位（Harris-Beath view）最佳**；單一部位聯合常在標準 AP＋側位看不到 → **必須留意間接徵象**。[^1]
- **四大間接徵象**：[^1]
  - **Anteater sign**：跟骨前突延長似食蟻獸長吻 → **calcaneonavicular**。
  - **C sign**：側位載距突與距骨內下緣連成反 C 形硬化 → **talocalcaneal**。
  - **Talar beak**：距骨背側喙狀骨贅（力學重塑，非真骨關節炎）。
  - **Ball-and-socket ankle joint**：見於廣泛聯合。
- **CT／MR 為最佳特徵化工具**：可直接顯示聯合、區分骨性 vs 纖維/軟骨性（後者於 X 光可能只見關節面不規則、間隙變窄）；**MR 見聯合處骨髓水腫**提示症狀性。[^1]
- **雙側性**：**約 25% 為雙側**，即使臨床僅單側症狀，也應評估對側。[^1]

## 臨床重點（5 句）
1. 跗骨聯合舊稱 **spastic peroneal flatfoot**，因限制距下活動而致僵硬性扁平足與腓骨肌痙攣。
2. 多於**青少年至青年期**（聯合逐漸骨化、活動受限時）以僵硬扁平足或**反覆踝扭傷**表現。
3. 一般族群盛行率約 **1%**（可能低估，因許多無症狀）。
4. 纖維性／軟骨性聯合在 X 光上不易直接見，症狀持續者應以 **CT（骨性程度、術前規劃）或 MR（纖維/軟骨性、骨髓水腫）**確認。
5. 治療視症狀而定——保守（矯具、制動）無效可切除聯合，廣泛或退化嚴重者考慮關節融合。[^1]

> [!note] 考點："anteater sign" 是哪種跗骨聯合之徵象？
> **Calcaneonavicular coalition（A）**——跟骨前突延長形似食蟻獸長吻部，為跟舟骨聯合之特徵性側位/斜位 X 光間接徵象（C sign 則對應 talocalcaneal）。[^1][^2]
