# ipf-uip-pattern-criteria

**ATS/ERS/JRS/ALAT IPF 指引的 HRCT pattern 為四級：UIP / Probable UIP / Indeterminate for UIP / Alternative diagnosis；不含「NSIP pattern」。Honeycombing 是 definite UIP 的關鍵特徵。**

## Summary
- 2022 更新版 ATS/ERS/JRS/ALAT IPF 指引以 HRCT 分四類：**UIP、Probable UIP、Indeterminate for UIP、Alternative diagnosis** [^1]
- **NSIP pattern 不是 IPF 的 HRCT pattern 選項**；NSIP 為獨立的 IIP 亞型 [^1]
- 在恰當臨床情境下，HRCT 呈典型 UIP pattern 可不需外科肺切片即診斷 IPF [^1]
- 2022 版另定義 progressive pulmonary fibrosis（PPF），並將 transbronchial lung cryobiopsy 列為外科切片的可接受替代 [^1]

## 放射科醫師影像判讀重點
- **UIP pattern（definite）**：subpleural、basal 為主分布 + reticular + **honeycombing**（± traction bronchiectasis/bronchiolectasis），且無不符合特徵 [^1]
- **Probable UIP**：subpleural、basal 為主 + reticular + peripheral traction bronchiectasis/bronchiolectasis，但**無 honeycombing**；即缺 honeycombing 是 probable 與 definite UIP 的分界 [^1]
- **Indeterminate for UIP**：分布或特徵不確定，未達 probable，但也未提示替代診斷 [^1]
- **Alternative diagnosis（不符合 UIP）**：upper/mid-lung 為主、peribronchovascular 分布、廣泛 GGO、大量 micronodules、discrete cysts、瀰漫 mosaic/air-trapping、consolidation 等，指向 IPF 以外的診斷 [^1]
- 判讀陷阱：見到 honeycombing 即歸 definite UIP，不可誤列為 probable；NSIP 不在此 pattern 清單內 [^1]

## 臨床重點（5 句）
1. IPF 為老年、進行性、預後不良的 ILD，需多科（MDD）整合影像、病理、臨床診斷 [^1]
2. 典型 UIP HRCT + 恰當臨床情境可免外科肺切片直接診斷 IPF [^1]
3. 抗纖維化藥（nintedanib、pirfenidone）為 IPF 主要治療 [^1]
4. 非 IPF 的 ILD 若符合 PPF 條件（症狀、影像、生理三取二惡化）可考慮 nintedanib [^1]
5. Cryobiopsy 在有經驗中心可作外科肺切片的替代選項 [^1]

> [!note] 考點：下列何者「不是」ATS/ERS/JRS/ALAT IPF 指引的 HRCT pattern 分類？
> NSIP pattern —— 它是獨立的 IIP 亞型，不在 IPF 的 HRCT pattern（UIP / Probable UIP / Indeterminate / Alternative）之列。 [^1]

> [!question]- ATS/ERS/JRS/ALAT IPF 診斷標準的 HRCT pattern 分類「不包含」下列何者？ (2019-309)
> 答案：B. NSIP pattern（為獨立 IIP 亞型，非 IPF 的 HRCT pattern 選項）。 [^1]

> [!question]- 下列何者屬於 definite UIP pattern（而非 possible/probable UIP）的特徵？ (2019-492)
> 答案：C. Honeycombing（含或不含 traction bronchiectasis）—— 為 definite UIP 的關鍵特徵；probable/possible UIP 無 honeycombing。 [^1]
