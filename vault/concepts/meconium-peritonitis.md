# meconium-peritonitis

**Meconium peritonitis 因胎兒時期腸穿孔導致 chemical peritonitis。Fibroadhesive type 最常見。Water-soluble contrast enema 可用於鑑別診斷。嚴重者（calcification + ascites + pseudocyst）需要手術。**

## Summary
- 病因：utero 時期腸道穿孔，meconium 外漏引起化學性腹膜炎 [^1]
- 分型 [^1]：
  - **Fibroadhesive**（最常見）：纖維沾黏型
  - **Cystic（pseudocyst）**：meconium 被包裹形成假性囊腫
  - **Generalized**：廣泛鈣化
- 影像特徵：**腹腔鈣化**（peritoneal calcification）、ascites、pseudocyst [^1]
- Water-soluble contrast enema 可鑑別 meconium ileus vs other causes [^1]
- **需要手術的情況**：有 calcification + ascites + pseudocyst 等嚴重表現 [^1]

## 放射科醫師影像判讀重點
- **產前超音波徵象組合**：胎兒腹水（ascites）、**腹腔內鈣化**（intra-abdominal calcification）、腸管擴張（dilated bowel loops）、假性囊腫（pseudocyst）與羊水過多（polyhydramnios）為五大特徵；據 PubMed 一系列 14 例產前診斷，腹水見於 100%、腹腔鈣化 93%、腸管擴張 57%、假性囊腫 29%、羊水過多 50%。[^2]
- **鈣化是核心判讀線索**：腹腔線狀/斑點狀鈣化來自漏出胎便引發之化學性腹膜炎，出生後腹部 X 光亦可見；出現鈣化即高度提示子宮內腸穿孔病史。[^2]
- **分型影像對應**：fibroadhesive（最常見，纖維沾黏含鈣化）、cystic/pseudocyst（胎便被包裹成假囊）、generalized（廣泛鈣化）——影像上假囊壁鈣化與囊內液平為 pseudocyst 型特徵。[^2]
- **產前徵象具預後意義（判讀陷阱）**：早期偵測（孕早期）**不**等於預後差；腸管擴張與羊水過多**消退**者出生後多不需手術，故追蹤徵象動態變化比單看有無鈣化更能預測是否需手術。[^2]

## 臨床重點（5 句）
- 胎便性腹膜炎為子宮內胎兒腸穿孔漏出胎便引起的無菌性化學性腹膜炎，發生率罕見。[^2]
- 若延誤至出生後才診斷，可致嚴重新生兒罹病甚至死亡，故產前診斷有助及早安排術後處置。[^2]
- 據 PubMed 一系列產前診斷個案，整體存活率約 92.9%，預後大致良好。[^2]
- 早期（孕早期）偵測與不良預後無關，不需因此選擇終止妊娠。[^2]
- 腸管擴張與羊水過多消退者出生後手術率低，處置取決於出生後臨床與影像而非產前偵測時機。[^2]

## 陷阱
- 「所有 meconium peritonitis 都不需手術」此說法**錯誤**，嚴重者仍需手術介入
