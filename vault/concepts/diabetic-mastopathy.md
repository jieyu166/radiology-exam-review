# diabetic-mastopathy

**Diabetic mastopathy（糖尿病乳腺病變）是一種少見的良性乳房疾病，發生於長期胰島素依賴型糖尿病（type 1 或 type 2 insulin-dependent DM）病人，病理特徵為 lymphocytic mastitis（淋巴球性乳腺炎）合併 stromal fibrosis（間質纖維化）。臨床表現為大而無痛之「硬」塊，與乳癌臨床難以區分。** 判讀分水嶺：**超音波典型為 irregular hypoechoic mass 伴「顯著後方聲影（marked posterior acoustic shadowing）」——後方聲影反映病灶質地堅硬緻密，因此本病是「硬」而非「軟」的低回音病灶；把它當成「hypoechoic soft lesion」是錯誤描述。影像可與乳癌高度相似，須靠病史（長期胰島素依賴型 DM）＋core biopsy 確診而非誤判為惡性。**

## Summary
- **定義與族群**：少見良性乳房疾病，發生於長期 type 1 或 type 2 **insulin-dependent** DM 病人；亦曾報告見於男性。[^1]
- **病理**：屬 lymphocytic mastitis + stromal fibrosis；有緻密纖維化與以 **B 細胞為主**的淋巴球浸潤，圍繞導管、小葉與血管；病因不明、可能與免疫反應有關，並與 Hashimoto 甲狀腺炎、Sjögren 症候群、SLE 等自體免疫病歸為一類。[^1]
- **臨床**：大、無痛、**硬**塊，臨床上與 breast cancer 難以區分；多中心（multicentric）或雙側（bilateral）侵犯相對常見，常見於疾病晚期。[^1]
- **超音波（最具特徵）**：irregular hypoechoic mass 伴 **marked posterior acoustic shadowing**；可模擬惡性病灶——即本病為堅硬病灶，非「soft」。[^1]
- **乳房攝影**：最常見為 ill-defined mass 或 asymmetric density；常被緻密腺體組織遮蔽，使判讀困難。[^1]
- **MRI**：顯影表現多變，可從 decreased diffuse contrast enhancement 到 rapid, intense enhancement（與乳癌無法區分）。[^1]
- **處置與預後**：core biopsy 即足以診斷；FNA 因病灶極堅硬、取材細胞不足而較不適用；為自限性疾病、不一定需治療，但復發常見，手術反而可能增加復發。[^1]

## 影像診斷

### 乳房攝影（Mammography）
- 最常見 ill-defined mass 或 asymmetric density；於緻密乳房易被遮蔽，敏感度有限。[^1]

### 超音波（Ultrasound）
- 最具診斷特徵的模態：irregular hypoechoic mass 伴 **顯著後方聲影**；質地堅硬，聲影明顯是重要線索，但同時與惡性重疊，故不能單憑影像排除乳癌。[^1]

### MRI
- 顯影多變：由瀰漫性減弱強化到快速強烈強化皆有；快速強化型與乳癌無法區分，需結合病史與切片。[^1]

## 鑑別與報告要點

| 項目 | 重點 |
|---|---|
| 首要鑑別 | breast carcinoma（臨床/影像高度相似，靠病史＋core biopsy 區分）[^1] |
| 病史線索 | 長期 insulin-dependent DM（type 1 或 type 2），常合併其他 DM 晚期併發症 [^1] |
| 分布 | multicentric 或 bilateral 相對常見（晚期）[^1] |
| 切片選擇 | 首選 core biopsy；FNA 因病灶硬、取材不足較不佳 [^1] |
| 報告陷阱 | 超音波後方聲影＋不規則低回音會被誤判為惡性；「hypoechoic soft lesion」為錯誤描述（本病為硬塊）[^1] |

## 題目
> [!question]- Which of the following statement about diabetic mastopathy of the breast is **incorrect**? (2021-013)
> **C（Ultrasound showed a hypoechoic soft lesion）為錯誤**——超音波典型為 irregular hypoechoic mass 伴「顯著後方聲影」，反映病灶「硬」而非「軟」；正確描述應為堅硬（hard）低回音伴後方聲影。A（少見良性病、lymphocytic mastitis + stromal fibrosis）、D（MRI 為 ill-defined mass 伴顯影、表現多變）皆正確。B（好發於長期 type 1 DM）為此病的經典關聯敘述，一般視為正確；惟嚴格而言 Radiopaedia 指其亦見於 type 2 insulin-dependent DM，本題單一最不正確者仍為 C。[^1]
