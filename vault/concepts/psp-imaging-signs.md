# psp-imaging-signs

**進行性核上性麻痺（PSP）＝中腦被蓋（tegmentum）萎縮；矢狀面中腦上緣由正常「上凸」變為「扁平/凹陷」→ hummingbird / penguin sign，軸位中腦被蓋外側緣凹陷 → morning glory / Mickey Mouse sign。但「最準確」的不是這些定性徵象，而是「中腦面積：橋腦面積比」下降（PSP ≈ 0.12，正常 ≈ 0.24）。** 判讀分水嶺：**定性徵象憑印象、易有觀察者差異；定量指標（midbrain area < 70 mm²、midbrain:pons ratio < 0.15、MRPI/MRPI 2.0）才最準確，並能與 MSA-P（比值反而偏高 ~0.27、有橋腦小腦萎縮）、PD（無明顯中腦萎縮）區分。記憶鉤：矢狀面看蜂鳥、軸位看米奇、算比值最準（PSP 中腦瘦、橋腦相對胖）。**

## Summary
- **Hummingbird / penguin sign（矢狀）**：中腦上緣**由正常上凸變扁平/凹陷**、上丘變薄，腦幹輪廓似蜂鳥/企鵝。[^1][^2]
- **Morning glory / Mickey Mouse sign（軸位）**：中腦被蓋**外側緣異常凹陷**。[^1][^2]
- **最準確＝中腦:橋腦面積比**：PSP **0.124** vs PD 0.208 / MSA-P 0.266 / 正常 0.237；**中腦面積 < 70 mm²＋比值 < 0.15 → 診斷 PSP（敏感度 100%、特異度 91–100%）**。[^1]
- **MR parkinsonism index（MRPI）／MRPI 2.0**：進一步區分 PSP 與 MSA-P、PD。[^1]
- **DDx 關鍵**：MSA-P 有橋腦小腦萎縮（比值偏高）、PD 無明顯中腦萎縮。[^1]

## 放射科醫師影像判讀重點

### 定性徵象（sagittal / axial）
- **Hummingbird / penguin sign（矢狀 T1）**：中腦上緣正常為上凸，PSP 變**凹陷或扁平**，加上丘變薄，形似蜂鳥/企鵝側影。[^1]
- **Morning glory / Mickey Mouse sign（軸位 T1）**：中腦被蓋**外側緣凹陷**（正常外凸消失）。[^1]
- **上小腦腳（SCP）萎縮**：與病程長短相關。[^1]
- **CT/T2 附見**：中腦萎縮、mesencephalic cisterns 擴大、第三腦室擴大；T2 被蓋/導水管周圍高訊號、± 紋狀體低訊號。[^1]

### 定量指標（最準確，考點核心）
- **中腦:橋腦面積比**（矢狀正中面、voxel-based morphometry）：**PSP 0.124 << PD 0.208 / MSA-P 0.266 / 正常 0.237**。[^1]
- **診斷切點**：**中腦面積 < 70 mm²（約正常一半）＋ midbrain tegmentum:pons 比 < 0.15 → 診斷 PSP**（敏感度 100%、特異度 91–100%）。[^1]
- **AP 中腦徑 < 17 mm**（軸位 T2）：區分 PSP vs MSA 之 PPV 約 75%。[^1]
- **MRPI ＝（pons/midbrain 面積）×（MCP/SCP 寬）**：區分 PSP 與 MSA-P/PD/正常，文獻達 100% 敏感/特異/PPV；**MRPI 2.0 ＝ MRPI ×（第三腦室/額角寬）**，對早期 PSP-P vs PD 更佳。[^1]

### 進階序列
- **DWI/DTI**：putamen ADC 上升（可與 PD 區分）、SCP decussation mean diffusivity 上升。[^1]
- **核醫**：FDG-PET putamen/thalamus/medial frontal/midbrain 代謝下降；DaT（I-123-FP-CIT）SPECT 紋狀體攝取下降；tau-PET（flortaucipir）中腦攝取上升。[^1]

### 鑑別診斷（非典型帕金森）
- **MSA-P**：**putamen T2 低訊號、小腦與橋腦萎縮（hot cross bun）**、無明顯中腦萎縮（故比值偏高 ~0.27）；自律神經失調、小腦症狀。[^1]
- **皮質基底核退化（CBD）**：**不對稱額頂葉萎縮**、單側帕金森、alien limb、皮質感覺缺損。[^1]
- **路易體失智（DLB）**：皮質萎縮、無明顯中腦萎縮；幻覺、皮質型失智。[^1]
- **巴金森病（PD）**：無明顯中腦萎縮、震顫為主、對 levodopa 反應佳。[^1]

> [!note] 考點：Hummingbird sign（penguin sign）見於何種疾病？
> **Progressive supranuclear palsy（PSP）**——中腦被蓋萎縮致矢狀面腦幹上緣扁平/凹陷似蜂鳥/企鵝；與 morning glory/Mickey Mouse sign、中腦:橋腦面積比降低（~0.12，最準確）共構 PSP 判讀骨架。[^1][^2]

## 臨床重點（5 句）
1. **本質**：**非典型帕金森症候群、散發性 4-repeat（4R）tau 病變**（Steele-Richardson-Olszewski 症候群）；核心＝**垂直核上性凝視麻痺、姿勢不穩跌倒、僵硬、構音障礙、認知功能障礙**。[^1]
2. **亞型**：**PSP-RS（Richardson，典型）**＝蹣跚步態、軸性肌張力不全、垂直核上凝視麻痺；**PSP-P（帕金森型，約 1/3）**＝運動遲緩/僵硬、眼動正常、對 levodopa 短暫反應。[^1]
3. **流行病學**：**最常見之非典型帕金森症候群、整體第二常見之神經退化性帕金森症**；好發 45–75 歲、尖峰 65 歲、盛行率 3–7/10 萬、無性別偏好。[^1]
4. **病理**：4R tauopathy；**tufted astrocytes 為 PSP 標誌**；蒼白球/視丘下核/黑質有神經纖維纏結，皮質相對保留（除 perirolandic）；**tau H1 haplotype（第 17 號染色體，與 CBD 共享）**。[^1]
5. **病程/治療**：症狀發作後**存活約 5.3–9.7 年**、逾半數 2 年內出現神經精神症狀；治療為**症狀性**（levodopa 對僵硬/遲緩僅部分幫助、CoQ10 些微效益）；**對 levodopa 反應差**有助與 PD 區分。[^1]
