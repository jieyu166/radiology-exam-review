# scheuermann-disease

**Scheuermann disease（juvenile kyphosis / vertebral epiphysitis）＝青少年結構性後凸的最常見原因，結果是「胸椎後凸（thoracic kyphosis）」——不是脊椎側彎、也不是腰椎前凸或頸椎後凸。診斷靠 Sorensen 標準：連續 ≥ 3 個椎體、每個前緣楔形變 ≥ 5°，伴終板不規則（波浪狀）、前方椎間隙變窄與界清 Schmorl nodes。** 判讀分水嶺：**「有 Schmorl nodes 但沒有前緣楔形變」不算 Scheuermann——楔形變（anterior wedging）才是關鍵；影像上也可能只見波浪狀終板而非離散 Schmorl node。記憶鉤：3 節、5 度、胸椎、前楔＋Schmorl。**

## Summary
- **本質**：多發 Schmorl nodes → 椎體楔形變所致之後凸（椎體終板骨軟骨病）。[^1]
- **診斷標準（Sorensen）**：**連續 ≥ 3 個椎體、各 ≥ 5° 楔形變**＋終板波浪狀不規則＋前方椎間隙最窄＋界清 Schmorl nodes。[^1][^2]
- **定位**：**75% 胸椎**、20–25% 胸腰段、< 5% 純腰椎、極少頸椎。[^1]
- **後凸角度**：胸椎後凸 **> 40° 為異常**（正常隨年齡增加）。[^1]
- **考點**：Scheuermann 造成 **thoracic kyphosis**（2019-506 答案 D），非 scoliosis/lordosis/cervical kyphosis。[^1]

## 放射科醫師影像判讀重點

### 診斷標準與測量
- **Sorensen 標準**：**連續 ≥ 3 椎、各 ≥ 5° 楔形變**；終板因椎間盤大量嵌入而呈**波浪狀（undulation）**；**前方椎間隙變窄最明顯**；界清 Schmorl nodes。[^1]
- **後凸測量**：胸椎型自 **T3–T12** 量 Cobb 角；胸腰/腰段型自「受累椎上一節到下一節」量，更能反映功能性後凸；**腰椎前凸消失具功能意義**。[^1]
- **伴隨徵象**：± limbus vertebrae（椎間盤穿過環狀骨突生長板）；**15% 合併脊椎側彎**；**過度後伸側位片**評估後凸柔軟度（可否矯正）。[^1]

### 分模態
- **X 光（診斷首選）**：楔形椎、波浪狀終板、Schmorl nodes、前方椎間隙窄。[^1]
- **CT**：終板異常較 X 光更明顯。[^1]
- **MR（排除椎間盤病變）**：Schmorl nodes 與椎間盤突出 T1 低訊號、± discogenic sclerosis；**50% 受累椎間盤退化**；Schmorl nodes 於 T2 可低可高；± 鄰近骨髓水腫。[^1]
- **核醫/骨密度**：骨掃描可正常或活性增加；**骨質密度（DEXA/CT）正常**（有別於代謝性骨病）。[^1]

### 鑑別診斷（DDx）
- **姿勢性後凸（postural kyphosis）**：**終板正常、過度後伸可矯正**（除非長期）——與 Scheuermann 最需鑑別。[^1]
- **楔形壓迫骨折**：可多節；前皮質成角、MR 見骨折線與骨髓水腫。[^1]
- **先天性後凸**：有椎體發育異常。[^1]
- **結核（TB）**：後凸常嚴重、終板破壞 ± 椎體融合。[^1]
- **成骨不全（OI）**：platyspondyly、嚴重骨質疏鬆；**僵直性脊椎炎**（椎體融合、薦髂關節異常）、**SED tarda**（全脊椎 platyspondyly）。[^1]

> [!note] 判讀陷阱
> **有 Schmorl nodes 但無前緣楔形變 → 不是 Scheuermann disease**；X 光有時只見波浪狀終板而非離散 Schmorl node。[^1]

## 臨床重點（5 句）
1. **流行病學**：盛行率 **0.4–8%**、**尖峰 13–17 歲**、輕微男性偏多；為**青少年結構性後凸/下背痛最常見原因**。[^1]
2. **病因**：不明——終板生長缺陷＋機械應力使椎間盤穿過弱化終板、前柱生長遲滯致楔形；具**家族遺傳性**（丹麥雙胞胎登錄顯著遺傳貢獻、體染色體顯性 OMIM #181440）；**舉重、體操等脊椎負重運動**可能促成。[^1]
3. **臨床表現**：**胸椎疼痛與壓痛、活動後加重**、疲勞；後凸於青春期發展、可能較晚才就診；嚴重者可有神經症狀。[^1]
4. **自然史**：青春期生長爆發期間惡化、生長完成後輕微進展；**> 70° 後凸功能結果差**；並發早發性椎間盤退化與突出。[^1]
5. **治療**：**觀察**（後凸 < 50°、仍在生長）→ **背架**（至少剩 1 年生長、< 70°、後伸可部分矯正）→ **手術**（骨骼未成熟 > 75°、成熟 > 60°、劇痛或神經缺損；後路 ± 前路融合）。[^1]

> [!note] 考點：Scheuermann disease（vertebral epiphysitis）造成何種畸形?
> **thoracic kyphosis（D，胸椎後凸）**——非 thoracic scoliosis/lumbar lordosis/cervical kyphosis。主要影響胸椎（75%），後凸 > 40° 為異常。[^1]
