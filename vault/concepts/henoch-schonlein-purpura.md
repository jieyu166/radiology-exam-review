# henoch-schonlein-purpura

**HSP（現稱 IgA vasculitis, IgAV）是兒童最常見的血管炎——免疫複合體介導之小血管炎，侵犯皮膚/腸胃/關節/腎。腸道侵犯呈『跳躍性（skip/discontinuous）』節段性腸壁增厚，不侷限單一血管領域；早發型本質為非進行性。** 判讀分水嶺：**GI 症狀約見於一半（Tizard）～多達 75%（STATdx）兒童（並列）；範圍輕（噁心/嘔吐/腹痛/暫時性麻痺性腸阻塞）到重（腸胃出血、腸缺血壞死、腸套疊、腸穿孔）；腸套疊常為 ileoileal；典型影像＝長節段小腸壁增厚、充液小腸、腹水。**

## Summary
- **本質/流行病學**：**兒童最常見血管炎**；**免疫複合體介導之小血管炎**，侵犯皮膚、GI、泌尿、關節；**早發型本質為非進行性（nonprogressive）**。[^1][^2]
- **臨床四聯**：可觸性紫斑（臀/下肢）、關節痛、GI 症狀、IgA 腎炎。[^2]
- **GI 受累比例**：約**一半（Tizard）／多達 75%（STATdx）**——並列（非 100%）；範圍輕至重（出血/缺血壞死/腸套疊/穿孔）。[^1][^2]
- **腸道侵犯型態**：**跳躍性/不連續（skip）節段性、環周腸壁增厚、長度不一**；可侵犯**不常見部位（胃/十二指腸/直腸）**、**不侷限單一血管領域**。[^1][^2]
- **腸套疊**：**常為 ileoileal（小腸-小腸）**，lead point 為腸壁水腫/血腫。[^2]
- **典型影像**：**長節段小腸壁增厚、充液小腸、腹水**（診斷性）。[^1][^2]

## 放射科醫師影像判讀重點
- **skip lesions**：不連續節段增厚（正常腸段間隔），與單一血管領域缺血（腸繫膜缺血）分佈不同。[^1][^2]
- **超音波/CT**：環周腸壁增厚（target/halo）、充液擴張、腸繫膜水腫、腹水；找 ileoileal 腸套疊（非阻塞性、可自復或需處理）。[^2]
- **不常見部位**：胃/十二指腸/直腸受累提示 HSP（非典型缺血分佈）。[^1]
- **併發搜尋**：腸穿孔（游離氣）、缺血壞死、持續腸套疊。[^2]
- **臨床整合**：兒童 + 可觸性紫斑 + 腹痛 + 腸壁增厚 → IgAV；紫斑可晚於腹痛出現。[^2]

## 臨床重點（5 句）
1. **最常見兒童血管炎**：IgA 小血管炎，四聯（紫斑/關節/GI/腎）。[^2]
2. **GI 受累**：約半數～75%，輕到重。[^1][^2]
3. **skip 型態**：不連續節段腸壁增厚，不侷限單一血管領域。[^1][^2]
4. **腸套疊**：常 ileoileal。[^2]
5. **典型影像**：長節段小腸壁增厚 + 充液小腸 + 腹水。[^1][^2]

> [!note] 考點：關於 Henoch-Schönlein purpura (HSP)，何者「正確」?
> 「**長節段小腸壁增厚、充液小腸與腹水為診斷性表現（D）**」正確。早發型本質非進行性（A 錯）、GI 症狀約半數～75%而非 100%（B 錯）、腸道侵犯呈跳躍性且不侷限單一血管領域（C 錯）。[^1][^2]
