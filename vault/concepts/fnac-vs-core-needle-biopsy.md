# fnac-vs-core-needle-biopsy

**乳房 FNAC 最適合「超音波導引」（快、安全，亦可抽水泡/囊液），而非 MR-guided（MR 導引通常保留給 core needle biopsy）；FNAC 整體敏感度仍低於 core needle biopsy，且高度仰賴 cytopathologist 經驗——這三個限制是此題核心。** 判讀分水嶺：**要「細胞學（囊液/明確良性 B2/C2 如 fibroadenoma）」用 US 導引 FNAC；要「組織學/分級（B3/C3 以上 gray zone、ADH、原位癌、乳突病灶）」用 core needle biopsy（14G，取 3 條準確度 ~95% vs 1 條 ~70%）。**

## Summary
- **FNAC 最適導引**：**超音波導引**（快、安全，亦可抽囊液），**非** MR-guided；MR 導引多用於需組織學之 core needle biopsy。[^1][^2]
- **仰賴判讀者**：需**經驗豐富之 cytopathologist** 判讀，FNAC 準確度方能提高（人員依賴為其限制）。[^1][^2]
- **敏感度**：**FNAC 敏感度低於 core needle biopsy**；US 導引 CNB（14G）**取 1 條約 70%、取 3 條約 95%**（取樣數顯著影響準確度）。[^1][^2]
- **FNAC 優勢族群**：**B2/C2**（如 fibroadenoma）表現優越，為 FNA 門診主要病例。[^2]
- **FNAC 限制**：gray zone（**B3/C3、B4/C4**）角色有限；**B3/C3 以上**（ADH、原位癌、乳突病灶）需明確組織學以定處置（是否手術/化療）。[^2]

## 放射科醫師影像判讀重點
- **導引選擇**：可觸摸/US 可見 → US 導引（首選，即時、無輻射）；僅 MR 顯示之病灶 → MR 導引 CNB（非 FNAC）；僅攝影鈣化 → 立體定位 CNB。[^1]
- **取樣量**：CNB 多取（≥3 條 14G）顯著提升準確度，鈣化病灶需確認檢體含鈣化。[^2]
- **FNAC 定位**：快速分流囊/實、抽囊液、確認明確良性或轉移淋巴結；不適合需分級/結構之病灶。[^2]
- **B/C 分級對接**：C2＝良性、C3/C4＝非典型/可疑 → 升級為 CNB 取組織學。[^2]
- **陷阱**：FNAC 陰性/不足量不排除惡性，臨床可疑仍需 CNB 或切除。[^2]

## 臨床重點（5 句）
1. **FNAC 導引**：US 導引最適，非 MR。[^1][^2]
2. **敏感度**：FNAC < CNB（CNB 14G 取 3 條 ~95%）。[^2]
3. **人員依賴**：需資深 cytopathologist。[^2]
4. **適用**：FNAC 適 B2/C2、囊液；gray zone 用 CNB。[^2]
5. **原則**：需組織學/分級選 CNB，需細胞學/抽液選 FNAC。[^2]

> [!note] 考點：關於breast FNAC與core needle biopsy,何者為非？
> 「**FNAC 最適用於 MR-guided 之 FNAC**」為非——FNAC 最適合超音波導引（MR 導引多用於 CNB）。經驗豐富 cytopathologist 判讀時 FNAC 準確度高、FNAC 敏感度低於 core needle biopsy（14G 取 3 條 95% vs 1 條 70%）皆為正確。[^1][^2]
