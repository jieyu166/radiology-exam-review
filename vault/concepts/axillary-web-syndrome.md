# axillary-web-syndrome

**腋網症候群（AWS）是腋部手術（尤其乳癌 ALND/SLNB）後常見之自限性併發症，特徵是腋下到上臂/胸壁出現一條或多條可觸/可見的緊繃索狀帶（"cords"），伴疼痛與肩臂活動受限。** 判讀分水嶺：AWS 診斷**以臨床（觸診索狀構造）為主**，影像非必需；病生理**以淋巴管損傷（lymphatic cording）為主**、常合併淺層靜脈受累，故 US 上表現為無/低回音索狀構造、Doppler 無血流——但「一定是血栓化淺靜脈」是過度簡化（見下方陷阱與 ⚠️ 題目衝突）。

## Summary
- **流行病學**：AWS **常見於腋部手術後、好發乳癌病患**（ALND > SLNB）；為術後併發症。[^1][^2]（選項 A 正確）
- **臨床表現**：一條或多條**緊繃線狀索帶（firm linear bands / cords）**位於腋下並延伸至上臂（±胸壁），伴**疼痛與肩臂活動範圍受限**；多於術後數日至數週出現，亦可較晚出現。[^1][^2]（選項 B 正確——見 ⚠️）
- **性質**：**自限性**；病生理未完全明瞭，主流認為**手術造成之淋巴管損傷（lymphatic injury）**為最常見原因，常合併淺層淋巴/靜脈之破壞、停滯與局部高凝/血栓。[^1][^2]
- **診斷**：以**臨床評估**為主——理學檢查觸及索狀構造即可診斷；放射科多於腋部/上肢超音波轉介時遇到，應認得其表現以免誤判。[^1][^2]
- **超音波表現**：肩外展時真皮變形、**無回音（anechoic）索狀構造伴高回音邊（可能為血管腔與管壁）**、高回音結構（推測為纖維化）；**Doppler 無血流**。[^2]（選項 C 之依據——但措辭見 ⚠️）
- **MRI 表現**：索狀構造呈**低訊號之皮下線狀帶或點狀（low signal subcutaneous linear bands or dots）**。[^2]（選項 D 正確）
- **與 Mondor disease 關係**：腋部之 Mondor disease（淺靜脈血栓性靜脈炎）即被稱為 axillary web syndrome——歷史上二者概念重疊，反映 AWS 兼具淋巴與靜脈成分。[^3]
- **關鍵反證（AWS ≠ 血栓化淺靜脈）**：有以 **18 MHz 高頻超音波無法辨識出特定索狀結構**之研究，顯示 AWS **並非血栓化淺靜脈、亦不等同 Mondor disease**；此點強化 2021-336 選項 C「US usually demonstrates a non-compressible thrombosed superficial vein」為可疑錯述。[^5] 誠實註記：AWS 為冷門主題，白名單五來源（StatDx/Radiopaedia/ClinicalKey/RadioGraphics/AJR）無此專文，退用同儕審查放射期刊佐證。[^4][^5]

## 影像診斷
### 超音波（首選影像；診斷仍以臨床為主）
- 肩外展誘發真皮牽拉變形；沿索帶走行可見**無回音索狀腔（anechoic cord）伴高回音管壁**、及推測為纖維化之高回音結構。[^2]
- **Doppler 無血流**——與無/慢流之淺層血管/淋巴管相符。[^2]
- 用途：排除其他索狀/線狀病灶（如淺靜脈血栓、術後纖維化），並向臨床確認 AWS。[^2]

### MRI
- 索狀構造呈**低訊號皮下線狀帶或點狀**；非例行檢查，於複雜/非典型時輔助。[^2]

## 鑑別與報告要點
| 要點 | 說明 |
| --- | --- |
| 典型情境 | 腋部手術（乳癌 ALND/SLNB）後數日至數週[^1][^2] |
| 表現 | 腋下→上臂緊繃索帶＋疼痛＋肩臂活動受限[^1][^2] |
| 診斷方式 | **臨床觸診為主**，影像非必需[^1][^2] |
| US | 無回音索帶＋高回音邊、Doppler 無血流[^2] |
| MRI | 低訊號皮下線狀帶/點狀[^2] |
| 病生理 | 以淋巴管損傷為主，常合併淺靜脈受累（與 axillary Mondor 重疊）[^1][^2][^3] |
| 預後 | 自限性，多可保守（物理治療/伸展）改善[^1][^2] |

> [!warning] 「一定是血栓化淺靜脈」是過度簡化
> AWS 之本質**以淋巴管索化（lymphatic cording）為主**，並非單純之淺靜脈血栓；US 雖可見無回音索狀腔（可能為血管腔），但將其一律描述為「非可壓縮之血栓化淺靜脈」會忽略其淋巴/纖維化成分。此點正是本題答案爭議所在（見下）。

## 題目
> [!question]- Which of the following statement about axillary web syndrome of the breast is incorrect? (2021-336)
> **⚠️ 官方答案（B）與其詳解自相矛盾、且與所引文獻不符。** 官方標答案 B「patients usually present with one or more palpable or visible firm linear bands」為「錯誤」，但官方詳解卻寫「(以上皆對)」並逐項確認四敘述皆正確。經查證：**B 實為正確**——官方所引之 Mullen & Harvey（Eur J Radiol 2019, DOI 10.1016/j.ejrad.2019.02.001）摘要逐字寫「patients develop one or more linear bands of firm tissue ("cords")」，即 B 之敘述；Radiopaedia 亦述「一或多條可觸索狀構造」。A（術後常見、好發乳癌）、D（MRI 低訊號皮下線狀帶/點狀）亦正確。若四選項須挑一最可議者，應為 **C**「US usually demonstrates a non-compressible thrombosed superficial vein」——AWS 以淋巴索化為主、非單純血栓化淺靜脈，措辭過度簡化；惟官方詳解將 C 視為正確，故此題判定存疑，**建議醫師對照原卷確認答案，本卡不改官方 json**。[^1][^2][^3]
