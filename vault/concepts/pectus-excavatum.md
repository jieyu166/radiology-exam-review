# pectus-excavatum

**漏斗胸（pectus excavatum）＝胸骨向內凹陷（sternal depression）的前胸壁畸形；嚴重度以 Haller index 量化＝胸廓「橫徑 ÷ 前後徑」，且測量取自「內側」骨性標記（胸椎體前緣到胸骨後緣），而非胸壁外側。判讀分水嶺：Haller index 是「內-內」測量、於最凹陷軸切面計算，數值越大越嚴重（>3.25 常為手術指標）。**

## Summary
- **定義**：pectus excavatum 為以胸骨凹陷（sternal depression）為特徵的前胸壁畸形，俗稱**漏斗胸（funnel chest）**；為最常見的先天性胸壁畸形。[^1][^2]
- **Haller index（pectus index）**：＝**胸廓橫徑（transverse diameter）÷ 前後徑（AP diameter）**。[^1][^2]
- **測量方法（關鍵）**：於 CT（或胸片）**最凹陷的軸切面**（胸骨後緣與胸椎體前緣距離最小處），AP 徑取自**胸椎體前緣到胸骨後緣**、橫徑取胸廓內側——即以**內側骨性標記**測量，**非**自「胸壁外側（outer aspect）」測量。[^1][^2]
- **嚴重度切點**：Radiopaedia 分級 normal <2.0、mild 2.0–3.2、moderate 3.2–3.5、severe >3.5；臨床常以 **Haller index >3.25** 作為手術（Nuss/Ravitch）參考指標。[^1]

## 放射科醫師影像判讀重點
- **胸片徵象**：胸骨凹陷、心影向左移位、右心緣模糊（obscured right heart border）、下位前肋斜向下、縱膈變窄。[^1][^2]
- **CT 角色**：量化 Haller index 與 correction index、評估心臟受壓與轉位（心臟順時針旋轉、降主動脈介面消失），術前規劃。[^1][^2]
- **測量陷阱（本題考點）**：Haller index 為「**內-內**」測量（胸椎前緣↔胸骨後緣、胸廓內側橫徑），**不是**自胸壁外側量；且應於**最凹陷層面**取值以求一致（Haller index 於較頭側較大）。[^1]
- **相關指數**：correction index（量胸骨相對肋骨後移程度）、depression index，作為 Haller index 之補充。[^1]

## 題目
> [!question]- Which one is NOT true about Pectus excavatum? (2022-426)
> **C（關鍵）「Measurement of Haller index is starting from outer aspect of chest wall.」為錯誤**——Haller index 取自**內側**骨性標記（胸椎體前緣到胸骨後緣的 AP 徑、胸廓內側橫徑），並非自胸壁外側量。其餘正確：A. pectus excavatum 為以胸骨凹陷為特徵之胸壁畸形；B. Haller index＝胸廓橫徑 ÷ 前後徑；D. 又稱 funnel chest（漏斗胸）。[^1][^2]
