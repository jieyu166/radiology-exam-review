# pediatric-head-neck-infections

**小兒頭頸部感染的影像評估涵蓋上呼吸道阻塞、頸部淋巴腺炎、及深頸部膿瘍。兒童上呼吸道阻塞最常見原因為 Waldeyer's ring 淋巴組織增生（adenotonsillar hypertrophy）；雙側頸部淋巴腺炎最常見為病毒感染，單側則為細菌感染；1-5 歲兒童頸部淋巴腺炎最常見位置為咽後淋巴結（retropharyngeal lymph nodes）；深頸部膿瘍的影像診斷以 CT 高度敏感但特異性不高。**

## Summary
- **上呼吸道阻塞**：[^1]
  - 兒童最常見原因：**Waldeyer's ring 淋巴組織增生**（adenoid + palatine tonsil hypertrophy）
  - 其他原因：異物吸入、喉氣管支氣管炎（croup）、咽後膿瘍
- **頸部淋巴腺炎（cervical adenitis）**：[^1]
  - **雙側（bilateral）**最常見原因：**病毒感染**（viral infection）
  - **單側（unilateral）**最常見原因：**細菌感染**（bacterial infection，常為 S. aureus 或 Group A streptococcus）
  - **1-5 歲最常見位置**：**咽後淋巴結（retropharyngeal lymph nodes）**（因這些淋巴結引流鼻咽及扁桃腺的感染）
- **深頸部膿瘍影像診斷**：[^1]
  - **CT**：高度敏感（highly sensitive）但特異性不高（not specific）— 可見環形增強但無法區分蜂窩性組織炎與膿瘍
  - **超音波**：可用於表淺評估但深層結構有限
  - **MRI**：敏感度高但掃描時間長、兒童需鎮靜

## 放射科醫師影像判讀重點
- **模態選擇順序**：兒童因輻射考量常以超音波(US)為第一線評估表淺頸部腫塊/淋巴腺炎；急性情境（尤其疑深頸部感染或呼吸道受壓）以增強 CT 快速評估膿瘍與氣道；MRI 對軟組織與深層範圍最佳但需時長、幼童需鎮靜。[^2]
- **膿瘍 vs 蜂窩組織炎之判讀**：CT 上環形強化雖敏感但特異性不足，無法可靠區分蜂窩組織炎/蜂窩織炎性淋巴結與真正膿瘍；MRI 在兒童深頸部感染診斷準確度佳（文獻報告敏感度約 0.96、特異度約 0.77、準確度約 0.89），有中央 T2 高訊號、DWI 擴散受限且環形強化較支持膿瘍。[^2]
- **部位分布之年齡差異（判讀線索）**：相較成人，兒童深頸部感染以咽後(retropharyngeal)感染與淋巴腺炎比例較高、扁桃周/咽旁感染比例較低——此與 1–5 歲咽後淋巴結(引流鼻咽/扁桃腺)為好發部位一致，判讀時應特別檢視咽後間隙。[^2]
- **DDx 與陷阱**：判讀頸部腫塊須與先天性病灶(甲狀舌管囊腫、鰓裂囊腫、囊狀水瘤)、腫瘤性病灶(淋巴瘤、神經母細胞瘤、橫紋肌肉瘤)鑑別；咽後間隙須注意勿將正常淋巴組織或增厚誤判為膿瘍，並留意氣道受壓程度。[^2]

## 臨床重點（5 句）
- 兒童頸部腫塊多為良性/感染性，惡性比例較成人低，但評估時仍須將惡性(淋巴瘤等)納入鑑別。[^2]
- 兒童頸部與免疫系統之解剖與生理差異，使其深頸部感染表現與成人不同（咽後感染與淋巴腺炎較多）。[^2]
- 單側細菌性淋巴腺炎常見致病菌為金黃色葡萄球菌與 A 群鏈球菌；雙側者多為病毒性。[^2]
- 咽後膿瘍為兒科重要急症，可致氣道阻塞與縱膈延伸，需及時影像評估與處置。[^2]
- 兒童 C 反應蛋白(CRP)常較成人低，但膿瘍發生比例、大小與手術率與成人相近，故不宜僅憑發炎指標低就排除膿瘍。[^2]
