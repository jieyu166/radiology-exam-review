# uvc-catheter-route

**UVC 從臍靜脈進入後，正常路徑依序經過 portal sinus → ductus venosus → IVC → right atrium。UVC 不應經過 portal vein（左右門脈分支），若導管進入 portal vein 則為 malposition。**

## Summary
- 正常 UVC 路徑 [^1]：
  1. Umbilical vein → 進入肝門
  2. → **Portal sinus**（左門脈水平段）
  3. → **Ductus venosus**（旁路肝臟）
  4. → **IVC**（下腔靜脈）
  5. → Right atrium
- **Portal vein**（右門脈分支等）不在正常 UVC 路徑上 [^1]
- UVC tip 理想位置：IVC-RA junction（T8-T10 level on XR）[^1]

## 放射科醫師影像判讀重點
- **正確位置判讀**：理想 UVC tip 位於 IVC 與右心房交界處(IVC-RA junction)；在前後位胸腹 X 光片上此目標區很短(約一個 T8 椎體高度)，故 tip 稍偏即為 malposition，臨床上 UVC 錯位相當常見。[^2]
- **兩種定位法比較**：以「心影法(cardiac silhouette method)」判斷 tip 位置優於「椎體法(vertebral body method)」——研究中心影法對照超音波之敏感度 86%、特異度 94%，明顯高於椎體法(61%/74%)；判讀時應優先參考 tip 與心影/橫膈的關係。[^2]
- **錯位路徑辨識**：導管若停在肝內門脈分支(未越過 ductus venosus)、迴繞入下腔靜脈以下、或過深進入右心房/卵圓孔到左心房，皆屬錯位；正常路徑應為 umbilical vein → portal sinus → ductus venosus → IVC → RA。[^2]
- **判讀陷阱與確認**：X 光為初步定位但誤差不小，對位置存疑或需即時確認時，床邊超音波可快速(數分鐘內)確認 tip 位置；tip 位於肝實質/門脈系統有導致肝損傷、輸注滲漏之風險，發現後應調整。[^2]
- **完整正常路徑與「不經髂靜脈」**：UVC 正常走向為 umbilical vein → umbilical recess → 跨越 left portal vein → ductus venosus → middle/left hepatic vein → IVC → right atrium；全程**不**經過 internal iliac vein（髂靜脈屬 UAC 端的動脈側解剖，非 UVC 路徑），此為考題常見鑑別點。[^3][^4]
- **UVC vs UAC 影像分辨**：兩管皆自臍部進入，但 UAC 先向**尾側下行**進入髂動脈系統再折返上行入主動脈，UVC 則直接上行且偏前；X 光上以此「初始走向」區分兩者。UVC 常見錯位：進入門脈分支(未越過 ductus venosus)、或過深至 RA/SVC、經 PFO 入 LA 或肺靜脈。[^4]

## 臨床重點（5 句）
- UVC 是新生兒(尤其早產兒)重要的中央靜脈通路，用於給液、輸血與換血。[^2]
- 導管尖端位置正確與否直接影響安全性，錯位可致肝損傷、心律不整、心包填塞或血栓。[^2]
- 目標定位區在影像上很短，臨床上導管常見錯位，須例行以影像確認。[^2]
- 相較椎體高度法，以心影為參考的定位法更能準確預測真實 tip 位置。[^2]
- 超音波可快速輔助或取代 X 光確認 tip，特別適合需即時定位的情境。[^2]

## 陷阱
- Portal sinus ≠ portal vein：portal sinus 是左門脈水平段（UVC 會經過），而 portal vein branch 不在 UVC 正常路徑上

## 題目
> [!question]- An umbilical venous catheter generally doses not passes through which vessels? (2022-500)
> **B（internal iliac vein）** UVC 自臍靜脈直接上行，正常路徑 umbilical vein(A) → umbilical recess → left portal vein(C) → ductus venosus → middle/left hepatic vein(D) → IVC(E) → RA，全程**不經過 internal iliac vein**。髂靜脈屬 UAC（臍動脈導管）端的動脈側解剖：UAC 才會向尾側下行入 internal iliac artery → common iliac artery → aorta。故本題「不會經過」者為 B。[^3][^4]
