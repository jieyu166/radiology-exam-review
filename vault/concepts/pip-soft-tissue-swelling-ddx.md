# pip-soft-tissue-swelling-ddx

**「所有手指近端指間關節（PIP）孤立性軟組織腫脹」的鑑別，別只想到發炎性關節炎——除了幼年特發性關節炎（JIA）與類風濕性關節炎（RA），還必須納入 pachydermodactyly（一種良性、非發炎的軟組織纖維增生，好發於年輕男性、無骨侵蝕）。判讀分水嶺：看「有無骨侵蝕／關節間隙變窄／骨旁疏鬆」——有＝發炎性關節炎；只有軟組織腫脹、骨頭乾淨＝要想到 pachydermodactyly。**

## Summary
- **鑑別三主角**：JIA、pachydermodactyly、RA 皆可表現為 PIP 周圍孤立性軟組織腫脹，故正解為「以上皆是」。[^1][^2]
- **JIA／RA（發炎性）**：軟組織腫脹是最早期的 X 光徵象，之後才出現骨旁疏鬆、關節間隙變窄與骨侵蝕。[^1][^2]
- **Pachydermodactyly（非發炎性陷阱）**：良性指節軟組織纖維增生，典型為年輕男性、雙側 PIP 側方梭形腫大，X 光「只見軟組織腫脹、無骨侵蝕或關節破壞」，常與反覆機械刺激（搓手動作）相關。[^2]

## 放射科醫師影像判讀重點
- **先看骨頭再下結論**：孤立 PIP 軟組織腫脹的分流關鍵＝有無骨侵蝕／關節間隙變窄／骨旁疏鬆。發炎性關節炎（JIA、RA）會逐步出現這些；pachydermodactyly 骨質完全正常，僅軟組織增厚。[^1][^2]
- **JIA 影像序（Tier 1）**：最早期 X 光徵象為 periarticular 軟組織腫脹（±dactylitis 香腸指）與骨膜反應，接著 uniform 骨質疏鬆、關節間隙變窄與侵蝕；晚期可強直（carpus 融合）、骨骺過度生長（hyperemia）。US power Doppler／增強 MRI 可早於 X 光偵測滑膜炎。[^2]
- **RA 分布**：對稱性，好侵犯 MCP、PIP 與腕；早期為軟組織腫脹與骨旁疏鬆，續而邊緣性侵蝕（bare area）、uniform 關節間隙變窄。[^1]
- **Pachydermodactyly 判讀要點**：雙側對稱 PIP 側方軟組織腫大、無滑膜炎的骨徵、無關節積液破壞；MRI 顯示皮下／軟組織纖維增生而非侵犯性滑膜炎——用以與早期發炎性關節炎區分，避免不必要的抗風濕治療。[^2]

## 題目
> [!question]- Isolated soft-tissue swelling around the proximal interphalangeal joints of all fingers, the differential diagnosis should include which of the following? (2022-488)
> **D. All of the above（關鍵）**——JIA、pachydermodactyly、RA 皆可造成 PIP 周圍孤立性軟組織腫脹。JIA/RA 早期以關節周軟組織腫脹起始（續有骨旁疏鬆、侵蝕）；pachydermodactyly 則為良性、年輕男性、無骨侵蝕的軟組織纖維增生，是不可漏的非發炎性鑑別。[^1][^2]
