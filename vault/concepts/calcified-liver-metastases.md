# calcified-liver-metastases

**肝轉移瘤內出現鈣化時，原發灶清單遠比「只有黏液性大腸癌」廣——凡是會產生黏液、骨基質、軟骨基質，或本身易壞死出血的腫瘤，其肝轉移都可能鈣化。** 判讀分水嶺有二：（1）先確認是「鈣化」而非顯影後的腫瘤強化——鈣化在**非顯影** CT 即為高密度，動脈／靜脈／延遲期都不會像血管性強化般沖刷變化；（2）看到鈣化性肝病灶，第一鑑別其實不是轉移，而是**肉芽腫性感染（結核）**，因為單就「肝內鈣化」而言，發炎／肉芽腫才是最常見成因。記憶鉤：**「黏液（colon/stomach/ovary/pancreas）＋成骨成軟骨（osteosarcoma/chondrosarcoma）＋神經內分泌（neuroblastoma/carcinoid）＋肺癌」都可鈣化——故本題『以上皆為可能』正確。**

## Summary
- **流行病學**：鈣化性肝轉移見於約 **25% 的大腸直腸癌肝轉移**，最常來自其中的**黏液性腺癌（mucinous adenocarcinoma）**亞型；其他多種原發灶亦可造成鈣化性肝轉移。[^1]
- **原發灶清單**：黏液性腺癌（大腸最常見、胃）、**肺癌**、攝護腺癌、乳癌、卵巢癌、**甲狀腺髓質癌（medullary thyroid ca）**、神經內分泌腫瘤（含 GIST、**神經母細胞瘤 neuroblastoma**、黑色素瘤 melanoma），以及罕見的骨性腫瘤（**骨肉瘤 osteosarcoma、軟骨肉瘤 chondrosarcoma**）。[^1] 綜合來看，鈣化性肝轉移**最常伴隨產黏液腫瘤（如大腸癌）**。[^2]
- **鈣化機轉**：（1）腫瘤內出血／壞死造成鈣鹽沉積（**營養不良性 dystrophic calcification**）或產黏液腺癌的**黏液性鈣化（mucoid calcification）**；（2）骨性腫瘤可直接產生鈣化（成骨性腫瘤的類骨質、軟骨腫瘤的化生性鈣化）。[^1]
- **化療後變化（判讀陷阱）**：既有鈣化在化療中可維持穩定或變動；原本**非鈣化的轉移**在化療／放療後可**新生鈣化**；然而腫瘤在化療期間**完全鈣化並不等於完全失活**，不可據此判定治療反應。[^1]
- **與腫瘤強化的區分**：鈣化在**非顯影** CT 即為高密度，須與動脈／靜脈／延遲期的真正腫瘤強化區分，避免把鈣化誤判為存活腫瘤成分（或反之）。[^1]
- **鑑別定位**：就「肝內鈣化」整體而言，**肉芽腫性發炎（如結核）為最常見成因**，其鈣化常侵犯整個病灶、密度緻密並在 CT 產生假影；判讀鈣化性肝病灶時勿一律歸因轉移。[^2]

## 影像診斷
### 超音波
鈣化呈**高回音（hyperechogenicity）**，可伴或不伴**後方聲影（posterior acoustic shadowing）**；於氣腫性肝膿瘍時可能被誤認為氣體聲影。**Twinkling artifact** 有助於區分氣體與鈣化，但並非恆定出現。[^1]

### CT
非顯影 CT 呈**高密度**，須與動脈／靜脈／延遲期腫瘤強化區分。肝轉移鈣化型態多樣：**無定形（amorphous）、點狀（punctate）、顆粒狀（granular）、毛玻璃樣（ground glass）**；分布可為**中央或周邊**；化療後常呈**弧形（arciform）或粗糙（coarse）**型態。[^1]

### MRI
鈣化在**所有序列多呈訊號空缺（signal void）**，惟此並非恆定表現。[^1]

## 鑑別與報告要點
| 病灶 | 鈣化特徵 | 報告要點 |
|---|---|---|
| 鈣化性肝轉移 | 多型態（無定形/點狀/顆粒/毛玻璃）、中央或周邊；產黏液腫瘤最常見 | 非顯影下即高密度；化療後可新生或轉呈弧形/粗糙鈣化 [^1] |
| 鈣化性肝肉芽腫（結核等） | 鈣化常侵犯**整個病灶**、緻密、可播散至肺與脾 | 「肝內鈣化」整體最常見成因；勿一律當轉移 [^2] |
| 包蟲囊腫（hydatid） | **曲線狀／環狀鈣化**，各期皆可見 | 病史／地域線索 [^1][^2] |
| 海綿狀血管瘤 | 大者可見**中央粗大鈣化**於纖維化區（CT 約 20%、X 光約 10%） | 搭配漸進性周邊結節狀強化 [^2] |
| 纖維板層型 HCC | 鈣化位於**中央星狀瘢痕**，CT 約 15–25% | 年輕、無肝硬化；巨大分葉腫塊 [^1][^2] |
| 肝內膽管癌 | 常伴**desmoplastic 反應**，CT 約 18% 可見鈣化 | 併局部膽管擴張、包膜回縮 [^2] |
| 肝母細胞瘤 | 約半數見營養不良性鈣化 | 小兒、AFP 升高 [^1] |

## 題目
> [!question]- Which is not the possible origin of the metastatic liver tumor with calcification? (2021-126)
> **E（以上病灶皆為可能病因）**——鈣化性肝轉移的原發灶清單很廣：A 產黏液腫瘤（大腸/胰/胃/卵巢，以黏液性腺癌最常見）、B 骨肉瘤（骨性腫瘤可直接產生鈣化）、C 神經母細胞瘤（屬神經內分泌腫瘤群）、D 肺癌，皆屬公認可造成鈣化性肝轉移之原發灶。因 A–D 全部可能，故「以上皆非不可能／皆為可能病因」的 E 為正解。[^1][^2]
