# desmoplastic-small-round-cell-tumor

**促結締組織增生性小圓細胞瘤（DSRCT）是一種罕見、高度侵襲性的間葉性小圓藍細胞腫瘤，典型好發於青少年／年輕成年男性，以腹膜腔內多發軟組織腫塊、無明顯原發臟器為特徵，預後差。** 判讀分水嶺：**年輕男性＋腹膜／骨盆腔（retrovesical／rectouterine 空間）多發軟組織腫塊、無明確器官起源＋廣泛腹膜播散／肝轉移 → 想到 DSRCT；它不是「預後良好」的腫瘤，而是高度惡性、預後不佳。** 記憶鉤：**年輕男孩、腹膜滿佈腫塊、找不到原發臟器、預後很差。**

## Summary
- **本質**：罕見、高度侵襲性的原發腹膜惡性腫瘤，屬**小圓藍細胞腫瘤（small round blue cell tumor）**家族；特徵性 EWSR1–WT1 基因融合〔t(11;22)〕。[^1][^2]
- **流行病學**：好發**青少年／年輕成年男性**（約 15–25 歲），**男：女約 6:1** 之明顯男性優勢。[^1][^3]
- **好發部位**：典型發生於**腹膜腔／骨盆腔而無明顯原發臟器**，多佔 **retrovesical（膀胱後）或 rectouterine（直腸子宮／retrouterine）空間**。[^1][^3][^4]
- **臨床表現**：常以可觸及腹部腫塊與腹痛表現。[^1]
- **轉移／擴散**：腹膜播散（seeding）、淋巴結侵犯常見；**肝為最常見遠端轉移處**，並可見骨轉移。[^1][^3]
- **預後**：**預後差（非 very good prognosis）**——高度惡性、診斷時多已廣泛播散。[^1][^3]

## 影像診斷
### CT（主要工具）
腹膜腔／骨盆腔內單發或多發軟組織腫塊，**無明確器官起源**，好發於膀胱後（retrovesical）區；常伴腹膜播散結節、腹水、淋巴結腫大，以及肝、骨轉移。腫塊可有壞死與點狀鈣化。[^1]

### MRI／其他
可用於評估骨盆腔腫塊範圍與臟器、血管侵犯；小圓藍細胞腫瘤細胞密度高，擴散受限。診斷仍賴組織病理與 EWSR1–WT1 融合確認。[^1][^2]

## 鑑別與報告要點
| 項目 | DSRCT 重點 | 鑑別 |
|---|---|---|
| 族群 | 年輕男性（15–25 歲），M:F≈6:1 | 與腹膜癌病（年長）不同 [^1][^3] |
| 部位 | 腹膜／骨盆腔多發腫塊，無原發臟器（retrovesical/rectouterine） | peritoneal carcinomatosis、malignant peritoneal mesothelioma [^1] |
| 病理 | 小圓藍細胞＋豐富促結締組織間質；EWSR1–WT1 | non-Hodgkin lymphoma、rhabdomyosarcoma [^1][^2] |
| 轉移 | 肝最常見；骨、淋巴結、腹膜播散 | — [^1][^3] |
| 預後 | 高度侵襲、預後差 | — [^1][^3] |

## 題目
> [!question]- Which statement is wrong about the desmoplastic small round cell tumor? (2021-109)
> **D（It has a very good prognosis）——錯誤，即本題答案。** DSRCT 為罕見、**高度侵襲性**間葉性腫瘤，**預後差**，非預後良好。其餘正確：A. 好發青少年男性；B. 男:女約 6:1；C. 典型發生於腹膜腔而無明顯原發臟器（多佔 retrovesical/retrouterine 空間）。補充：肝為最常見遠端轉移處。[^1][^2][^3]
