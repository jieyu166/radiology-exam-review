# mammography-dose-limits

**美國放射線學會（ACR）規定標準假體下每張乳房攝影之平均乳腺劑量（mean glandular dose, MGD）不得超過3mGy；2D乳房攝影、3D乳房斷層攝影、以及2D+3D併用檢查，其平均劑量皆未超過此規定值。**

## Summary
- **ACR 規定門檻**：標準假體（standard phantom）下，每張乳房攝影之 MGD **不得超過 3 mGy**。[^1]
- **實測值**：2D 乳房攝影（FFDM）與 3D 乳房斷層攝影（DBT）併用（2-view DBT plus FFDM）之平均劑量約 **2.0–2.23 mGy**——**2D、3D、與2D+3D併用，皆未超過 3 mGy 規定值**。[^1]

## 放射科醫師影像判讀重點

### 劑量規範與量測（技術判讀）
- **MGD（mean glandular dose）＝乳腺組織的等效吸收劑量**,是乳房攝影劑量規範的核心指標（非表面入射劑量或器官劑量），因乳腺為輻射致癌敏感組織;規範以**標準假體、每張影像**為量測基準。[^1]
- **ACR/MQSA 上限＝每張影像 3 mGy（標準假體）**;實務上 2D FFDM 與 DBT 之典型 MGD 約 **2.0–2.23 mGy**,**2D、3D、2D+3D 併用皆在 3 mGy 以內**。判讀劑量報告時勿把「併用劑量較高」等同「超標」。[^1]
- **影響 MGD 的因子**：乳房壓迫厚度與腺體密度、kVp／靶-濾片組合、AEC 設定;**適當壓迫可降低厚度與散射 → 降低 MGD 並提升影像品質**,為技術端可控的降劑量手段。[^1]
- **合成 2D（synthesized 2D, C-view）** 由 DBT 資料重建可**取代傳統 FFDM**,以避免 2D+3D 併用時的劑量疊加,是臨床上控制總劑量的常用策略。[^1]

## 陷阱
- 考題常設計「哪一項檢查超過規定劑量」之選項，正確答案為**以上皆未超過**——需注意 2D+3D 併用雖劑量高於單獨 2D，仍在 3 mGy 規定值以內。[^1]
