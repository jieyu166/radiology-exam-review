# extraadrenal-paraganglioma

**腎上腺外副神經節瘤好發於「Zuckerkandl 器官」（腹主動脈分叉附近之副神經節組織），多於 40-50 歲診斷，MRI 典型 T2 高訊號（±flow voids，salt-and-pepper）。「Carney triad」＝gastric GIST + pulmonary chondroma + extra-adrenal paraganglioma，好發年輕女性。** 判讀分水嶺：**Carney triad 三要素為『胃部』GIST（非泛指 GI 基質瘤）、肺軟骨瘤、腎上腺外副神經節瘤；副神經節瘤可任何年齡但多 40-50 歲、T2 高訊號、分泌兒茶酚胺者有高血壓/頭痛；性別大致相當，但 glomus jugulotympanicum 與 vagal paraganglioma 好發女性。**

## Summary
- **好發部位**：**Zuckerkandl 器官（腹主動脈分叉/IMA 起始附近）為腹部腎上腺外副神經節瘤最常見部位**；亦見膀胱、para-aortic、頭頸（carotid body、glomus jugulare/tympanicum、vagal）。[^1][^2]
- **好發年齡**：任何年齡，但**多於 4th-5th decade（40-50 歲）**診斷。[^1][^2]
- **MRI**：**T2 對肝呈高訊號**（特徵）；相對高 T1 + **flow voids（salt-and-pepper）**；強化明顯。[^2]
- **功能性**：chief cells 含兒茶酚胺顆粒；分泌者有**高血壓、頭痛、心悸、blushing**。[^2]
- **Carney triad**：**gastric GIST + pulmonary chondroma + extra-adrenal paraganglioma**，好發**年輕女性**；⚠️ 三合症之 GIST specifically 為**胃部（gastric）**（非泛指一般 GI 基質瘤）。[^1]
- **性別**：大致相當，但 **glomus jugulotympanicum 與 vagal paraganglioma 對女性有顯著好發**。[^1]

## 放射科醫師影像判讀重點
- **定位**：腹主動脈分叉旁 T2 高訊號強化腫塊 → 想 Zuckerkandl 副神經節瘤；膀胱壁者可致排尿誘發高血壓。[^1][^2]
- **T2 高訊號 + flow voids**：salt-and-pepper 為 MRI 特徵，反映高血流。[^2]
- **功能評估**：查血漿/尿 metanephrines；功能性者術前 α-阻斷避免術中高血壓危象。[^2]
- **症候群連結**：Carney triad（年輕女性，胃 GIST + 肺軟骨瘤 + 副神經節瘤）；Carney-Stratakis dyad（副神經節瘤 + GIST，SDH 突變）；SDHx 遺傳症候群。[^1]
- **功能影像**：¹²³I-MIBG、⁶⁸Ga-DOTATATE PET 定位多發/轉移。[^2]

## 臨床重點（5 句）
1. **部位**：Zuckerkandl 器官為腹部最常見。[^1][^2]
2. **年齡**：多 40-50 歲。[^1][^2]
3. **MRI**：T2 高訊號 + flow voids。[^2]
4. **Carney triad**：胃 GIST + 肺軟骨瘤 + 副神經節瘤，年輕女性。[^1]
5. **性別**：大致相當，但頸靜脈鼓室球瘤/迷走副神經節瘤好發女性。[^1]

> [!note] 考點：關於extraadrenal paraganglioma，何者「為偽」?
> **B 為偽**——Carney triad 正確組成為 **gastric GIST（胃部基質瘤，非泛指一般 GI 基質瘤）**、pulmonary chondroma、extra-adrenal paraganglioma。多數於 40-50 歲診斷（A）、T2 高訊號（C）、好發 Zuckerkandl 器官（D）皆為真。[^1][^2]
