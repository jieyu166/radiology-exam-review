# axillary-adenopathy-mammography

**篩檢乳攝發現腋下淋巴腫大、乳房本身無可疑病灶時，關鍵在「單側 vs 雙側」與「有無已知感染/發炎病因」——這兩軸決定 BI-RADS 給 2 還是 4。** 判讀分水嶺：**孤立單側**腋下 adenopathy（無已知感染/發炎原因）＝可疑（**BI-RADS 4**），提示隱匿乳癌，須細查同側乳房；**雙側** adenopathy 則**因情境而定**——反應性/感染性（sarcoidosis、SLE、psoriasis、HIV 等）＝良性 **BI-RADS 2**，但無已知原因（尤其新出現）可能是淋巴瘤/白血病＝可疑 **BI-RADS 4** 並建議 US 導引切片。故「雙側一律 BI-RADS 2」是錯的。

## Summary
- **異常腋淋巴結之影像特徵**：緻密、圓/不規則、**皮質增厚 ≥3 mm**（偏心性增厚偏惡性、均勻增厚偏反應性）、脂肪門（fatty hilum）消失/受壓/移位；US 對轉移敏感度 54–77%、特異度 80–88%。[^2]
- **單側 adenopathy → 首想隱匿乳癌**：孤立單側腋下 adenopathy 提示**隱匿性乳癌**，較少為淋巴瘤、轉移性黑色素瘤、卵巢癌或其他轉移癌；**須仔細檢查同側乳房影像**。[^1][^2][^3]（選項 D 正確）
- **孤立單側 + 無已知感染/發炎原因 → BI-RADS 4**：在無已知感染或發炎病因下，孤立單側腋下 adenopathy 應給**可疑（BI-RADS category 4）**評估。[^2][^3]（選項 B 正確）
- **雙側 adenopathy → 視情境而定（本題關鍵）**：**並非一律良性**。反應性/感染性（sarcoidosis、SLE、psoriasis、HIV，及其他發炎）＝良性 **BI-RADS 2**；但**無已知原因、尤其新出現**時可能為淋巴瘤/白血病之徵象＝可疑 **BI-RADS 4**，建議 US 導引 FNA 或 core biopsy。[^2][^3]（選項 C「雙側一律 BI-RADS 2」**錯誤**＝正解）
- **雙側腋下超音波確認對稱性**：可行**雙側腋下超音波**確認病灶為不對稱/單側。[^2][^3]（選項 A 正確）
- **BI-RADS 分派整理（ACR Atlas 5th / STATdx reporting tips）**：已知病因（已知淋巴瘤/CLL/HIV/sarcoid，乳房陰性）→ **BI-RADS 1 或 2**；可疑淋巴結且同側已知惡性 → **BI-RADS 4**；已知轉移淋巴結＋乳癌 → **BI-RADS 6**；篩檢見腋下不對稱/疑似結節而乳房其餘正常 → **BI-RADS 0**（需追加評估）。[^2]
- **無已知病因即需 work-up**：若無已知造成 adenopathy 之原因（如 RA、HIV、sarcoid、已知淋巴瘤），需進一步檢查（血球計數、周邊血抹片、胸片、CRP、系統性回顧）。[^2]

## 影像診斷
### 乳房攝影（Mammography）
- Level I 腋淋巴結約 50% 患者於常規乳攝/斷層可見；異常結節見於約 0.3% 篩檢乳攝。[^2]
- 正常：腎形、薄皮質、透亮脂肪門。異常：緻密、脂肪門消失、皮質增厚。大小非良惡性可靠指標（1–5 cm 皆可）；形態（long/short axis 比 <1.4 或局部皮質增厚 ≥3 mm）較重要。[^2]

### 超音波（US）
- 正常結節：回音性門部＋對稱腎形皮質。異常：低回音皮質、皮質厚 ≥3 mm（**均勻增厚偏反應性、偏心增厚偏轉移**）、門部受壓/消失/移位。[^2]
- Doppler：周邊/穿包膜血流偏惡性（惡性 50.5% vs 良性 2.9% 有非門部周邊血流）。silicone 沉積呈 "snowstorm" 表現。[^2]
- 影像導引切片：14-G core（83%）略優於 FNA（72%），兩者特異度 98–100%；疑淋巴瘤/白血病時至少一檢體置於 RPMI 1640 或生理食鹽水做流式細胞儀。[^2]

### MRI
- 皮質 T1 低、STIR 高訊號；正常與異常結節皆可早期皮質強化並 washout（強化型態非可靠鑑別）。轉移不明原發之腋 adenopathy，MR 可找出 50–86% 之原發。[^2]

### PET/CT
- 惡性結節 ≥7–8 mm 可偵測攝取；整體敏感度 61%、PPV 62%、NPV 79%——**不建議作為乳癌腋部常規分期**。反應性/發炎（如 sarcoid、HIV）亦可高攝取，不能單憑攝取判良惡性。[^2]

## 鑑別與報告要點
| 情境 | ACR BI-RADS Atlas 5th 評估 |
| --- | --- |
| 孤立單側、無已知感染/發炎原因 | **BI-RADS 4（可疑）**，提示隱匿乳癌，細查同側乳房[^2][^3] |
| 雙側、反應性/感染性（sarcoid/SLE/psoriasis/HIV） | **BI-RADS 2（良性）**[^2][^3] |
| 雙側、無已知原因（尤其新出現） | **BI-RADS 4（可疑）**——疑淋巴瘤/白血病，建議 US 導引 FNA/core[^2][^3] |
| 已知淋巴瘤/CLL/HIV，乳房陰性 | **BI-RADS 1 或 2**[^2] |
| 已知轉移淋巴結＋乳癌 | **BI-RADS 6**[^2] |
| 確認對稱性 | 可行**雙側腋下 US**[^2][^3] |

> [!warning] 常見陷阱
> 「雙側腋下 adenopathy 因常為反應性/感染性，一律評為良性 BI-RADS 2」是**錯的**——雙側 adenopathy 之評估**取決於臨床情境**：有已知反應性/感染性病因才給 2；無已知原因（尤其新出現）需警覺淋巴瘤/白血病並給 4。單側則首想隱匿乳癌。[^2][^3]

## 題目
> [!question]- When axillary adenopathy is seen at screening mammography with no suspicious findings in the breasts, which is FALSE per ACR BI-RADS Atlas 5th Edition? (2021-004)
> **C（雙側腋下 adenopathy 應一律評為良性 BI-RADS 2，因其常為反應性/感染性）為錯誤**——雙側 adenopathy 之評估**視情境而定**：反應性/感染性（sarcoid/SLE/psoriasis/HIV）給 BI-RADS 2，但無已知原因（尤其新出現）可能為淋巴瘤/白血病之徵象，給 BI-RADS 4 並建議 US 導引 FNA/core。A（雙側腋下 US 確認不對稱/單側）、B（孤立單側無已知感染/發炎原因 → BI-RADS 4）、D（單側提示隱匿乳癌，較少為淋巴瘤/黑色素瘤/卵巢癌等轉移，須查同側乳房）皆正確。[^2][^3]
