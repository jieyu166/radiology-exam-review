# coronary-vasculitis-complications

**冠狀動脈血管炎之三大併發症為「動脈瘤樣擴張（可破裂出血）、血栓形成、狹窄」，三者皆為已知併發症；共同途徑為慢性發炎造成血管壁破壞與加速性動脈粥狀硬化。成人最常見於結節性多動脈炎（PAN，冠狀動脈受累約 50%），兒童最常見於川崎氏病（Kawasaki disease）。** 判讀分水嶺：**CTA 上「管壁增厚強化 + 口徑改變（狹窄或動脈瘤）±閉塞」＝血管炎；臨床表現常跟著背景症候群走（Kawasaki 淋巴結/手足腫/草莓舌；PAN 腹痛；GCA 頭痛/陣發失明）。**

## Summary
- **三大併發症（皆屬已知）**：[^1][^2]
  - **動脈瘤樣擴張/ectasia（aneurysm/ectasia）**：≥1 條冠狀動脈瘤樣擴張，**可破裂出血**。
  - **血栓形成/閉塞（thrombosis/occlusion）**。
  - **狹窄（stenosis）**。
- **共同病理途徑**：慢性發炎致血管壁破壞 + **加速性動脈粥狀硬化（accelerated atherosclerosis）**。[^2]
- **好發族群**：**成人**最常見 **PAN**（冠狀動脈受累約 **50%**、男性為主）；**兒童**最常見 **Kawasaki disease**。[^1][^2]
- **對照**：**動脈粥狀硬化為成人冠狀動脈瘤最常見「總體」病因**；血管炎為重要之非粥狀硬化性病因。[^1]

## 放射科醫師影像判讀重點
- **CTA 徵象**：**管壁增厚 + 強化**、口徑改變（**狹窄或動脈瘤**）、不同程度狹窄甚至**閉塞**；慢性 Kawasaki 動脈瘤可**鈣化**。[^1]
- **分佈與型態**：aneurysm/ectasia 與 stenosis 可並存於同一冠狀動脈樹；OCT/IVUS 可辨管腔狹窄成因。[^1]
- **臨床連動**：影像判讀要結合背景症候群（Kawasaki/PAN/GCA/Takayasu），因表現「跟著症候群走」。[^1]
- **併發後果**：aneurysm 內血栓 → 心肌梗塞；aneurysm 破裂 → 出血/心包填塞——早期治療可降此風險。[^1]
- **COVID 關聯**：COVID-19 可伴 Kawasaki 樣血管炎，兒童/青少年需警覺。[^1]

## 臨床重點（5 句）
1. **三併發症全都算**：aneurysm、thrombosis、stenosis 皆為冠狀動脈血管炎併發症，無一可排除。[^1][^2]
2. **年齡分流**：成人 PAN（冠狀受累約 50%）、兒童 Kawasaki 為各自最常見。[^1][^2]
3. **共同途徑**：慢性發炎 + 加速性動脈粥狀硬化 → 瘤/狹窄/血栓。[^2]
4. **影像主力**：冠狀 CTA 看管壁強化/口徑改變/鈣化瘤；OCT/IVUS 輔助。[^1]
5. **早治關鍵**：適當治療降低心肌梗塞與動脈瘤破裂風險。[^1]

> [!note] 考點：下列何者非冠狀動脈血管炎之併發症？
> **以上皆會出現（D）**——動脈瘤樣擴張（可破裂出血）、血栓形成、狹窄三者皆為已知併發症，無一可排除。[^1][^2]
