# angiography-standing-wave

**Standing arterial wave 是血管攝影中因動脈壁彈性反射產生的波狀偽影，使用 vasodilator（如 nitroglycerin）可消除，增加 filming rate、injection rate 或 contrast volume 則無效。**

## Summary
- 機轉：contrast bolus 撞擊動脈壁產生反射波 [^1]
- 消除方法：**vasodilator**（使血管舒張、降低彈性反射） [^1]
- 增加 filming rate / injection rate / contrast volume 無法消除 [^1]

## 放射科醫師影像判讀重點
- **影像特徵**：於數位減影血管攝影（DSA）上呈現沿動脈長軸**規則、對稱、等間距的波浪／扇貝狀（scalloped）管徑起伏**，通常兩側緣對稱、間距一致，此對稱規則性是與真正病灶區分的關鍵。[^1]
- **與 fibromuscular dysplasia（FMD）之鑑別（首要陷阱）**：FMD 的「string-of-beads」呈**不規則、非對稱**的狹窄與瘤樣擴張交替，且為固定性病變；standing wave 為**一過性、規則對稱**，給予血管擴張劑或重複攝影後可消失，藉此區分。[^1]
- **與導管誘發痙攣（catheter-induced spasm）之鑑別**：痙攣多為局部、近導管尖端、管徑普遍變細；standing wave 為節律性波狀且分布較廣。兩者皆對血管擴張劑有反應，但形態不同。[^1]
- **消除／確認手法**：懷疑 standing wave 時，給予血管擴張劑（如 nitroglycerin）後重攝，波狀外觀消失即可確認為偽影；單純提高 filming rate、injection rate 或對比劑量無法消除，不應據此改變診斷。[^1]

## 臨床重點（5 句）
- Standing wave 為良性、暫時性的血管攝影現象，本身不代表血管病變，無臨床後果。[^1]
- 正確辨識可避免誤診為 FMD、血管炎或動脈剝離而導致不必要的處置。[^1]
- 此現象與血管壁平滑肌張力有關，血管舒張後即消失，屬功能性而非結構性變化。[^1]
- 較常於中等口徑動脈（如腸繫膜、腎、四肢動脈）觀察到。[^1]
- 判讀報告時宜註明為 standing wave 偽影，並說明其可逆性以利臨床理解。[^1]
