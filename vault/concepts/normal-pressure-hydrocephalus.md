# normal-pressure-hydrocephalus

**NPH 是可治療的失智病因，臨床三聯（Hakim triad）＝步態障礙（magnetic gait，常最早）＋尿失禁＋認知障礙（wet, wacky, wobbly），CSF 開口壓正常。** 影像診斷不能單靠一項，關鍵徵象組合為 **Evans index >0.3、acute callosal angle（<90°）、cingulate sulcus sign（後段窄於前段）**，加上 **DESH（腦室擴大＋Sylvian fissure/insular cistern 擴大＋高凸面/parafalcine 溝回擁擠）**。判讀分水嶺：**「刀刃狀腦回（knife-blade gyri）」是額顳葉萎縮（FTD/Pick 病）的徵象，不是 NPH**——NPH 反而在高凸面呈溝回擁擠而非刀刃狀萎縮，考題以此設陷阱。與腦萎縮的核心區分：NPH 為**不成比例**的蛛網膜下腔變化（下方 Sylvian 擴大、上方凸面擁擠）＋鑫狀胼胝體角變銳。

## Summary
- **臨床三聯（Hakim triad）**：步態/平衡障礙（magnetic gait，常最早出現）、逼尿肌過動之尿失禁、認知障礙（輕至失智）；開口壓在正常範圍（<18–20 cmH₂O）。[^1]
- **腦室擴大量測**：**Evans index >0.3**（額角最大寬 / 顱內最大橫徑）；顳角 >6 mm（非海馬萎縮所致）；**callosal angle 變銳（<90°，冠狀面經後聯合垂直於 AC-PC 量測）**；胼胝體上弓。[^1][^2]
- **不成比例蛛網膜下腔變化**：Sylvian fissure 與 insular cistern 擴大、高凸面與 medial/parafalcine 溝回**擁擠（effacement）**、**cingulate sulcus sign（後半段窄於前半段）**、凸面個別溝回局部擴大。[^1][^2]
- **DESH**（disproportionately enlarged subarachnoid space hydrocephalus）＝腦室擴大＋Sylvian/insular 擴大＋凸面擁擠三者組合，支持診斷。[^1]
- **腦實質變化**：室周低密度（CT）或 T2-FLAIR 高訊號（transependymal oedema／小血管病）。[^1]
- **CSF flow**：導水管 flow void 明顯（流速增高）；aqueductal stroke volume/peak velocity 可輔助但非必要。[^1]
- **鈑刀刃狀腦回（knife-blade gyri）非 NPH**：屬額顳葉萎縮（FTD/Pick 病）之嚴重局部萎縮徵象。[^2]（詳見「鑑別與報告要點」）
- **治療**：確診後以 CSF 分流（多為 VP shunt）；病人選對時約 80% 有反應；步態先於認知惡化、症狀短（<6 個月）、CSF tap test 陽性者預後較好。[^1]

## 影像診斷
### CT
- 可顯示腦室擴大與不成比例蛛網膜下腔變化，但顯示解剖細節劣於 MRI；可見室周低密度。[^1]

### MRI（首選）
- **矢狀面**：cingulate sulcus sign（後半窄於前半）、胼胝體上弓。[^1][^2]
- **冠狀面（經後聯合）**：**callosal angle 變銳（<90°）**——與 Alzheimer/腦萎縮（角度較鈍、>90°）鑑別的關鍵量測。[^1][^2]
- **軸位**：Evans index >0.3、顳角擴大、Sylvian/insular 擴大並列高凸面溝回擁擠（DESH）；T2-FLAIR 室周高訊號。[^1]
- **CSF flow study**：導水管 flow void／stroke volume 可輔助排除阻塞性水腦與支持診斷。[^1]

### 核醫（次要）
- Cisternography：放射性藥物早期進入側腦室（heart-shaped）、逾 24–48 小時滯留、不上達凸面——為輔助但重要性低。[^1]

## 鑑別與報告要點
| 對照 | NPH | 腦萎縮 / 其他 |
|---|---|---|
| Callosal angle（冠狀，經後聯合） | **銳角 <90°** | Alzheimer/萎縮多**鈍角 >90°** |
| 凸面/高位溝回 | **擁擠（DESH）** | 瀰漫性擴大 |
| Knife-blade gyri（刀刃狀腦回） | 無（反而擁擠） | **FTD/Pick 病**之嚴重局部萎縮徵象 |
| 顳角旁/海馬周裂 | 較不擴大 | Alzheimer 海馬周裂明顯擴大 |
| 臨床 | wet/wacky/wobbly、可治療 | 對應各失智/退化病 |

**報告要點**：量測 Evans index 與 callosal angle、描述 cingulate sulcus sign 與 DESH 型態；提醒臨床 NPH 不能單靠影像診斷、需結合三聯與 tap test；勿把凸面溝回擁擠誤讀為萎縮，也勿把刀刃狀萎縮誤歸 NPH。[^1][^2]

## 題目
> [!question]- Which of the following is not a classical radiological sign of normal pressure hydrocephalus (NPH)? (2021-063)
> **D（"Knife-blade" configuration of gyri——非 NPH 徵象）**——刀刃狀腦回是**額顳葉萎縮（FTD/Pick 病）**的嚴重局部萎縮表現；NPH 在高凸面反而呈溝回擁擠。A（Evans index >0.3）、B（acute callosal angle <90°）、C（cingulate sulcus sign，後段窄於前段）皆為 NPH 經典徵象（另含 DESH、Sylvian fissure 擴大）。
