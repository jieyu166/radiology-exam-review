# postpartum-hemorrhage-embolization

**產後出血（PPH）動脈栓塞的主要出血來源是『子宮動脈（uterine artery）』——卵巢動脈與圓韌帶動脈雖是子宮的重要『側枝吻合』來源，但並非主要出血源。** 判讀分水嶺：**主要出血源＝子宮動脈（雙側栓塞，因子宮血供左右交叉吻合豐富）；子宮切除後仍出血不會只是卵巢動脈（需找其他側枝如陰部內動脈等）；gelfoam 優於 coils（coils 近端阻斷、側枝易快速再灌流致失敗；gelfoam 達遠端小血管、栓至血流停滯更完全）；目前證據對停經與生育無顯著長期不良影響。**

## Summary
- **主要出血來源**：**子宮動脈**——雙側栓塞為標準（子宮血供左右交叉吻合豐富）；**卵巢/圓韌帶動脈為主要側枝吻合來源而非主要出血源**。[^1][^2]
- **子宮切除後持續出血**：**非單純以卵巢動脈為唯一來源**——需考慮其他側枝（如陰部內動脈等），不可視卵巢動脈為 sole source。[^1][^2]
- **栓塞材料**：**gelfoam 優於 coils**——coils 阻斷位置較近端、側枝快速代償再灌流易失敗；**gelfoam 可達遠端小血管、栓至血流停滯（stasis）更完全**（UAE 多優先 gelfoam）。[^1][^2]
- **對停經/生育影響**：**目前證據對停經（menopause）與懷孕（fertility/pregnancy）無顯著長期不良影響**。[^1][^2]

## 放射科醫師影像判讀重點
- **雙側 UAE**：因交叉吻合，單側栓塞常不足，標準為雙側栓至停滯。[^1]
- **找 extravasation/側枝**：DSA 找造影劑外滲/假性動脈瘤；若子宮動脈栓後仍出血，找卵巢/陰部內/陰道動脈等側枝。[^1][^2]
- **材料選擇**：出血情境優先 gelfoam（遠端、暫時、完全）；coils 用於局部大血管/假性動脈瘤但單用於 UAE 易失敗。[^2]
- **適應症**：對子宮收縮劑/藥物/內視鏡難治之 PPH、可保留子宮；也用於胎盤植入/genital tract injury。[^2]
- **併發/追蹤**：多數保留生育；監測缺血併發（罕見子宮壞死），對月經/懷孕無顯著長期影響。[^1][^2]

## 臨床重點（5 句）
1. **主源**：子宮動脈（雙側栓塞）。[^1][^2]
2. **側枝**：卵巢/圓韌帶為吻合來源；切除後出血找其他側枝。[^1][^2]
3. **材料**：gelfoam 優於 coils（達遠端、栓至停滯）。[^1][^2]
4. **生育**：對停經/懷孕無顯著長期不良影響。[^1][^2]
5. **適應症**：藥物難治 PPH，可保留子宮。[^2]

> [!note] 考點：關於 TAE for PPH，何者「錯誤」?
> 「**主要出血來源是 uterine arteries 或 ovarian arteries（A）**」錯誤——**主要出血源為子宮動脈**，卵巢與圓韌帶動脈為主要側枝吻合來源而非出血源。子宮切除後持續出血非單純卵巢動脈為唯一來源、coils 較 gelfoam 易失敗、目前對停經/懷孕無顯著影響，皆正確。[^1][^2]
