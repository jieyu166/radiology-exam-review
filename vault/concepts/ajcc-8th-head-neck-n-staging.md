# ajcc-8th-head-neck-n-staging

**AJCC 第 8 版（2018-01-01 起）首次把「腺外擴散（extranodal extension, ENE）」正式納入頭頸癌 N 分期——臨床明顯之 ENE 陽性不論淋巴結大小或側別，一律歸 cN3b，為第 8 版最重要變革。ENE 是「非 HPV 相關（p16−）」SCC 之 N 分期決定因子；HPV(+) 口咽、鼻咽、甲狀腺癌另有獨立 N 分期。** 判讀分水嶺：**cN3b＝臨床/影像明顯 ENE（任何大小）；但『病理』門檻較高——≤3 cm 節合併 ENE：臨床 cN3b、病理僅 pN2a。惡性淋巴結判讀要「多判準併用」（大小＋圓形＋成簇＋壞死＋ENE），單靠大小誤差 10–20%。影像 ENE（iENE）分三級。記憶鉤：ENE 任何大小＝cN3b、≤3cm 病理＝pN2a、HPV+ 另計。**

## Summary
- **版本變革**：第 8 版首次將 ENE 納入 N 分期（第 7 版無）。[^1][^3]
- **ENE 適用**：ENE 為 non-HPV（p16−）SCC 的 N 分期決定因子；nodal 分期綜合位置、數目、大小、側別與 ENE。[^1][^3]
- **cN3b**：任何淋巴結轉移合併臨床明顯 ENE，不論大小或側別。[^1][^3]
- **臨床 vs 病理**：≤3 cm 節合併 ENE 時，臨床為 cN3b、病理為 pN2a。[^2][^3]
- **部位例外**：HPV(+) 口咽、鼻咽、甲狀腺癌另有獨立 N 分期系統，並非同樣使用 ENE。[^3]

## 放射科醫師影像判讀重點

### 惡性淋巴結判準（多判準併用）
- **大小**：level I/IIA ≥15 mm、IIB–VI ≥10 mm、**retropharyngeal ≥8 mm**（長軸；**單靠大小誤差 10–20%**）。[^3]
- **形態**：**圓形（長軸:短軸 < 2）**、**成簇（≥3 顆 8–9 mm）**、**局部缺損/壞死**（異質、可囊變，須與脂肪 hilum 區分）；**>3 cm 多為融合結節塊→找 ENE**，>3 cm 無壞死不太像 SCC。[^3]
- **ENE 徵象**：腫瘤浸潤結外脂肪/鄰近血管/器官/肌肉→邊界不清、包膜不規則強化、周邊脂肪浸潤。[^3]

### 影像 ENE（iENE）分級（ASHNR/ESHNR/AOSHHNR 聯合）
- **Grade 1＝結周脂肪浸潤；Grade 2＝結節融合；Grade 3＝侵犯周圍器官**；**須有明確影像證據才判、符合多級時取最高級**。[^3]

### 分區、引流與可切除性
- **分區 I–VII**（AJCC/AAO-HNS）；**下咽引流 level II、III > IV，pyriform/後壁可及 RPN**；**level VII 屬區域轉移、其餘縱膈屬遠端 M1**。[^3]
- **手術不可切除徵象**：**頸動脈包覆 ≥270°、侵犯 prevertebral 肌、high skull base、dermal lymphatics**。[^3]

### 模態、DDx、unknown primary
- **CECT 或 MR**（CT 對 nodal 偵測與 iENE 略優、MR 對 RPN 較佳）；**US（hilar echogenicity/血流消失＋周邊血流增加）＋FNA**；**PET FDG 約 75% 準（cystic 節易偽陰）**；**DWI 勿用於良惡性鑑別**。[^3]
- **DDx**：反應性（卵圓形）、第二鰓裂囊腫（擬 cystic level II）、化膿性、甲狀腺癌節（鈣化/囊/高密度，level VI/III/IV）、非何杰金淋巴瘤（多發非壞死）、非頭頸惡性（鎖骨上/Virchow/Troisier）。[^3]
- **Unknown primary 四大部位**：鼻咽 fossa of Rosenmüller（EBV+）、口咽 palatine tonsil（p16+）、lingual tonsil（p16+）、下咽 pyriform apex。[^3]

## 臨床重點（5 句）
1. **預後**：**淋巴結轉移為頭頸 SCC 最重要預後因子**；報告須含大小/數目/側別/ENE。[^3]
2. **ENE 角色**：**ENE 為 non-HPV SCC 之 N 分期決定因子**；臨床明顯 ENE＝cN3b。[^1][^3]
3. **流行病學**：**level IIA 最常受累**；淋巴結轉移比例最高＝鼻咽癌（~85%）、最低＝聲門型喉癌（<10%）。[^3]
4. **臨床情境**：轉移節無原發＝「unknown primary」；**成人新頸部腫塊惡性至證明為止**；cystic level II 節易誤為鰓裂囊腫。[^3]
5. **治療**：切除 ± 放療/化放療；頸部廓清分**根治性（level I–V＋SCM/IJV/CN XI）、改良根治性、選擇性**。[^3]

> [!note] 考點：3cm 同側轉移淋巴結合併腺外擴散於下咽癌之 N 分期？
> **N3b**——依 AJCC 第 8 版，任何淋巴結轉移合併臨床明顯 ENE 即歸為（c）N3b，不論大小/側別。（註：若為病理分期，≤3 cm + ENE 為 pN2a。）[^1][^3]
