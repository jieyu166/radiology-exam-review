# postoperative-stomach

**胃切除/胃腸吻合術後常見併發症：dumping syndrome、afferent loop syndrome、stomal（吻合口）阻塞、邊緣潰瘍、膽汁逆流性胃炎、殘胃癌;Zollinger-Ellison（ZES）是 gastrinoma 引起的高胃酸，屬原發疾病，不是手術併發症。** 判讀分水嶺：**afferent loop syndrome＝Billroth II 後輸入袢阻塞,US/CT 見上腹擴張充液的 C 形管狀構造（越過中線）;dumping＝食物快速排空致血管／低血糖症狀;ZES 與術後解剖無關。**

## Summary
- **常見術後胃併發症**：[^1]
  - **Dumping syndrome**：胃排空過快 → 早期（滲透/血量）或晚期（反應性低血糖）症狀。
  - **Afferent loop syndrome**：胃空腸吻合**輸入袢（afferent limb）機械性阻塞**（Billroth II、部分胃切除、Roux-en-Y、gastric bypass、pancreaticoduodenectomy 後皆可）,影像見上腹擴張充液管狀構造（越過中線的 C 形/U 形）、可膽道擴張;PD 後約 13%。[^2]
  - **Stomal（吻合口）obstruction**：吻合口水腫/狹窄/疝。
  - 其他：邊緣（marginal）潰瘍、鹼性逆流性胃炎、傾倒、殘胃癌、bezoar。
- **非術後併發症**：**Zollinger-Ellison syndrome（ZES）為 gastrinoma 分泌過量 gastrin → 高胃酸／多發頑固消化性潰瘍**,屬原發內分泌腫瘤疾病,與胃手術無因果。[^1]

## 放射科醫師影像判讀重點
- **檢查選擇（Woodfield & Levine）**：**早期併發症用水溶性對比造影排除 leak/阻塞；晚期用鋇劑評估吻合口狹窄/潰瘍/膽汁逆流性胃炎/復發腫瘤；CT 偵測膿瘍/積液/復發轉移/afferent loop/腸套疊**。[^3]
- **辨識正常術後解剖（Woodfield，關鍵）**：**熟悉常見術式（partial gastrectomy、esophagogastrectomy + gastric pull-through、total gastrectomy + esophagojejunostomy）之正常術後外觀，以免把正常影像誤為 pseudoleak 或併發症**。[^3]
- **afferent loop syndrome（STATdx/Radiopaedia）**：Billroth II 後輸入袢阻塞——**US/CT 見上腹擴張充液之 C/U 形管狀構造（越過中線）± 膽道擴張**；PD 後約 13%；膽汁性嘔吐後暫緩。[^2]
- **早期 vs 晚期併發症（Woodfield）**：**早期＝leak/吻合口漏、阻塞、膿瘍、出血；晚期＝吻合口狹窄/邊緣潰瘍、膽汁逆流性胃炎、傾倒、殘胃癌、bezoar、gastrojejunal intussusception**。[^3]
- **陷阱**：ZES（gastrinoma 高胃酸）為原發內分泌疾病、非術後併發症；勿與術後邊緣潰瘍混淆。[^1]

## 臨床重點（5 句）
1. **術式適應（Woodfield）**：胃手術用於良/惡性上消化道疾病（消化性潰瘍、胃癌）；不同術式決定術後解剖與併發症譜。[^3]
2. **dumping syndrome**：胃排空過快 → **早期（滲透/血量、餐後即發）或晚期（反應性低血糖）**症狀。[^1]
3. **afferent loop syndrome**：輸入袢機械阻塞致上腹痛/脹/膽汁性嘔吐；PD 後約 13%。[^2]
4. **殘胃癌**：胃部分切除後長期風險增，晚期併發症需監測。[^1][^3]
5. **非併發症**：**ZES（gastrinoma）**為原發疾病，與胃手術無因果。[^1]

> [!note] 考點：何者「不是」術後胃的併發症?
> 「**Zollinger-Ellison syndrome**」不是——ZES 為 gastrinoma 引起的高胃酸,非手術併發症。Dumping、afferent loop、stomal obstruction 皆為術後胃常見併發症。[^1]

## 題目
> [!question]- 何者「不是」術後胃（postoperative stomach）的併發症? (2017-193)
> 「**Zollinger-Ellison syndrome**（C）」不是——ZES 為 gastrinoma 引起的高胃酸/頑固潰瘍,屬原發疾病。Dumping syndrome、afferent loop syndrome、stomal obstruction 皆為術後胃併發症。[^1]
