# plantar-fibroma

**足底纖維瘤（Ledderhose disease）＝足底腱膜的良性纖維增生，是足踝最常見的實性軟組織腫瘤。因膠原含量高，在 MRI 上 T1、T2「都偏低到中等訊號」（不是高訊號）；病灶會有內部強化並可見「fascial tail sign」（強化沿腱膜延伸的線狀影）。** 判讀分水嶺：足底腱膜（多在中/內側帶）梭形/多結節腫塊、與跟骨附著點分開、T1/T2 低-中訊號＋fascial tail＝plantar fibroma；若訊號高或邊界侵犯，要重新想（黏液性/侵襲型/肉瘤）。

## Summary
- **定義/命名**：足底腱膜的良性纖維母細胞增生，又稱 Ledderhose disease；為足踝最常見的實性軟組織腫瘤。[^1][^2]
- **臨床**：足底可觸及的硬結節，長時間站立/行走後可有輕微疼痛；與 Dupuytren 攣縮、Peyronie 病等纖維增生性疾病相關。[^1][^2]
- **MRI 訊號（本題關鍵）**：因膠原含量高，病灶在 **T1 呈等-低訊號、T2 呈低-中等訊號**（相對肌肉）——**並非「T1、T2 均勻高訊號」**。[^1][^2]
- **強化與 fascial tail sign**：注射對比劑後呈**不等程度內部強化**，並可見 **fascial tail sign**——強化沿足底腱膜（aponeurosis）延伸的線狀影，為特徵性徵象。[^1]
- **部位/多發**：多位於足底腱膜的中央或內側帶、與跟骨附著點分開；約 1/3 雙側、症狀側約 1/4 為多發。[^2]

## 放射科醫師影像判讀重點
- **超音波**：與跟骨附著點分開的梭形/多結節腱膜增厚，低回音（~75%）或等回音（~25%）；多數（~90%）無明顯內部血流。[^2]
- **MRI**：梭形/多結節腱膜增厚、不侵犯跟骨起點；**T1 等-低、T2 低-中訊號**（膠原多）；Gd 後不等強化，可見 fascial tail sign。[^1][^2]
- **判讀陷阱**：若病灶大且邊界呈浸潤性，須考慮較罕見的侵襲型足底纖維瘤病（aggressive plantar fibromatosis）；訊號偏高或明顯 T2 亮則不典型，應重新鑑別（軟組織肉瘤等）。[^1][^2]
- **鑑別**：黃色瘤（xanthoma，散斑狀）、足底滑囊炎、足底腱膜撕裂（外傷史、腱膜不連續）。[^2]

## 題目
> [!question]- Which description about plantar fibroma is WRONG? (2022-372)
> **C（錯誤）— 「因膠原含量高，足底纖維瘤在 T1、T2 均呈均勻高訊號」為錯**。正好相反：膠原含量高使病灶在 **T1、T2 均呈等-低（低-中）訊號**（Radiopaedia：T1 iso-low、T2 low-intermediate；STATdx：T1 isointense、T2 hypo-to-isointense）。A（Ledderhose disease、足踝最常見實性軟組織腫瘤）、B（足底可觸及腫塊、久站/久走後輕微疼痛）、D（內部強化＋fascial tail sign，強化沿腱膜延伸）皆為正確描述。⚠️ 匯入題庫的原始答案標為 D，但依 Radiopaedia＋STATdx 查證，正確「錯誤選項」應為 C（D 的內部強化與 fascial tail sign 為真實特徵）。[^1][^2][^3]
