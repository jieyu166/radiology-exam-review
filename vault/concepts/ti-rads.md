# ti-rads

**ACR TI-RADS 的五個評估項目為：composition、echogenicity、shape、margin、echogenic foci。Vascularity（血流）不包含在 TI-RADS 評估項目中。**

## Summary
- ACR TI-RADS 五大評估項目 [^1]：
  1. **Composition**：cystic / spongiform / mixed / solid
  2. **Echogenicity**：anechoic / hyperechoic / isoechoic / hypoechoic / very hypoechoic
  3. **Shape**：wider-than-tall / taller-than-wide
  4. **Margin**：smooth / ill-defined / lobulated / irregular / extra-thyroidal extension
  5. **Echogenic foci**：none / large comet-tail / macrocalcification / peripheral calcification / punctate echogenic foci
- **Vascularity 不是 TI-RADS 評估項目**（舊版 Kwak TI-RADS 曾納入，ACR TI-RADS 已移除）[^1]

## 放射科醫師影像判讀重點
- **點數化評分**：ACR TI-RADS 對五類別各特徵給分後加總，分為 TR1（良性）至 TR5（高度懷疑）；越懷疑惡性之特徵給分越高。[^2]
- **高風險特徵（各給高分）**：solid composition、very hypoechoic、taller-than-wide（縱橫比 >1）、lobulated/irregular margin 或甲狀腺外侵犯、punctate echogenic foci（微鈣化）。[^2]
- **低風險線索**：純囊性或海綿狀（spongiform）結節可判為良性（TR1），大彗尾偽影（large comet-tail artifact）不給分。[^2]
- **切片/追蹤閾值**：依 TR 分級結合結節最大徑決定 FNA 或超音波追蹤（如 TR5 ≥1 cm 建議 FNA、TR3/TR4 有較高徑閾值），旨在減少不必要切片。[^2]
- **判讀陷阱**：vascularity（血流）非 ACR TI-RADS 評分項目（舊 Kwak 版曾納入）；echogenic foci 中須區分微鈣化（punctate，惡性提示）與良性彗尾/巨鈣化/周邊鈣化。[^2]

## 臨床重點（5 句）
- 甲狀腺結節在頸部超音波極常見，絕大多數為良性；風險分層旨在挑出少數需切片或手術者。[^2]
- ACR 於 2012 年成立委員會，先於 2015 年發表偶見結節報告建議與超音波詞彙（lexicon），再據此提出 TI-RADS。[^2]
- TI-RADS 借用乳房 BI-RADS 的分級與報告架構概念，統一甲狀腺超音波用語與處置建議。[^2]
- 其臨床目標是在不漏診惡性的前提下，降低對良性結節不必要的細針抽吸與追蹤。[^2]
- 分層依據為超音波影像外觀而非臨床或實驗室資料，適用於成人甲狀腺結節之標準化報告。[^2]

## 陷阱
- 不要把 vascularity 當成 TI-RADS 項目，這是常見考題陷阱
