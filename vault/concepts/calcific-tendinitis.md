# calcific-tendinitis

**鈣化性肌腱炎＝羥基磷灰石（hydroxyapatite）沉積於肌腱，最好發旋轉肌袖的棘上肌腱（supraspinatus，約 80%）。鈣化在 MRI 各序列皆呈低訊號，容易被忽略——所以要靠「梯度回訊（GRE）序列的 blooming artifact」來放大偵測微小鈣化。** 判讀分水刀：X 光/CT 對鈣化最敏感；MRI 上鈣化為 all-sequence 低訊號，GRE 的磁化率 blooming 反而是幫手（不是無用）。

## Summary
- **病因（Uhthoff 循環）**：確切病因不明，一般認為與局部微創傷（microtrauma）及局部氧張力降低（decreased oxygen tension）導致纖維軟骨化生後續發性礦化有關；病程分 precalcific → calcific（formative）→ resorptive（最痛，鈣質外滲入滑囊）→ postcalcific 四期。[^1][^2]
- **好發部位**：可侵犯全身任何肌腱，但典型為旋轉肌袖，尤以**棘上肌腱（約 80%）**最常見。[^2]
- **好發族群**：30–60 歲中年、女性略多。[^1]
- **MRI 訊號**：鈣化沉積呈邊界清楚的卵圓/分葉狀病灶，**於所有脈衝序列皆為低訊號**；周邊可有肌腱病變水腫。[^2]
- **GRE 的價值（本題關鍵）**：梯度回訊序列因磁化率效應在低訊號鈣化周圍產生 **blooming artifact（暈染放大）**，**有助於偵測微小鈣化**——故「GRE 對偵測微小鈣化無幫助」的敘述是錯的。[^2]

## 放射科醫師影像判讀重點
- **X 光/CT**：沿肱骨頭邊緣的鈣化為最直接證據；CT 對鈣化最敏感，呈絨毛狀/無定形鈣化。[^2]
- **MRI**：鈣化在 T1/T2/PD 各序列皆低訊號，易被漏看；**GRE 的 blooming artifact 可放大微小鈣化的可見度**（重要判讀技巧，非無用）；鄰近肌腱水腫、肩峰下-三角肌下滑囊炎、甚至肱骨頭骨內水腫（resorptive 期鈣質外滲）皆為伴隨徵象。[^2]
- **超音波**：肌腱/滑囊內強回音灶，並為影像導引沖洗（barbotage/lavage）之首選工具。[^2]
- **鑑別**：副甲狀腺機能亢進、腫瘤性（特發性）鈣質沉著、關節內游離體、焦磷酸鹽關節病（CPPD）。[^2]

## 題目
> [!question]- Which description about calcified tendinitis is WRONG? (2022-371)
> **D（錯誤）— 「梯度回訊（GRE）序列對偵測微小鈣化無幫助」為錯**。實際上 GRE 因磁化率效應在鈣化周圍產生 blooming artifact，反而**有助**偵測微小鈣化（STATdx 明載 blooming artifact around low-signal calcific deposits）。A（病因為微創傷＋氧張力降低致續發礦化）、B（可侵犯任何肌腱、典型旋轉肌袖尤棘上肌）、C（邊界清楚卵圓/分葉狀、各序列皆低訊號）皆正確。[^1][^2][^3]
