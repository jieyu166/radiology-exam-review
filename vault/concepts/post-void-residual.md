# post-void-residual

**餘尿量（PVR）＝排尿後膀胱內殘留的尿量；超音波以前列橢球體公式（長 × 寬 × 高 × 0.52）估算。判讀分水嶺：正常成人排尿後膀胱應近乎排空——超音波考試教材以「不超過約 20 mL」為界；臨床/影像文獻則多以 <50 mL 為正常、>100–200 mL 才算明確異常，門檻依採用來源不同，作答與報告須標明依據。**

## Summary
- **定義**：PVR 為排尿（micturition）後殘留於膀胱內之尿量，反映膀胱排空效率。[^1]
- **正常門檻（超音波考題依據）**：正常成人餘尿量**不應超過約 20 mL**（超音波複習教材）。[^3]
- **異常門檻（臨床/影像）**：Radiopaedia 將**明確升高之 PVR 定義為超過 100–200 mL**；介於其間屬邊界值，臨床常以 <50 mL 為正常上限。[^1]
- **量測方法**：超音波以**前列橢球體公式（prolate ellipsoid：長 × 寬 × 高 × 0.52）**估算膀胱體積，便於床邊／膀胱掃描器評估。[^2]
- **臨床意義**：PVR 升高提示**膀胱出口阻塞（如良性前列腺增生 BPH）或逼尿肌無力／神經性膀胱**，可續發膀胱壁增厚、小樑化、憩室、上尿路擴張與感染。[^2]

## 放射科醫師影像判讀重點
- **測量時機與技術**：請病患排尿後**立即**掃描；膀胱視為橢球體，取最大橫徑、前後徑與上下徑代入 ×0.52 得體積，延遲會因新尿液生成而高估。[^1][^2]
- **門檻依來源而異的陷阱**：超音波複習教材以 ~20 mL 為正常上限；臨床/影像文獻多以 >100–200 mL 為明確異常、<50 mL 為正常——報告與考題作答須認清所依據之標準。[^1][^3]
- **續發徵象一起看**：PVR 升高時同步評估膀胱壁增厚/小樑化、憩室、前列腺體積與膀胱內前列腺突出（IPP），以及有無雙側腎積水，判斷阻塞程度。[^2]

## 題目
> [!question]- Postvoid residual in a normal adult urinary bladder should not exceed: (2022-470)
> **B. 20 mL（關鍵）**——超音波複習教材以正常成人排尿後餘尿量**不超過約 20 mL** 為界，代表膀胱近乎完全排空。⚠️ 臨床/影像門檻不同：Radiopaedia 以 PVR **>100–200 mL** 為明確異常、常以 <50 mL 為正常，故答案依採用之標準而異，本題採超音波教材觀點取 20 mL。餘尿升高提示膀胱出口阻塞（BPH）或神經性膀胱。[^1][^3]
