# sarcoidosis-msk

**急性類肉瘤關節炎（Lofgren syndrome）的踝關節腫脹為 periarticular soft tissue swelling 及 tenosynovitis，真正的 synovitis 或 joint effusion 少見。**

## Summary
- Lofgren syndrome triad：bilateral hilar LAD + erythema nodosum + joint pain [^1]
- 急性關節炎的關節腫脹 = **periarticular soft tissue swelling + tenosynovitis**，非 true synovitis/effusion [^1]
- MRI 可見 tenosynovitis / tendinitis / bursitis / synovitis，但表現非特異性 [^1]
- Sarcoid muscle nodule：fusiform、longitudinal、central low signal on T2WI/T1W C+ FS [^1]
- 指骨：lacy trabecular pattern，無明顯骨膜反應 [^1]

## 放射科醫師影像判讀重點
- **X 光（骨骼）**：慢性肌骨類肉瘤好發於手足短管狀骨，典型為 lacy／reticulated trabecular pattern、囊狀或穿鑿樣（punched-out）溶骨病灶，通常無明顯骨膜反應。[^2]
- **急性關節炎（Löfgren）判讀**：踝／足周圍腫脹多為 periarticular soft tissue swelling 併 tenosynovitis，而非真正 synovitis／關節積液；X 光常僅見軟組織腫脹而無骨侵蝕。[^1][^2]
- **MRI**：對肌肉、肌腱與骨髓病灶最敏感；可見 tenosynovitis／tendinitis／bursitis／synovitis 及骨髓浸潤，惟表現非特異，須結合臨床與其他系統受累判讀。[^2]
- **肌肉結節型**：sarcoid muscle nodule 呈 fusiform、沿肌纖維縱走，T2WI 與 T1W 增強脂肪抑制影像可見中央低訊號（「dark star／three‑stripe」樣），為相對特徵之判讀線索。[^1][^2]
- **判讀陷阱（pitfall）**：肌骨類肉瘤影像常與其他發炎性／退化性關節病、感染或轉移重疊；於已知類肉瘤病人若見不明骨關節或肌肉病灶，應將本病納入鑑別並考慮 MRI 篩檢。[^2]
- **中軸骨病灶 vs 轉移（高頻考點）**：大骨與中軸骨（脊椎、骨盆、近端股骨）之類肉瘤病灶常在 X 光與骨掃描上隱匿，須靠 MRI 顯示；但其 MRI 訊號（T1 低、fluid-sensitive 高、會強化）與骨轉移／多發性骨髓瘤**完全重疊**——**標準 MRI 無法可靠區分類肉瘤中軸骨病灶與轉移**，確診常需切片。唯一相對有用線索為病灶內含脂肪（involuting granuloma）於已知類肉瘤者偏向類肉瘤（特異度高但敏感度低）。[^3]

## 臨床重點（5 句）
- Löfgren 症候群為急性類肉瘤，三聯徵為雙側肺門淋巴結腫大、結節性紅斑與關節痛，預後通常良好。[^1]
- 肌肉受累於活動性類肉瘤其實常見，但多為臨床無症狀而易被忽略。[^2]
- 若標準 X 光陰性而病人有無法解釋之骨關節症狀，臨床可考慮以 MRI 進一步評估。[^2]
- 骨性類肉瘤常見於已有肺部及皮膚侵犯之慢性病人，代表全身性病程。[^2]
- 影像表現非特異，確診仍須結合臨床、實驗室與必要時之組織病理。[^2]

## 題目
> [!question]- Regarding MRI features of sarcoidosis involving the musculoskeletal system, all of the following are true EXCEPT? (2022-459)
> **B（關鍵，錯誤敘述）：Axial bone lesions may be distinguished from metastases using standard MRI techniques**——此為「除外」的錯誤選項。中軸骨類肉瘤病灶與骨轉移在標準 MRI 上訊號／強化完全重疊（T1 低、fluid-sensitive 高、會強化），**無法可靠區分**，確診常需切片。其餘皆真：MRI 可顯示 X 光隱匿之骨髓／軟組織病灶(A)、軟組織可見肌肉水腫與結節狀強化病灶(C)、關節可見 synovitis／tenosynovitis／積液與軟骨下骨髓水腫(D)。詳見 [[sarcoidosis-msk]]。[^3]
