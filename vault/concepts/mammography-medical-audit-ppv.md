# mammography-medical-audit-ppv

**乳房攝影醫學稽核（medical audit）的三個陽性預測值分水嶺：PPV1＝篩檢陽性判讀（分母含 BI-RADS 0、3、4、5，切記別漏掉 category 3！）；PPV2＝建議切片者（category 4、5）；PPV3＝實際做了切片者（category 4、5，即陽性切片率／PBR）。**

## Summary
- **PPV1（abnormal findings at screening）**：所有「篩檢陽性判讀」中 1 年內確診乳癌的百分比；ACR BI-RADS 定義分母為 **BI-RADS category 0、3、4、5**（category 3 若在篩檢時給定也算陽性）。[^1][^2]
- **PPV2（biopsy recommended）**：所有「建議組織診斷／外科會診」（**BI-RADS 4、5**）中 1 年內確診乳癌的百分比。[^2]
- **PPV3（biopsy performed）**：所有「實際執行切片」（**BI-RADS 4、5**）中確診乳癌的百分比，又稱 **Biopsy Yield of Malignancy／Positive Biopsy Rate（PBR）**；為 FDA 法規要求收集之數據。[^2]
- **台灣**：乳房攝影品質保證由衛生福利部（DOH/衛福部）規範。[^1]
- **Recall rate（回招率／abnormal interpretation rate）**：篩檢時「需再評估」者占總篩檢數的比例；在純篩檢情境下分子＝**BI-RADS category 0**（不完整、需追加影像）之篩檢數 ÷ 總篩檢數。**只含 category 0，不含 4、5**（4、5 通常於診斷性檢查後才給定）。[^4]
- **CDR（cancer detection rate，癌症偵測率）**：所偵測之惡性數 ÷ 總篩檢數（常以每 1000 例表示）。[^4]
- **category 3 之陽/陰性歸屬**：在 **screening** 給定的 category 3 屬「陽性判讀」（其偽陽性計入 FP1、亦計入 PPV1 分母）；在 **diagnostic** 給定的 category 3 屬「陰性判讀」（probably benign，建議短期追蹤而非切片）。[^2]

## 放射科醫師影像判讀重點
- **稽核邏輯**：PPV1 → PPV2 → PPV3 是「篩檢 → 建議切片 → 實際切片」的漏斗；PPV 值通常 PPV3 ≥ PPV2 ≥ PPV1，因分母逐步限縮至更可疑的族群。[^2]
- **易錯陷阱**：PPV1 分母**必須包含 category 3**（篩檢時給定的 probably benign），只寫「0、4、5」是錯的；category 3 的 false positive 亦計入 FP1。[^2]
- **PPV2 vs PPV3**：PPV3 因「已做切片」故較能反映真實癌症狀態、且較高；但 PPV2 更能反映「判讀醫師的解讀表現」（醫師無法控制哪些被推去做切片）。[^2]
- **BI-RADS 各評估分類的癌症 PPV（供對照）**：category 2＝0%、3＝≤2%、4＝>2% 至 <95%（4A >2–≤10%、4B >10–≤50%、4C >50–<95%）、5＝≥95%。[^3]

## 題目
> [!question]- What is the following about Medial Audit is INCORRECT? (2022-429)
> **B（不正確）** 選項 B 稱「PPV1 ... includes recommendation of BI-RADS Category 0, 4, 5」——漏掉了 **category 3**。依 ACR BI-RADS 2013 醫學稽核定義，PPV1（abnormal findings at screening）的分母為所有篩檢陽性判讀，即 **BI-RADS category 0、3、4、5**（篩檢時給定的 category 3 亦算陽性，其偽陽性計入 FP1）。故 B 敘述不完整而錯誤。A（台灣衛福部規範乳攝品保）、C（PPV2＝建議切片之 category 4、5）、D（PPV3＝實際切片之 category 4、5，即陽性切片率）皆正確。[^2] → [[mammography-medical-audit-ppv]]

> [!question]- 關於 Mammography audit, 以下何者為非？ (2021-337)
> **C（為非／錯誤）**——Screening 的 **recall rate** ＝（**BI-RADS category 0**）÷（總檢查數），**只含 category 0**；選項 C 稱「(category 0,4,5 之和)÷(總檢查數)」多納入 4、5，故錯（4、5 屬 CDR/PPV 相關，且通常於診斷性檢查後才給定）。A（screening 的 category 3 屬陽性判讀）正確；B（diagnostic 的 category 3 屬陰性判讀）正確；D（PPV2＝真陽性數 ÷ 建議切片數）正確。[^2][^4] → [[mammography-medical-audit-ppv]]
