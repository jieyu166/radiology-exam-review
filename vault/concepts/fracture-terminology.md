# fracture-terminology

**骨折術語最常考的陷阱是「疲勞性 vs 不足性骨折」定義對調——疲勞性骨折（fatigue）＝『正常骨』受『異常應力』；不足性骨折（insufficiency）＝『異常骨』受『正常應力』，兩者剛好相反。蝴蝶狀骨片（butterfly fragment）是骨折線間的三角形骨片（粉碎性骨折），並非撕脫性骨折。開放性骨折＝骨折處與外界相通。** 判讀分水嶺：**記「fatigue＝運動員/新兵的正常骨過用」「insufficiency＝骨鬆/老人/女性的弱骨」；butterfly＝彎折力造成的楔形中段骨片（≠ 韌帶拉扯的 avulsion）；open＝有皮膚破損/與空氣相通（感染風險、外科急症）。**

## Summary
- **開放性骨折（open/compound）**：骨折處與**外界環境（空氣/皮膚破損）相通**——感染風險高，屬外科急症。[^1]
- **疲勞性骨折（fatigue，屬 stress fracture）**：**正常骨骼承受「異常/反覆」應力**（好發運動員、跑者、軍事新兵）。[^1][^2]
- **不足性骨折（insufficiency，屬 stress fracture）**：**異常/弱化骨骼承受「正常」應力**（骨質疏鬆、女性、老人、放射後、代謝性）。[^1][^2]
- **病理性骨折**：發生於**局部骨病灶（腫瘤/轉移）**處，屬 insufficiency 之特例但保留給焦點性骨異常。[^2]
- **蝴蝶狀骨片（butterfly fragment）**：位於近/遠端骨折片「之間」之**大型三角形/楔形骨片**（彎折力所致粉碎骨折），ORIF 時可能需獨立螺絲/骨板；**非**韌帶/肌腱附著處撕脫（後者為 avulsion fracture）。[^1]

## 放射科醫師影像判讀重點
- **fatigue vs insufficiency（核心）**：看「骨質正常否 + 應力正常否」——正常骨異常力＝fatigue；異常骨正常力＝insufficiency。[^2]
- **好發族群線索**：新兵/跑者的蹠骨/脛骨＝fatigue；老年骨鬆的薦骨/恥骨支/股骨頸＝insufficiency。[^2]
- **butterfly vs avulsion**：butterfly＝骨折線間楔形片（粉碎、彎折）；avulsion＝關節/附著點被韌帶肌腱拉下的小片。[^1]
- **open 判讀**：找皮下氣體/軟組織缺損/與外界相通，提示開放性（影響處置與抗生素）。[^1]
- **病理性警覺**：低能量骨折 + 局部溶骨/破壞 → 疑病理性骨折，找底下病灶。[^2]

## 臨床重點（5 句）
1. **定義對調陷阱**：fatigue＝正常骨異常力；insufficiency＝異常骨正常力。[^1][^2]
2. **族群**：fatigue 運動員/新兵；insufficiency 骨鬆/老人/女性。[^2]
3. **butterfly ≠ avulsion**：前者骨折線間楔形片、後者附著點撕脫。[^1]
4. **open**：與外界相通、感染風險、外科急症。[^1]
5. **病理性**：局部病灶處骨折，需找底下腫瘤/轉移。[^2]

> [!note] 考點：關於骨折術語，何者敘述正確？
> **開放性骨折 = 與外界環境相通（A）**——正確。疲勞性/不足性骨折之「正常/異常骨」與「異常/正常應力」常被對調（正確：fatigue＝正常骨異常力、insufficiency＝異常骨正常力）；蝴蝶狀骨片為骨折線間三角形骨片（粉碎），非撕脫性骨折。[^1][^2]
