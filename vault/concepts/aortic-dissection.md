# aortic-dissection

**分類分水嶺只看「有沒有吃到 ascending aorta」：吃到＝Stanford A（開刀），沒吃到＝Stanford B（先內科控血壓）。破口在哪、往哪延伸都不影響 Stanford 分類——只從 arch 到 descending、不侵犯升主動脈者，即 Type B。**

## Summary
- **Stanford 分類（決定治療的實用分類）**：**Type A（約 60%）＝侵犯 ascending aorta**（90% 距主動脈瓣 10 cm 內）；**Type B（約 40%）＝不侵犯 ascending aorta**。分界只看升主動脈是否受累，與原發破口位置無關。[^1][^2]
- **由 aortic arch 起始延伸至 descending thoracic aorta、未及 ascending aorta ⇒ Stanford Type B。**[^2]
- **DeBakey 分類（依起源與範圍）**：Type I＝起源於升主動脈、至少侵犯弓部、可延伸至降主動脈；Type II＝起源且侷限於升主動脈；Type III＝起源於降主動脈（IIIa 侷限胸主動脈、IIIb 延伸至橫膈以下）。[^2]
- **治療對應**：Type A 因侵犯 aortic root 須手術；Type B 標準為內科控制高血壓，複雜型（malperfusion、破裂、瘤樣擴大）才手術或 TEVAR。[^2]

## 放射科醫師影像判讀重點
- **CTA 為急性剝離首選**（快速、準確）；升主動脈段須 ECG-gating 或 high-pitch 以免搏動假影誤判 intimal flap；MR/MRA 適合非急性追蹤與血流動力學評估。[^2]
- **雙腔＋intimal flap（double-barrel aorta）為診斷關鍵**。False lumen 通常較大、呈 beak sign（楔入 true lumen）、cobweb sign（膠原殘餘）、流速較慢對比較低、可血栓化延遲強化；true lumen 與未剝離段相連、截面積較小。[^1][^2]
- **判類的第一步是判斷升主動脈是否受累**（決定 Stanford A/B）；接著沿 flap 追蹤範圍與各分支（冠狀、頭臂、腹腔、腎、腸繫膜上、髂動脈）起源自 true 或 false lumen，評估 malperfusion。[^2]
- **CXR 常異常但非特異**（25% 正常）：縱膈變寬（>8 cm）、主動脈弓輪廓模糊（66%）、ring sign（鈣化內膜內移 >5 mm）、左心尖帽、氣管偏移。[^2]
- **DDx**：thrombosed aneurysm、intramural hematoma（壁內出血、無 flap／破口）、penetrating atherosclerotic ulcer（多見於降主動脈、可進展為剝離）。[^1][^2]

## 題目
> [!question]- 依照 Stanford classification of aortic dissection，如果一位病患的 dissection 是由 aortic arch 開始到 thoracic descending aorta，算是哪種 type? (2022-359)
> **Type B（關鍵）**——Stanford 分類只看是否侵犯 **ascending aorta**：本例剝離自 aortic arch 起、延伸至 descending thoracic aorta，**未侵犯升主動脈**，故為 **Stanford Type B**（DeBakey 對應 Type III）。若吃到升主動脈才是 Type A。⚠️ 原始選項因解析退化僅存 A/B 且文字殘缺，此處依實際查證給出正確概念答案 Type B。[^1][^2]
