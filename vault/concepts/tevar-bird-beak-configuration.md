# tevar-bird-beak-configuration

**TEVAR 後「鳥嘴徵象（bird-beak）」＝近端支架與主動脈弓「內側／小彎（lesser/inner curvature）」貼合不全，兩者間夾一楔形間隙。分水嶺：它出現在弓的內彎（underside），不是外彎（greater curvature）——這是本題陷阱。鳥嘴與 type Ia endoleak 風險升高相關，也是支架內折（infolding/collapse）的潛在危險因子。**

## Summary
- **定義**：bird-beak 為近端支架（endograft）與主動脈弓壁「貼合不全」，於支架與管壁間形成**楔形間隙（wedge-shaped gap）**；發生在主動脈弓的**內側/小彎（inner/lesser curvature）**，因支架難以貼合弓內彎的銳角。[^1][^2]
- **與 type Ia endoleak 相關**：bird-beak 與 type Ia（及 IIa）endoleak 風險顯著相關（P<.01）；鳥嘴越長，發生 endoleak 的機率越高。[^2]
- **type II endoleak 來源**：本研究中 type II endoleak 來自**左鎖骨下動脈（left subclavian artery）**。[^2]
- **支架內折/塌陷（infolding/collapse）**：為 TEVAR 不良事件之一，bird-beak 為其潛在危險因子。[^2]

## 放射科醫師影像判讀重點
- **判讀位置**：於術後 CTA 矢狀/斜矢狀重組觀察近端 landing zone，鳥嘴位於弓的**下緣（內彎）**，表現為支架游離緣翹起、與管壁間充填對比劑或血栓的三角形間隙；沿**外彎（greater curvature）** 描述即為錯誤（本題 A 選項的陷阱）。[^1][^2]
- **臨床意義**：辨識 bird-beak 有助預測 TEVAR 後不良事件——近端封閉不良 → type Ia endoleak（血流沿支架近端漏入瘤腔）、以及血流動力學造成的支架近端內折/塌陷。[^2]
- **endoleak 分類複習**：type I＝支架貼附處漏（Ia 近端、Ib 遠端），type II＝分支血管逆流填充瘤腔（TEVAR 常為左鎖骨下動脈；腹主為腰動脈/IMA），type III＝支架接合處或破孔，type IV＝織物孔隙滲漏，type V＝endotension。[^3]

### 參考來源
[^1]: *Endoleak*. Radiopaedia.org（實際查證 accessed 2026-07-06）：endoleak 五型分類——type I 為支架貼附處漏（Ia 近端、Ib 遠端）、type II 為分支血管逆流（最常見）、type III 為支架缺損、type IV 為織物孔隙、type V 為 endotension；type I 佔 up to 10%，常因病人/裝置選擇不當。
[^2]: **Tier 1** Ueda T, Fleischmann D, Dake MD, Rubin GD, Sze DY. *Incomplete endograft apposition to the aortic arch: bird-beak configuration increases risk of endoleak formation after thoracic endovascular aortic repair*. Radiology. 2010;255(2):645-652（According to PubMed；DOI [10.1148/radiol.10091468](https://doi.org/10.1148/radiol.10091468)；實際查證 accessed 2026-07-06）：bird-beak 定義為近端 endograft 與主動脈弓「貼合不全、形成楔形間隙」；64 例中 28 例（44%）有 bird-beak，與 type Ia 或 IIa endoleak 風險顯著相關（P<.01）；type II endoleak 來自左鎖骨下動脈；鳥嘴較長者 endoleak 較多；不良事件含支架塌陷/內折（6 例）。
[^3]: **Tier 1** 同 Radiopaedia《Endoleak》與 Ueda 2010：endoleak 分型與 TEVAR type II 來源（左鎖骨下動脈）。
