# aortic-dissection-stanford

**Stanford 分型只問一件事——最近端的剝離累及到哪裡：只要「碰到升主動脈」就是 Type A（開刀），沒碰到（左鎖骨下動脈遠端起始）就是 Type B（藥物）。剝離「從主動脈弓起始」是原始 Stanford／DeBakey 都未明確涵蓋的灰色地帶，現代共識另立 non-A-non-B 一類。**

## Summary
- **Stanford 分型（依最近端累及範圍，treatment-oriented）**：[^1][^2]
  - **Type A**：累及**升主動脈**（±弓／降主動脈）；原始定義為累及左鎖骨下動脈起源「近端」的任何一段。→ **手術重建**（因可致冠狀動脈阻塞、主動脈瓣閉鎖不全、心包填塞）。
  - **Type B**：**僅累及降主動脈**（剝離起於左鎖骨下動脈**遠端**）。→ **藥物（控制血壓）** 為主，惡化／併發症才介入。
- **DeBakey 分型（依起源＋侵犯範圍）**：[^1]
  - **Type I**：起於升主動脈，向下延伸至少到主動脈弓、常更遠。
  - **Type II**：起於且**侷限**於升主動脈。
  - **Type III**：起於降主動脈、通常向遠端延伸（不累及升主動脈）。
- **弓部剝離的分類爭議（本題核心）**：起源／逆行侵犯**侷限在主動脈弓**（brachiocephalic trunk 與左鎖骨下動脈之間）者，**原始 Stanford 與 DeBakey 皆未明確定義**。[^2]
  - 依**原始 Stanford「最近端累及」**邏輯，弓部位於左鎖骨下動脈近端 → 會被歸為 **Type A**。
  - 美國外科共識（2020）改以**內膜撕裂位置**定義：撕裂在升主動脈（含 brachiocephalic trunk 分支段）＝A；撕裂在 brachiocephalic trunk 遠端＝B。
  - 歐洲外科共識（2018）／TEM 分型另立 **non-A-non-B**：近端撕裂或逆行侵犯位於弓部（brachiocephalic trunk 與左鎖骨下動脈之間）者。
- **Svensson class 1–5**（AAS 統整）：1=典型剝離、2=壁內血腫(IMH)、3=不完全剝離(ID)、4=穿透性潰瘍(PAU)、5=醫源性／外傷性剝離。[^1]

## 放射科醫師影像判讀重點
- **判讀第一步＝定位最近端內膜瓣**：CTA 見 intimomedial flap 分出真假腔；只要升主動脈有 flap 即 Stanford A（外科急症），須額外評估冠脈開口、主動脈瓣、心包積血。[^1]
- **真假腔辨別**：真腔較小、收縮期擴大、無栓塞、早期收縮期層流；假腔較大、收縮期縮小、可栓塞、beak sign（假腔與 flap 呈銳角）、cobweb sign（假腔內線狀充盈缺損）。[^1]
- **ECG-gated CTA**：升主動脈受搏動假影干擾，弓／升主動脈段建議心電門控以免把 pulsation artifact 誤判為 flap（好發左前、右後象限）。[^1]
- **弓部起始／侷限剝離要主動標註 non-A-non-B**：現代共識與外科決策已把它與 A、B 分開，報告不宜含混歸為 A 或 B；需描述撕裂位置、逆行侵犯範圍與弓上分支受累。[^2]
- **NECT 不可省**：壁內血腫（IMH）在 NECT 呈環狀／新月形高密度，CTA 未必顯著，須以窄窗（W200/L40）判讀。[^1]

## 題目
> [!question]- 依照Stanford classification of aortic dissection，如果一位病患的dissection是由aortic arch開始到thoracic descending aorta，算是哪種type? (2022-359)
> **⚠️ 選項在題庫匯入時嚴重毀損（僅殘留 "Type" 與混合的 B 選項），無法對應單一字母，請醫師覆核原卷。** 依**原始 Stanford「最近端累及」**定義，主動脈弓位於左鎖骨下動脈近端 → 累及弓部者歸 **Type A**（因此若原卷選項含「Type A」則答 A）。惟此為 Stanford／DeBakey 原始分型未明確涵蓋的**弓部剝離特例**，現代外科共識（歐洲 2018／TEM）另立 **non-A-non-B** 一類專指弓部（brachiocephalic trunk 與左鎖骨下動脈之間）起始／侷限之剝離——若原卷選項含 non-A-non-B 則以其為最新答案。詳見 [[aortic-dissection-stanford]]。[^1][^2]
