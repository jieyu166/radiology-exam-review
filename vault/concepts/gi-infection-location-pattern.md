# gi-infection-location-pattern

**腸胃道感染依病原體有特徵性解剖分布：結核、typhlitis、阿米巴以『迴結腸（ileocolonic，遠端迴腸+盲腸）』為主；但 Giardia（梨形鞭毛蟲）主要侵犯『近端小腸』，非迴結腸。** 判讀分水嶺：**近端小腸寄生蟲（Giardia、Strongyloides）vs 遠端小腸細菌（Salmonella、Shigella、Yersinia）；迴結腸為主（TB、typhlitis、amebiasis）；右結腸（Salmonella/Shigella/Campylobacter/Yersinia，Yersinia/Salmonella 好發升結腸、Shigella 降結腸）；全結腸炎（C. difficile/CMV/E. coli）——C. difficile 之 CT 特徵為 accordion sign。**

## Summary
- **迴結腸為主（ileocolonic）**：**tuberculosis、typhlitis（嗜中性球低下盲腸炎）、amebiasis** 最常侵犯**遠端迴腸與盲腸**（Yersinia、Crohn 亦好發此區）。[^1]
- **近端小腸**：**寄生蟲（Giardia、Strongyloides）**——Giardia 主侵**近端小腸（十二指腸/近端空腸）**，**非迴結腸**。[^1]
- **遠端小腸**：**細菌（Salmonella、Shigella、Yersinia）**。[^1]
- **右結腸**：Salmonella、Shigella、Campylobacter、Yersinia；**Yersinia/Salmonella 好發升結腸、Shigella 好發降結腸**。[^1]
- **左結腸/直乙狀結腸**：Schistosomiasis（左結腸）；HSV、Gonorrhea（直乙狀結腸）。[^1]
- **全結腸炎（pancolitis）**：**Clostridioides difficile、CMV、E. coli**；**C. difficile 之 CT 相對特異徵象＝accordion sign（手風琴徵）**。[^1][^2]

## 放射科醫師影像判讀重點
- **首選/一般徵象（STATdx）**：**CECT + 多平面重組為首選**；**黏膜過度強化、明顯黏膜下水腫、腹水、多發氣液平、pericolonic fat 浸潤**；US 對稱壁增厚 + 黏膜下高回音 + color Doppler 壁血流增加。[^3]
- **部位對應病原（STATdx，關鍵表）**：**C. difficile 節段或全結腸（遠端小腸少）、Campylobacter/E. coli(O157:H7) 全結腸、CMV 遠端迴腸+右結腸或全結腸、Yersinia 右結腸+終末迴腸（RLQ 淋巴結群）、Salmonella(typhoid) 盲腸/右結腸+迴腸、Shigella 左結腸為主、TB 右+近端橫結腸+迴腸、amebiasis 右結腸±終末迴腸、Schistosoma 左/乙狀結腸、Actinomyces/Gonorrhea/Chlamydia/HSV/梅毒 直乙狀結腸、Histoplasma/mucor 迴盲/右結腸**。[^3]
- **accordion sign（C. diff，STATdx）**：**強化黏膜與黏膜下水腫交替條帶 + 管腔受壓**；常 pancolitis，見於 C. difficile/Campylobacter/E. coli/CMV；可進展至出血壞死/穿孔/toxic megacolon。[^2][^3]
- **TB ileocecal（STATdx）**：**Fleischner sign（迴腸-盲腸直角相交 + 顯著 ileocecal valve 肥大）、環周橫向潰瘍、壁增厚 > Crohn、apple-core 狹窄難與癌區分、低密度腸繫膜淋巴結腫（乾酪化）**。[^3]
- **amebiasis（STATdx）**：右結腸為主、skip lesion 似 Crohn、ameboma（右結腸短段肉芽腫）、可續發肝/肺膿瘍。[^3]
- **DDx（STATdx）**：UC（壁增厚較不明顯、lead pipe）、Crohn（cobblestone/瘻管/skip）、缺血性結腸炎（watershed、少 pancolitis、直腸罕受累、pneumatosis/門脈氣）、stercoral colitis（糞石壓迫壞死、乙狀/直腸）。[^3]
- **陷阱**：Giardia 屬近端小腸、非迴結腸——常考鑑別。[^1]

## 臨床重點（5 句）
1. **美國最常見細菌病原（STATdx）**：**C. difficile、Salmonella、Campylobacter、E. coli**；病毒以 norovirus/rotavirus、原蟲以 Cryptosporidium/Giardia/Cyclospora 最常見。[^3]
2. **C. difficile 危險因子（STATdx）**：**前用抗生素（尤 clindamycin）、住院/安養機構、化療黏膜損傷**；住院病人達 1% 發生。[^3]
3. **臨床/實驗室（STATdx）**：水樣或血樣腹瀉、發燒、腹絞痛壓痛；**細菌↑嗜中性球、病毒↑淋巴球、黴菌/寄生蟲→嗜酸性球增多**；急性起病（TB 例外為慢性）；診斷靠糞便/血液培養、內視鏡切片、血清學。[^3]
4. **併發（STATdx）**：出血/穿孔/阻塞/toxic megacolon/敗血；**Yersinia→肝膿瘍、amebiasis→肝肺膿瘍、Schistosoma→肝脾腫大/門脈高壓、E. coli O157:H7→溶血性尿毒症候群**。[^3]
5. **治療（STATdx）**：多數細菌自限 1-2 週；**C. difficile 用 metronidazole/糞菌移植；TB 用抗結核藥（不用類固醇）；CMV 治療 AIDS；黴菌/寄生蟲用抗黴/驅蟲藥**。[^3]

## 腹腔結核／結核性腹膜炎（abdominal / tuberculous peritonitis，enrich）
- **危險因子**：Radiopaedia 明列**同時 HIV 感染、腹膜透析、肝硬化**；題目另涵蓋糖尿病、惡性腫瘤（皆屬腹腔結核之公認危險因子）。[^4]（2021-325 選項 A 為正確敘述）
- **三大侵犯型／傳播路徑**：最常見型態為**腹膜、腸道、與/或肝臟**受侵；感染途徑＝吞入含菌乳汁/痰（先犯腸黏膜再擴及腸壁、局部淋巴結、腹膜）、血行播散至腹膜/淋巴結/實質臟器、鄰近直接蔓延（如脊椎結核經腰大肌膿瘍）。[^4][^5]（選項 B 為正確敘述）
- **結核性腹膜炎分型**：**濕型（wet，有腹水，最常見約 90%）／乾型（dry，無腹水，繫膜淋巴結腫＋纖維沾黏＋cake-like 網膜）／纖維固定型（fibrotic-fixed，cake-like 腫塊＋固定/糾結腸圈＋包裹性腹水）**，三型間常重疊。[^4]
- **腸道結核（ileocecal）**：**環周壁增厚以迴盲部最常見（約 90%）**；本概念上段 STATdx 內容另載 Fleischner sign、apple-core 狹窄、乾酪化淋巴結。[^5]（選項 C「迴盲部環周壁增厚」為正確敘述）
- **淋巴結（關鍵鑑別）**：結核性淋巴結腫呈**低衰減／中央乾酪化壞死**（可漸成囊狀），淋巴結彼此糾結而周圍發炎變化輕微；**並非均質實心中心**。[^4]（選項 D 稱「腸繫膜與後腹膜淋巴結呈 homogeneous solid centers」為**錯誤**＝正解）
- **CT 其他徵象**：腹膜/繫膜**結節狀或對稱增厚並強化**、腹水（濕型腹水常高衰減 20–45 HU，因高蛋白/細胞含量）、**cake-like/結節狀/塗抹狀網膜（omental caking）**——外觀與腹膜癌病（peritoneal carcinomatosis）相似，為主要鑑別。[^4]

> [!note] 考點：何者「非」以迴結腸(ileocolonic)為主要侵犯部位的疾病?
> **Giardia（D）**——梨形鞭毛蟲主要侵犯**近端小腸**，非迴結腸。Tuberculosis、Crohn disease、typhlitis 皆好發迴結腸區域（Campylobacter 好發右側結腸）。[^1]

## 題目
> [!question]- Which is not predominantly an ileocolonic disease? (2017-285)
> **Giardia（D）**——主要侵犯**近端小腸**，非迴結腸為主。Tuberculosis、Campylobacter、Crohn Disease、Typhlitis 皆與迴結腸區域相關。[^1]

> [!question]- Which of the following statement about tuberculous peritonitis is incorrect? (2021-325)
> **D（Lymphadenopathy usually demonstrates homogeneous solid centers over the mesentery and retroperitoneum）**——錯。結核性淋巴結腫典型呈**低衰減／中央乾酪化壞死**（可漸成囊狀），彼此糾結而周圍發炎輕微，**非均質實心中心**。A（危險因子含肝硬化、HIV、糖尿病、惡性腫瘤、腹膜透析）對、B（最常見型態為腹膜、腸道與/或肝臟受侵）對、C（腸道結核以迴盲部環周壁增厚最常見）對。
