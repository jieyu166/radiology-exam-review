# standing-arterial-wave

**Standing（或 stationary）arterial wave 是罕見、良性的血管攝影現象，見於『各處周邊動脈』（並非僅侷限下肢），為導管誘發動脈痙攣與對比劑分層流動偽影所致，無病理意義。** 判讀分水嶺：**表現為沿動脈『規則、對稱、等間隔』的多發鋸齒狀/波浪狀凹痕（sinusoidal）；較常見於傳統血管攝影（導管相關機轉），亦可見於 CTA/MRA；有時被誤認為 fibromuscular dysplasia（FMD）——但 FMD 之 string-of-beads 較不規則/不對稱。**

## Summary
- **外觀**：**多發、對稱、等間隔之鋸齒狀/波浪狀凹痕（corrugated/serrated，近正弦波型）**沿動脈分布。[^1][^2]
- **好發部位**：**多描述於周邊動脈整體**——**非侷限下肢血管**。[^1]
- **與檢查方式關係**：**較常見於傳統血管攝影（conventional angiography，導管相關）**；亦可見於 CTA/MRA（較少）。[^1][^2]
- **成因**：不明；提出機轉包括**導管誘發動脈痙攣**與**對比劑分層流動之血流性偽影**。[^1][^2]
- **臨床意義**：**無病理重要性、良性現象**。[^1][^2]
- **鑑別陷阱**：**可被誤認為 FMD**——需與真正 FMD 之 string-of-beads（較不規則/不對稱）鑑別。[^1]

## 放射科醫師影像判讀重點
- **辨識規則性**：standing wave 為「規則、對稱、等間隔」凹痕；FMD 之 beading 不規則、口徑不一——是關鍵區分。[^1]
- **檢查脈絡**：傳統導管攝影中出現規則波浪凹痕、無其他病灶 → 良性偽影，勿過度診斷。[^1][^2]
- **MRI 表現**：可呈沿血管之高低訊號帶。[^2]
- **可逆性**：屬暫時性/偽影，非固定狹窄；不需處置。[^1][^2]
- **陷阱**：勿誤判為 FMD、血管炎或動脈粥狀硬化串珠。[^1]

## 臨床重點（5 句）
1. **良性偽影**：規則對稱鋸齒凹痕，無病理意義。[^1][^2]
2. **部位**：周邊動脈整體，非僅下肢。[^1]
3. **檢查**：較常見於傳統血管攝影（導管相關）。[^1][^2]
4. **成因**：導管痙攣 + 對比劑分層血流偽影。[^1][^2]
5. **鑑別**：勿誤為 FMD（後者不規則串珠）。[^1]

> [!note] 考點：關於 Standing (or Stationary) arterial wave，何者「錯誤」?
> 「**僅發生於下肢血管（C）**」錯誤——多數描述於**周邊動脈整體**，非侷限下肢。與 MR angiography 相比較常見於 conventional angiography、為 benign phenomenon 無顯著臨床意義、有時被誤認為 FMD 皆正確。[^1][^2]
