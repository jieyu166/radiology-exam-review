# hht-liver

**HHT（Osler-Weber-Rendu）為體染色體顯性遺傳，肝臟受侵犯常見但多數無症狀。** CT 表現：dilated hepatic arteries、portal/hepatic vein early filling（A-V/A-P shunting）、biliary abnormality。

## Summary
- 遺傳：autosomal dominant [^1]
- 臨床三聯：mucocutaneous telangiectases + epistaxis + visceral AVMs [^1]
- 肝臟受侵犯：**有肝臟 AVM 的病人很多，但 symptomatic liver involvement 少見** [^1]
- CT：dilated hepatic arteries、arterial phase 早期 portal/hepatic vein filling、biliary changes [^1]
- 可侵犯：pulmonary / cerebral / spinal AVMs [^1]

## 放射科醫師影像判讀重點
- **肝動脈擴張與扭曲**：HHT 肝受侵犯的核心是異常血管分流，總肝動脈與肝內動脈常明顯擴張、扭曲，是動脈期首要陽性徵象。[^1][^2]
- **三型分流並存**：可同時存在動脈-門靜脈(arterioportal)、動脈-肝靜脈(arteriosystemic/肝靜脈)及門靜脈-肝靜脈分流；動脈期即見門靜脈或肝靜脈提早顯影(early filling)為關鍵判讀。[^2]
- **末梢望遠鏡樣毛細血管擴張與 THAD**：肝實質內可見瀰漫性 telangiectasia 及穿透性血管，分流造成一過性肝衰減差異(THAD/THID)，勿誤判為腫瘤。[^2]
- **膽道與灌注併發症**：慢性動脈竊流可致膽管缺血性狹窄/膽道異常，長期高流量分流可進展為高輸出心衰竭或門脈高壓、結節性再生性增生。[^2]
- **判讀陷阱**：分流造成的局灶性早期強化易被誤認為富血管腫瘤(如 FNH/HCC)，應結合擴張供養動脈、早期靜脈顯影與多發性/瀰漫分布判定為分流而非腫瘤。[^2]

## 臨床重點（5 句）
- HHT(Osler-Weber-Rendu)為體染色體顯性遺傳，多因 ENG、ACVRL1 等基因突變致血管生成異常。[^1]
- 臨床以 Curaçao 準則診斷：反覆鼻出血、皮膚黏膜毛細血管擴張、內臟動靜脈畸形、家族史，符合三項以上為確診。[^1]
- 肝臟血管病變在 HHT 病人相當常見，但多數無症狀，僅少數出現高輸出心衰竭、門脈高壓或膽道缺血等症狀性表現。[^1]
- 全身可同時侵犯肺、腦、脊髓 AVM，肺 AVM 有反常栓塞與腦膿瘍風險，需一併評估。[^1]
- 症狀性肝受侵犯的處置以支持與併發症治療為主，抗血管生成藥(如 bevacizumab)可用於高輸出心衰竭；肝移植保留給難治個案。[^1]
