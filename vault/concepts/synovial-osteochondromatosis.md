# synovial-osteochondromatosis

**原發性滑膜（骨）軟骨瘤病是滑膜的良性化生性腫瘤——滑膜下組織緩慢形成多顆透明軟骨結節，日後鈣化/骨化並可脫落為關節內游離體；好發膝（up to 70%）＞髖，男性成人為主。** 判讀分水嶺：其病理切片有「顯著細胞異型性」，若病理科不知道病灶「源自滑膜」，極易被誤判為 **extraskeletal（滑膜）chondrosarcoma**——因此放射科務必把「病灶為滑膜起源、關節內、ring-and-arc 軟骨型鈣化」這個定位訊息傳達給病理科（本題答案 D「Synovial origin」）。記憶鉤：**軟骨的鈣化＝ring-and-arc，軟骨的訊號＝T2 很亮**，而「救命的一句話」是告訴病理科「這是滑膜長出來的」。

## Summary

### 本質與分期
- **原發性滑膜軟骨瘤病＝滑膜的良性化生/腫瘤性過程**，滑膜下結締組織緩慢形成透明軟骨結節，結節可增大、鈣化/骨化並脫落成關節內游離體。[^1][^2]
- 病理三期：**initial（滑膜內化生形成軟骨結節）→ transitional（結節脫落成關節內游離體，同時仍有活動性滑膜）→ inactive（滑膜增生消退、僅剩游離體）**。[^1]
- 好發 **膝關節（up to 70%）＞髖（~20%）＞肘、肩**；單關節（monoarticular）為主，偶可侵犯 **bursa 或 tendon sheath（tenosynovial 型，較少見，可見於手足）**。[^1][^2]
- 流行病學：好發 **4–5 十歲、男性略多**。[^1][^2]

### 關鍵考點——為何會被誤判為 chondrosarcoma
- 病理切片上結節可呈**顯著細胞異型性（cellular atypia）**，組織學外觀可**模擬 chondrosarcoma**。[^1][^2]
- **放射科的定位資訊是正確診斷的關鍵**：把病灶定位為「**滑膜起源、關節內**」可避免病理誤判為 extraskeletal chondrosarcoma——這正是本題答案（Synovial origin）。[^2]
- 真正惡性轉化（synovial/secondary chondrosarcoma）**確實可發生但罕見**；提示惡性的是**軟組織腫塊、超出關節範圍、轉移**等。[^1]

## 影像診斷

### X 光 / CT
- 影像取決於鈣化/骨化程度。典型為**多顆大小形狀相近的關節內鈣化，遍布關節，呈 "ring-and-arc"（rings-and-arcs）軟骨型礦化**；X 光可見鈣化結節者約 **70–95%**。[^1][^2]
- **骨的外壓性侵蝕（extrinsic erosion）約 20–50%**（尤其髖等容積受限關節）。[^2]
- **CT 最能顯示鈣化的關節內碎片與骨侵蝕**，並確認游離體位於關節內；arthrography 亦可證實關節內位置。[^1][^2]
- 若尚未鈣化（純軟骨結節），X 光可完全陰性或僅見軟組織腫脹／關節積液。[^1]

### MRI
- 訊號多變，取決於礦化程度、滑膜增生與游離體比例。**最常見型態（約 77%）＝T1 低至中等訊號、T2 非常高訊號（軟骨含水）、其內鈣化處為訊號空缺（signal void）**。[^1][^2]
- GRE 序列上鈣化可見 **blooming artifact**。[^1]
- 「burnt-out」病例可僅見骨化游離體而少軟骨訊號。[^1]

## 鑑別與報告要點

| 鑑別 | 關鍵區分點 |
|---|---|
| **Secondary（osteo）chondromatosis** | 年紀較大、明顯退化性變化、碎片較少且較大且常大小不一 |
| **Synovial / extraskeletal chondrosarcoma** | 軟組織腫塊、**超出關節範圍**、破壞性、轉移；純滑膜軟骨瘤病之異型性易被誤判為此 |
| **Tenosynovial giant cell tumour（PVNS/TGCT）** | 較融合的腫塊、MRI 瀰漫性低訊號（含鐵血黃素 blooming），無 ring-and-arc 鈣化 |
| **Lipoma arborescens** | 特徵性脂肪訊號/密度 |
| **Tumoural calcinosis / siderotic synovitis** | 依鈣化型態與含鐵訊號區分 |

**報告要點**：見關節內多發 ring-and-arc 軟骨型鈣化、T2 很亮的軟骨結節、±骨侵蝕→提示滑膜軟骨瘤病；**務必在報告與病理溝通中明載「病灶為滑膜起源、關節內」**，以免病理將其細胞異型性誤判為 chondrosarcoma。[^2]

## 題目
> [!question]- Pathologists can misinterpret the considerable cellular atypia of primary synovial osteochondromatosis as extraskeletal chondrosarcoma, if the radiologist does not communicate which imaging finding? (2021-254)
> **D（Synovial origin，滑膜起源）**——原發性滑膜軟骨瘤病之軟骨結節具顯著細胞異型性，組織學可模擬 chondrosarcoma；正確診斷有賴影像把病灶**定位為滑膜起源、關節內**並傳達給病理科。其餘選項雖為此病可見的影像特徵（腫塊內鈣化 B、骨侵犯 C、T2 高訊號 E），但**能避免 chondrosarcoma 誤判的關鍵訊息是「滑膜起源」**；A（超音波內部血流）非本病特徵性關鍵。[^2]
