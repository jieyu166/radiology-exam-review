#交換 #2018交換 #Physics 孕婦及哺乳婦女使用含釓對比劑，以下何者**錯誤**?
(A) 加拿大安大略省2003-2015年大規模健保資料庫研究顯示孕婦在懷孕任一期間曾接受含釓對比劑者和胎兒之罕見病況如類NSF異常(包含免疫風濕、發炎、皮膚浸潤性病變等)以及死胎率及新生兒死亡率有相關性。
(B) 孕婦施行磁振造影時，需謹慎評估含釓對比劑注射之必要性及風險，並盡量避免含釓對比劑注射。
(C) 必須使用時，建議孕婦使用標準劑量之低風險之含釓對比劑。
(D) 哺乳婦女接受含釓對比劑後，24小時內乳汁中有微量(< 0.04%)含釓對比劑，而嬰兒從消化道只吸收小於1%之乳汁，估計進入嬰兒循環為原對比劑之0.0004%以下。
(E) 有研究報告指出分泌乳汁口感可能改變。
??
**Ans: C**
【醫師裁決 2026-07-11｜完結】答案 C。正解：孕婦必須使用含釓對比劑(GBCA)時應採「達到診斷目的之最小劑量」，故選項 C 稱「標準劑量」為錯誤敘述。爭議來源：本題所引之台灣 2017 手冊 p.37 原文即寫「除非有極強適應症(very strong indication)，建議不使用含釓對比劑；必須使用時，建議使用標準劑量之低風險之含釓對比劑 [25,62]」——選項 C 幾乎逐字照抄 2017 版，故爭議在於 2017 版本身用「標準劑量」。版本演變：台灣 2017 p.37＝標準劑量 → 台灣 2020 p.40／2023 p.42＝達到診斷目的之最小劑量（2023 另加「注射含釓前提供驗孕」）→ ACR 2026＝最小診斷劑量(lowest dose)；2020 起已修正為最小劑量並與 ACR 一致。其餘 A/B/D/E 依手冊皆為正確敘述。詳見 [[contrast-media-safety]]
