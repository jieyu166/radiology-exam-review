#交換 #2021交換 #MSK Post-traumatic ulnar avulsion tear (foveal and/or styloid ﬁbers) of TFCC is classified as Palmer classiﬁcation
(A) Type 1A
(B) Type 1B
(C) Type 1C
(D) Type 1D
??
**Ans: B**
答案 B。Palmer 分類的 Class 1 為創傷性損傷，其中 1B 即尺側撕脫（ulnar avulsion），涉及 foveal／styloid 附著、可合併或不合併尺骨莖突基部骨折，常伴 DRUJ 不穩，正符合題幹「尺側撕脫（foveal 和／或 styloid 纖維）」。A 1A 為關節盤本體中央穿孔；C 1C 為遠端撕脫（ulnolunate／ulnotriquetral 韌帶自 carpus 撕脫）；D 1D 為橈側撕脫（±sigmoid notch 骨折）。
