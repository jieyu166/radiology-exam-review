#交換 #2021交換 #ABD According to LI-RADS Version 2018 Ancillary Features at MR, which feature is Not favoring benignity?
(A) Non-enhancing “capsule”
(B) Marked T2 hyperintensity
(C) Hepatobiliary phase isointensity
(D) Undistorted vessel
??
**Ans: A**
答案 A。LI-RADS v2018 之 ancillary features 分「偏惡性（可升級，上限僅至 LR-4）」與「偏良性（可降級）」兩類。A non-enhancing「capsule」屬偏惡性（favoring malignancy／偏 HCC），並非偏良性，故為正解；B marked T2 hyperintensity、C hepatobiliary phase isointensity、D undistorted vessel 皆屬偏良性之輔助特徵。→ [[li-rads-ancillary-benignity]]
