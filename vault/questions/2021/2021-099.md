#交換 #2021交換 #ABD 請選出typical prostate cancer 之MRI findings?
(A) T2 hypointensity, ADC dark signal, type III enhancement
(B) T2 hyperintensity, ADC dark signal, type III enhancement
(C) T2 hypointensity, ADC dark signal, type I enhancement
(D) T2 hyperintensity, ADC dark signal, type II enhancement
??
**Ans: A**
答案 A。攝護腺癌於周邊帶正常高 T2 訊號中呈低訊號（T2 hypointensity），因細胞密度高致擴散受限、ADC map 呈明顯低訊號（ADC dark），DCE 動態曲線呈初期快速上升後下降之 type III（wash-out）曲線，最可疑為癌，故 A 正確、為正解。B、D 之 T2 hyperintensity 與典型癌相反；C 之 type I（持續上升）為良性型曲線，皆不符。→ [[prostate-mri]]
