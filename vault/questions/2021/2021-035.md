#交換 #2021交換 #CV Which of the following is **not** correct about the native T1 value in T1 mapping of cardiovascular magnetic resonance?
(A) The native T1 value in myocarditis is increased.
(B) The native T1 value in cardiac amyloidosis is increased
(C) The native T1 value in Fabry’s disease is decreased.
(D) The native T1 value in siderotic cardiomyopathy is increased.
??
**Ans: D**
答案 D。native T1 值上升代表組織含水量增加或間質空間擴大，下降則見於細胞內脂質或鐵沉積。鐵過載型（siderotic）心肌病因鐵的順磁性效應會使 native T1「下降」而非上升，因此 D 為錯誤敘述，為本題所選。其餘皆正確：(A) 心肌炎的心肌水腫使 native T1 上升；(B) 心臟類澱粉沉積造成細胞外間質擴張，native T1 上升；(C) Anderson-Fabry 病因醣鞘脂在細胞內堆積（脂質過載），native T1 下降，且常在左心室肥厚出現前即已降低。→ [[myocardial-t1-mapping]]
