#交換 #2022交換 #CV 依照Stanford classification of aortic dissection，如果一位病患的dissection是由aortic arch開始到thoracic descending aorta，算是哪種type?
(A) Type
(B) Type A with arch involvement Type B with arch involvement
??
**Ans: B**
Stanford 分類只看是否侵犯 ascending aorta：Type A 侵犯升主動脈、Type B 不侵犯升主動脈。本例剝離自 aortic arch 起延伸至 descending thoracic aorta、未侵犯升主動脈，故為 Stanford Type B（DeBakey Type III）。⚠️ 原始選項因解析退化嚴重（僅 A/B、文字殘缺），正確概念答案為 Type B，建議醫師覆核原卷選項排列。 → [[aortic-dissection]]
