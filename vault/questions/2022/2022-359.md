#交換 #2022交換 #CV 依照Stanford classification of aortic dissection，如果一位病患的dissection是由aortic arch開始到thoracic descending aorta，算是哪種type?
(A) Type A
(B) Type B
(C) Type A with arch involvement
(D) Type B with arch involvement
??
**Ans: D**
依官方 2022 詳解 PDF p.270（答案 **D**＝Type B with arch involvement）。剝離起於 aortic arch、延伸至 descending thoracic aorta、未侵犯升主動脈→基礎屬 Stanford Type B；但「起自 aortic arch 向遠端延伸」為原始 Stanford 分類未明確描述之情形。依 RadioGraphics 2022（Steinbrecher 等，CT of the Difficult Acute Aortic Syndrome, 42(1):69–86）及 Lempel 等，此類多為 uncomplicated、以藥物治療，故歸類為「Type B with arch involvement」＝D。（原始匯入選項解析退化僅剩 A/B、看不到「with arch involvement」細分，故先前誤記 B；經官方 PDF 重建 4 選項並更正為 D。附註：American surgical consensus 2020 仍以 intimal tear 相對 LSCA 位置分 type A/B。）→ [[aortic-dissection]]
