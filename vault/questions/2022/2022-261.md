#交換 #2022交換 #CH UIP is most frequently found in patients with:
(A) SLE
(B) Dermato-myositis
(C) Rheumatoid arthritis
(D) Scleroderma
??
**Ans: C**
![[Pasted image 20260711215546.png]]就臨床事實而言，於結締組織病相關間質性肺病（CTD-ILD）中，UIP 型態最常見於類風濕性關節炎（RA）；SLE、皮肌炎、硬皮症則以 NSIP 為主。→ [[ipf]]

## 詳解附圖（OCR）
**Table 1. Radiological pattern in CTD-ILD**（結締組織病相關間質性肺病之放射學型態）

| 疾病 | NSIP | UIP | OP | PH | DAD | LIP | Hemorrhage | Airways disease |
| --- | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| **RA**（類風濕性關節炎） | + | **++++** | ++ | | | + | | ++++ |
| SSc（硬皮症） | ++++ | + | + | +++ | + | | | |
| PM/DM（多發性肌炎/皮肌炎） | ++++ | + | ++++ | | + | | | |
| SjS（乾燥症） | ++ | + | + | | | ++++ | | +++ |
| MCTD（混合結締組織病） | ++ | + | | + | | | | |
| SLE（全身性紅斑性狼瘡） | ++ | + | | ++ | ++ | | + | |

> `+` 個數代表觀察到該損傷型態的頻率：`++++` = 很常見／臨床顯著，`+` = 較少見，空白 = 罕見或未描述。
> **判讀重點**：UIP 欄唯有 **RA 為 ++++**，其餘 CTD 皆僅 `+`——故「UIP 最常見於哪種 CTD」答 **RA**；SSc、PM/DM、SjS 以 NSIP／OP／LIP 為主。
