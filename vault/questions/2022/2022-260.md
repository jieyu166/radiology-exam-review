#交換 #2022交換 #Breast According to BI-RADS 5th edition, which of the following descriptions about BI-RADS categories is **true**?
(A) Under MQSA, it is necessary to include a numeric assessment code (i.e., 0, 1, 2, 3, 4, 5, or 6) in addition to the assessment category in all mammography reports
(B) BI-RADS category 4 subdivisions (4A, 4B, 4C) are necessary to be included in mammography report
(C) It is necessary to include BI-RADS final assessment and/or numeric code for mammography examinations performed on men
(D) All of the above are true
??
**Ans: C**
⚠️ 本題選項為 OCR 擷取後錯位、拼接（原始 B/C 選項文字有交錯），逐項判定困難，暫依來源標記答案 C。就 [[bi-rads-categories]] 可確認的原則：每份乳房影像報告都須給一個最終評估分類（0–6），MQSA 要求報告載明評估與其對應處置；分類適用於男性乳房攝影亦然。至於 category 4 是否「必須」細分 4A/4B/4C，指引為建議而非強制，是常見陷阱。因選項文字污損，建議醫師覆核原始題幹再定案。→ [[bi-rads-categories]]
